llm 命令行工具默认切换至 GPT-5.6 Luna 并支持任意 OpenAI 兼容端点

新闻时间: 2026-07-31T04:35:59.064156+00:00 · 来源: rss

广受欢迎的开源命令行工具 llm（由 Simon Willison 开发）正式发布 0.32rc2 版本。此次更新将新用户未手动配置时的默认大语言模型，从 GPT-4o mini 切换为最新发布的 GPT-5.6 Luna。这一调整兼顾能力与成本：Luna 在推理、工具调用和多模态理解方面显著更强，但单次调用价格略高——输入 token 每百万 0.20 美元，输出 token 每百万 1.20 美元，而 GPT-4o mini 分别为 0.15 和 0.60 美元。对预算敏感或追求低延迟的开发者，还可选择更轻量的 GPT-5 nano（0.05/0.40 美元），专为高频 API 调用与子智能体任务优化。

除模型默认值外，0.32rc2 新增核心功能 llm openai endpoint。它允许用户直接向任意兼容 OpenAI Chat Completions 协议的服务端点（如本地运行的 LM Studio 或 Ollama）发送提示、发起对话或查询模型列表，无需预先注册模型配置。更重要的是，这些请求不会被记录，保障了实验阶段的隐私安全。该功能甚至支持“免安装”使用：借助轻量级 Python 包运行器 uvx，一条命令即可完成本地模型测试。

一个典型示例展现了其实用性：仅用一行 uvx 命令，就能向本地 LM Studio 托管的 Gemma-4-31b 模型发送带工具调用（-T llm_time --td）的提示。这填补了本地大模型快速验证与生产级 CLI 工具之间的关键空白，直击开发者长期面临的碎片化测试痛点。

综上，llm 正从单一 OpenAI 官方模型封装器，演进为通用的大语言模型交互接口——无论云端服务、自托管实例还是前沿实验模型，均可无缝接入。其清晰的默认策略、透明的成本提示与灵活的协议兼容性，正持续巩固其在现代 LLM 工作流中的基础地位。
