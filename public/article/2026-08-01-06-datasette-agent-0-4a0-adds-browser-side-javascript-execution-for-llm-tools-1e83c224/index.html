Datasette-Agent 0.4a0 支持在用户浏览器中运行 JavaScript

新闻时间: 2026-08-01T04:33:02.137306+00:00 · 来源: rss

Datasette-Agent 是一个基于大语言模型（LLM）的开源助手，专为探索和分析 Datasette 中的数据而设计。其最新发布的 0.4a0 alpha 版本迈出关键一步：新增 await context.browser_task() 接口，允许插件在用户浏览器中直接执行任意 JavaScript 代码。与传统工具调用（如执行 SQL 查询或调用后端 API）不同，这一机制首次将 AI 的推理能力延伸至前端——实现无需服务器往返的实时交互，例如动态高亮表格行、自动填充表单，或即时更新图表。

该功能延续了 Datasette 的核心理念：把数据变成原生、可交互的网页体验。Datasette 本身将数据同时发布为可浏览网站和 RESTful API；而 Datasette-Agent 进一步让 AI 不仅能查询后端，还能在前端“行动”。举例来说，当用户说“标出所有收入超过 1 万美元的行”，插件即可通过 browser_task() 直接向当前页面注入 CSS 或绑定点击事件，即时响应。

实现上强调安全隔离：JavaScript 在沙箱 iframe 或受限上下文中运行，且需插件开发者显式启用，并依赖用户授权。默认不开放 window 全局对象或敏感 API（如 localStorage），以安全性为优先。即便权限有限，仅对 DOM 的可控操作已足以支撑自然语言驱动的界面增强。

这一设计显著区别于主流 LLM 工具使用模式——后者多聚焦于编排后端服务（数据库、API 等），而将浏览器视为被动渲染层。browser_task() 则把浏览器视作代理工作流中的主动参与者。这契合边缘智能与客户端推理的发展趋势：计算更靠近用户，兼顾隐私、响应速度与离线能力。随着 Datasette 持续推动数据民主化，这项功能标志着 AI 代理正从“回答问题”迈向“重塑用户与数据的交互方式”——就在数据呈现的同一页面上。
