uv 0.12.1 支持按包设置预发布策略并新增 Xonsh 激活脚本

新闻时间: 2026-08-01T04:33:03.230481+00:00 · 来源: github

Astral-sh 开发的 uv — 一款用 Rust 编写的高性能 Python 包安装器与依赖解析器 — 于 2026 年 7 月 31 日发布 0.12.1 版本。此次更新为使用现代 Python 工具链（如 PEP 723 内联脚本或自定义索引源）的开发者带来了多项实用改进。

最值得关注的新功能是支持按包指定预发布版本策略，通过 --prerelease-package 参数实现。不同于全局启用预发布版的 --prerelease 标志，该功能允许开发者仅对特定包（例如 requests 或 numpy）启用预发布版本，其余包仍保持稳定 —— 这在实际项目中极为关键：某些库早期发布重大变更，而另一些则需严格锁定版本。

另一项实用增强是支持本地 HTML 扁平索引（flat index）：开发者现在可直接将 uv 指向本地 index.html 文件，将其作为简易、离线可用的包仓库 —— 特别适用于无网络环境、CI 缓存或企业内部工具链。同时，uv 新增了 activate.xsh 激活脚本，使虚拟环境能在 Xonsh（一种融合 Python 与 Shell 语法的流行终端）中一键启用，填补了长期缺失的原生支持空白。

在可靠性方面，多个预览功能优化了元数据精简场景（如 PEP 723 脚本）下的锁文件验证逻辑：更准确地处理直接 URL 约束，并避免因工作区依赖共享源而导致的误判性拒绝。性能层面，ARM64 架构的 Windows 和 macOS 上 SHA-256 哈希计算加速，且 uv 锁文件解析路径更高效。此外，多项修复提升了稳定性：uv add --index 在更新 pyproject.toml 时保留原始文件路径；--find-links 的路径现在能正确相对于 requirements 文件解析；uv tool update-shell 等命令也确保配置写入完成后再退出。

尽管不是大版本跃迁，0.12.1 展现了 uv 团队以用户痛点为导向的扎实迭代节奏 —— 在易用性、可复现性和跨 Shell 兼容性上持续夯实基础。随着 uv（常被称比 pip 快 10–100 倍）在 Python 社区加速普及，这类高质量小版本正不断巩固其作为现代 Python 开发核心工具的地位。
