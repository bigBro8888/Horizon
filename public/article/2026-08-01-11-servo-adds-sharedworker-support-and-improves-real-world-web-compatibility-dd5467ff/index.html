Servo 实现 SharedWorker 支持并提升网页兼容性

新闻时间: 2026-08-01T04:33:02.670080+00:00 · 来源: hackernews

在2026年6月的更新中，Servo 浏览器引擎——这一最初由 Mozilla 孵化的、基于 Rust 的实验性渲染引擎——在关键 Web 平台能力上取得实质性进展。本次发布新增了对 CSS 媒体查询（media queries）的完整支持，显著提升了对主流网站的真实世界兼容性，并首次实现了 SharedWorker API 的可用版本。这些并非简单修补：媒体查询是响应式网页设计的基础，而 SharedWorker 则允许同一源（same-origin）下的多个标签页、窗口或 iframe 共享一个后台工作线程，此前 Servo 完全不支持该功能。

与 Blink 或 Gecko 等主流引擎不同，Servo 始终将架构创新置于功能追赶之上。其核心设计强调细粒度并行、通过 Rust 保障内存安全，以及基于 GPU 的加速渲染管线。自 2020 年 Mozilla 终止专职投入后，项目移交至欧洲 Linux 基金会，完全由志愿者维护。因此，每一个具体进展——尤其是 SharedWorker 这类涉及跨上下文消息路由、严格同源校验和生命周期协调的复杂功能——都体现了持续的技术活力。

SharedWorker 的实现尤为关键：它不仅关乎将 JavaScript 移出主线程，更要求引擎在多个隔离的浏览上下文间可靠同步状态、统一管理生命周期，并严格执行安全限制——例如禁止从专用 Worker 内部创建 SharedWorker，且所有连接客户端必须拥有完全一致的协议、主机和端口。Servo 当前已通过 Web 平台测试（WPT）中关于 SharedWorker 初始化、MessagePort 通信及错误处理的核心用例，但私密浏览模式下的共享行为仍待完善。

更深层的意义在于：尽管 Servo 目前未被任何量产浏览器采用，其技术影响却持续存在。其部分布局与渲染代码曾融入 Firefox 的 Quantum 项目；其“Rust 优先”的工程路径也推动了业界对 Web 系统级编程安全性的重新思考。此次更新再次表明，Servo 仍是活跃的前沿试验场——目标不是取代 Chrome 或 Safari，而是探索如何借助现代语言特性和并发模型，重构浏览器底层架构。对关注引擎原理或 Rust 系统开发的工程师而言，Servo 依然提供着罕见的、可运行的实践参考。
