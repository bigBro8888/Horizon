西蒙·威利森发布 condense-json 1.0 版本，支持 JSON 字符串去重压缩

新闻时间: 2026-08-03T04:44:33.535978+00:00 · 来源: rss

西蒙·威利森正式发布了 condense-json 1.0 版本——一个轻量级 Python 库，专为通过字符串片段去重来缩减 JSON 数据体积而设计。它不进行字节级压缩或编码，而是语义层面操作：识别重复出现的子字符串（例如常见短语或标识符），并用用户提供的替换映射表将其替换成带 $r 标记的紧凑结构。该方法保持 JSON 合法性，同时实现可预测、可逆的空间节省，特别适用于存储大量相似 JSON 文档的场景，比如日志记录或大语言模型交互轨迹。

此次发布标志着该项目已稳定运行一年半以上。威利森表示，他正更自信地为经过充分验证的小型工具标注 1.0 版本。该库已被集成进他的 LLM 命令行工具中，用于压缩 SQLite 日志中生成的 AI 模型交互记录。一份近期提交（PR #1586）展示了 condense-json 如何在不改变应用逻辑或查询方式的前提下显著降低存储开销。

使用方式简洁明了：传入一个 JSON 对象和一个替换映射字典（例如 "1": "with foxes in it"）。condense_json() 函数会递归扫描所有字符串，将匹配项替换为类似 {"$r": ["This is a string ", {"$": "1"}]} 的结构，并返回合法 JSON。其配套函数 uncondense_json() 则能借助同一映射表完整还原原始数据——零信息丢失、无歧义。与 gzip 等通用压缩不同，该方法输出仍为人可读、可 diff，非常适合带版本控制的日志或调试场景。

尽管并非算法压缩领域的突破，condense-json 却精准填补了一个实用空白：开发者需要一种确定性强、可检查、可逆的 JSON 缩减方案，且无需引入二进制格式或外部依赖。它与 Python 的字符串驻留（interning）或 JVM 的 G1 字符串去重（GC 特性）等底层机制互补，但通过显式、声明式的替换模型实现了跨环境、跨语言的便携性。
