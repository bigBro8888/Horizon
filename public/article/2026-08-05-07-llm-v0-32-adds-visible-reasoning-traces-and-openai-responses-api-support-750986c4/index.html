LLM v0.32发布：支持推理过程可视化与OpenAI Responses API

新闻时间: 2026-08-05T04:26:40.718603+00:00 · 来源: rss

LLM 命令行工具作者 Simon Willison 发布了 v0.32 版本，这是该项目自发布以来最重要的一次更新。新版本首次让大模型的推理过程“看得见”：当用户调用 GPT-5.6 Luna 或 Claude Sonnet-5 等具备推理能力的模型时，LLM 会将中间思考步骤（如“分析鹈鹕特征”）实时输出到标准错误流（stderr），而最终答案仍走标准输出（stdout）——既方便调试，又不破坏管道命令（如 | grep 或重定向）的可用性。

本次更新还原生支持 OpenAI 于 2025 年 3 月推出的 Responses API，该接口比传统 Chat Completions 更强大，支持多轮状态保持和内置工具调用。用户现在只需一条命令即可触发远程代码执行或网络搜索，例如 llm --tool CodeInterpreter '显示当前 Python 和 SQLite 版本'，无需本地环境配置。

工具能力不再局限于 OpenAI：新版 llm-anthropic 插件新增 WebSearch、WebFetch、CodeExecution 及 AnthropicMCP 支持。后者可让 Claude 直接调用外部服务，比如通过一行命令向作者部署的 Datasette MCP 接口发起请求，查询数据库表 blog_blogmark 的行数——模型真正成了可编程的 API 客户端。

日志系统也全面重构：采用内容寻址（content-addressable）的 SQLite 存储，确保相同输入总生成相同记录 ID，提升可复现性与查询效率；同时新增 llm openai endpoint 命令，支持一键对接任意兼容 OpenAI 协议的服务（如 Ollama、LM Studio），且默认不记录临时请求，兼顾灵活性与隐私。
