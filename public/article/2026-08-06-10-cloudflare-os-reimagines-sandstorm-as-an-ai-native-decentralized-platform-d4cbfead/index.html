Cloudflare OS 重构 Sandstorm：面向 AI 代理与去中心化应用的新平台

新闻时间: 2026-08-06T04:28:17.718341+00:00 · 来源: hackernews

Cloudflare 正式推出 Cloudflare OS —— 这并非传统意义上的操作系统，而是一个完全基于 Cloudflare Workers 构建的开源平台，旨在将十年前的 Sandstorm.io 项目带入 AI 时代。该项目由 Sandstorm 创始人兼 Cloudflare Workers 主要架构师 Kenton Varda 宣布，目标是重拾 Sandstorm 的核心理念：用户自主拥有、本地托管、默认隐私优先的应用生态，但全部用边缘计算、AI 推理和去中心化协作模式重新实现。

与 Sandstorm 原始设计（在个人服务器上以沙箱方式运行完整堆栈应用）不同，Cloudflare OS 将执行层移至边缘：应用与智能体以轻量级 Workers 形式运行，数据则存于 R2、Durable Objects 或 KV 中。关键突破在于深度集成 Workers AI —— 开发者无需管理 GPU 或容量规划，即可让智能体实时推理、获取上下文、调用 API 并协调工作流。

该平台架构刻意规避中心化协调：每个用户运行自己的实例，不依赖共享数据库或统一后端服务。数据同步通过无冲突复制数据类型（CRDT）、消息传递或用户主导的合并来实现，延续了 Sandstorm 倡导的数据主权原则。这种设计也自然引发工程层面的疑问：当多个智能体或分支同时修改同一数据结构时，如何保障一致性？更新语义又该如何定义？这些正是早期社区讨论中反复出现的技术关切。

Cloudflare OS 的真正差异点，不仅在于技术选型，更在于其抽象范式：它将‘工作’本身作为头等概念，把智能体、界面、数据与权限打包为可移植、可版本化、可共享的单元。这些单元可在个人或团队域内自由部署、复刻与组合。尽管目前仍处于预览阶段，但它标志着一个明确趋势：从封闭 SaaS 服务转向开发者与用户可控的环境，其中 AI 智能体是协作参与者，而非黑盒服务。
