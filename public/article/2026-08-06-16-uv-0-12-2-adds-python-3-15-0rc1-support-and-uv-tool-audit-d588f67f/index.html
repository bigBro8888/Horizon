uv 0.12.2 支持 Python 3.15.0rc1 并新增工具审计功能

新闻时间: 2026-08-06T04:28:18.428526+00:00 · 来源: github

Astral-sh 发布了 uv 0.12.2，这是其基于 Rust 构建的超快 Python 包管理器的最新补丁版本。该版本于 2026 年 8 月 5 日发布，在兼容性、诊断能力、性能和配置灵活性方面均有实质性提升，且完全向后兼容。它进一步巩固了 uv 作为 pip 和 Poetry 高性能替代方案的地位，尤其适合重视构建速度与可复现性的开发团队。

最具前瞻性的更新是原生支持 CPython 3.15.0rc1——Python 下一主要版本的首个发布候选版，以及稳定维护版 CPython 3.14.7。这种提前适配帮助开发者尽早验证项目兼容性，规避升级风险。同样值得关注的是全新命令 uv tool audit（预览功能），它可扫描已安装的工具（如 black 或 ruff）及其依赖树中的已知安全漏洞，功能上对标 pip-audit，但深度集成于 uv 工具链中。

性能优化虽不显眼却效果显著：uv.lock 文件解析（构建可复现性的关键环节）在轮子包（wheel）和源码分发包（sdist）两类条目上均提速；从分发 URL 中提取文件名的速度也得到提升。底层改进包括减少字节码编译过程中的冗余文件系统元数据查询，并在构建源码分发包时复用已有元数据。这些优化虽单次仅节省毫秒级时间，但在 CI 流水线或大型单体仓库中会显著累积。

新配置选项增强了运维灵活性：环境变量 UV_RUN_RLIMIT_NOFILE 允许用户为 uv run 启动的进程设置更高的文件描述符限制，缓解高并发场景下的资源瓶颈；预览功能 cache-physical-space 则在清理缓存时报告实际释放的物理磁盘空间，便于可观测性与自动化管理。其他修复包括提升旧版缓存工件的兼容性，以及更精准地控制工作区成员的依赖组同步行为。文档更新则优化了 GitHub Actions 工作流示例和 Docker 集成指南，降低了新用户的上手门槛。
