Claude Fable 5 从四年前推文一键生成可玩浣熊劫案游戏

新闻时间: 2026-08-06T04:28:17.431620+00:00 · 来源: rss

四年前，开发者西蒙·威利森（Simon Willison）曾用 GPT-3 和 DALL-E 构思了一款名为《浣熊劫案》的游戏：两只浣熊潜行穿过未来感街道，准备实施盗窃。如今，在该推文发布四周年之际，他用 Anthropic 新发布的 Claude Fable 5 重访这一构想——将当年的截图直接输入 Claude Code 网页版，指令其“把这条推文变成一个可玩的网页游戏”。几分钟内，AI 自动生成了 HTML、CSS 和 JavaScript 代码，提交至 GitHub，并产出一个完整可运行的浏览器游戏：玩家操控浣熊跳跃、蹲伏、收集金币，同时躲避巡逻机器人和警报。

这款《浣熊劫案》是一款轻量但功能完备的 2D 平台游戏，纯前端实现，不依赖任何框架或后端服务。它包含响应式操作、音效反馈、胜负判定机制，甚至用内联 SVG 绘制了浣熊角色与建筑。威利森全程未写一行代码：仅创建 GitHub 仓库、启动 Claude Code 网页版、输入原始推文截图，其余均由 AI 自主完成。

此次实验的关键不在于“AI 能写代码”，而在于其端到端的自主性。不同于以往需反复调试的人机协作模式，Fable 5 表现出真正的代理能力：它解析模糊的图文输入、规划文件结构、编写并调试逻辑、自动提交 Git 分支、甚至主动启用 GitHub Pages 部署——全程无需人工干预。威利森仅手动配置一次 GitHub Pages，后续所有版本迭代、分支管理、增量更新均由 AI 独立完成。

这当然不是一款商业级游戏，但它确实是一个可分享、可运行、带源码的完整网页应用，由一条四年前的社交媒体碎片在不到一小时内变为现实。项目开源、演示在线、视频详录了 AI 的推理过程：它主动拒绝过度工程化的方案，选择 Canvas 而非 DOM 动画以保障性能，并为自身代码添加注释。对关注智能体开发演进的工程师而言，《浣熊劫案》的意义不在画面或玩法深度，而在于它标志着“意图到交付”的可信度迈上新台阶：一个模糊、怀旧的想法，真正变成了可交付的软件。
