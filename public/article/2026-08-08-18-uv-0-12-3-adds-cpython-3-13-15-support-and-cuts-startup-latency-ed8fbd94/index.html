uv 0.12.3 支持 Python 3.13.15 并显著降低启动延迟

新闻时间: 2026-08-08T02:59:47.745909+00:00 · 来源: github

Astral 正式发布 uv 0.12.3 — 这是一次聚焦实际痛点的高质量补丁更新，进一步巩固了 uv 作为当前最快 Python 包管理器的地位。该版本于 2026 年 8 月 7 日发布，为大型代码库、CI/CD 流水线和自动化脚本开发者带来了切实可感的改进。最值得关注的是，uv 现已正式支持 CPython 3.13.15，与 Python 官方最新稳定版几乎同步适配，体现了其与上游生态的紧密协同。

性能优化是本次更新的核心亮点。在 Linux 系统上，uv 将工作区缓存初始化提前至多线程启动之前，显著降低了命令首次执行的延迟。它还绕过了依赖 /proc 文件系统读取的慢速 Python 解释器发现逻辑——这对容器环境或高负载服务器尤为关键。在依赖解析环节，uv 针对存在大量版本冲突的项目跳过了开销高昂的“范围补集”计算，提速明显，且不牺牲解析准确性。

开发者体验与工具链集成也得到增强。uv cache size 新增 --output-format 参数，支持自动识别、人类可读或原始字节三种输出格式，便于脚本解析与监控告警。uv workspace metadata 则改用流式 JSON 输出，不再将整个元数据结构一次性加载进内存，大幅缓解大型单体仓库（monorepo）的内存压力。配合 --quiet 使用时，诊断信息被静默，但结构化 JSON 保持完整——这一修复对依赖 JSON 输出的 CI 工具链至关重要。

文档层面同样注重实用性：GitHub Actions 发布示例已加入 PEP 740 可信签名实践，并限制仅匹配 Python 版本标签；CLI 示例中也修正了参数名（如将 --python-pin 更新为 --pin-python）。这些细节看似微小，却能有效降低团队在生产环境中落地 uv 的门槛。随着 uv 在 Rust 生态中持续替代 pip、pip-tools 和 pipx，像 0.12.3 这样的迭代正印证着：稳健的渐进式优化，比激进的架构变更更能长期提升开发效率。
