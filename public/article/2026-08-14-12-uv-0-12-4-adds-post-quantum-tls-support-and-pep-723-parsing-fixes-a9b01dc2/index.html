uv 0.12.4 支持后量子TLS并改进PEP 723解析

新闻时间: 2026-08-14T03:28:58.233860+00:00 · 来源: github

Python 工具链迎来一次低调却重要的安全升级：uv 0.12.4 于 2026 年 8 月 13 日发布，首次引入实验性后量子 TLS 密钥交换支持——这是为应对未来量子计算机破解现有加密算法而迈出的前瞻性一步。该功能目前为可选启用，但体现了行业对密码敏捷性的日益重视：安全加固不应等到威胁出现才启动。

在安全性之外，开发者体验也得到细致打磨。uv 现在能更稳健地解析 PEP 723 内联脚本元数据，例如准确报错带尾随空格的结束标签；同时改进了 PEP 508 依赖声明的解析逻辑，支持 >= 3.5.* 这类非标准通配符版本写法，兼容更多现实项目中的不规范用例。

性能优化同样扎实：解析器在处理大量不可用包版本时，会自动合并版本范围间隙，加快依赖求解；Simple API（PyPI 的包索引接口）解析则跳过中间 JSON 步骤，直接反序列化原始元数据，显著减少开销。这些改进在 CI 流水线或资源受限环境中尤为明显。

新发布的预览功能聚焦高级工作流：uv check --no-install-project 允许仅校验依赖而不构建或安装项目，适合预提交钩子或隔离式静态检查；uv check 调用 ty 子进程时，现在会继承 uv 的颜色、进度条和静默模式设置，输出更统一、更易集成。

修复项覆盖多个边缘场景：Windows 上虚拟环境正确使用 pythonw.exe 启动 GUI 应用；.venv 目录损坏时 uv lock 不再中断；解释器缓存严格隔离不同 PYTHONEXECUTABLE 或 __PYVENV_LAUNCHER__ 环境变量的复用；甚至 uv add 更新依赖时也能保留末尾的行内注释。这些细节共同构成专业级 CLI 工具应有的可靠性。

安装方式保持极简：一行 shell 或 PowerShell 命令即可下载预编译二进制文件，支持 macOS（Intel/Apple Silicon）、Windows（x86-64/ARM64）及主流 Linux 架构。无需编译，校验 SHA256 后即可使用。随着 uv 在 pip 和 Poetry 替代方案中地位日益稳固，这类务实、稳健的小版本更新，正悄然定义现代 Python 开发的底层体验标准。
