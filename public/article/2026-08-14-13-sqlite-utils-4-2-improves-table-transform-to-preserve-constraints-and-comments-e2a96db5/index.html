sqlite-utils 4.2增强表转换功能，完整保留约束与列注释

新闻时间: 2026-08-14T03:28:57.121166+00:00 · 来源: rss

sqlite-utils 4.2 于2026年8月发布，大幅升级了其核心功能 table.transform()——这是该库用于安全修改 SQLite 表结构的关键机制。SQLite 原生的 ALTER TABLE 仅支持有限操作（如重命名列或添加新列），而 table.transform() 则通过新建表、迁移数据、替换旧表的方式实现复杂变更，例如修改列类型、调整列顺序或删除列。但过去这一过程常丢失 CHECK 约束、UNIQUE 约束及列级 SQL 注释等细节。

4.2 版本彻底解决了这一问题。现在调用 transform() 时，不仅能保留主键和索引，还能完整继承 CHECK 约束（如 age > 0）、多列联合唯一约束，甚至通过 COMMENT ON COLUMN 添加的列说明文字。这对依赖数据库层保障数据完整性的生产应用意义重大——规则不再仅靠应用代码维护，而是随表结构一同迁移。

本版本还新增了实用的元数据查询能力。开发者可通过 table.checks 等属性直接获取已定义的 CHECK 约束列表，包括原始 SQL 表达式和所涉列名。此前，提取 CHECK 约束只能手动解析 CREATE TABLE 的 DDL 输出，既脆弱又易出错；如今这一痛点被正式解决。

此次发布也体现了活跃的社区协作，五位贡献者参与了功能开发、测试与文档完善。值得一提的是，发布后不久发现一个导致崩溃的严重 Bug（#842），团队迅速在数日内推出 4.2.1 版本修复。这种快速响应印证了 sqlite-utils 已成为稳定可靠的生产级工具，而非临时脚本。对使用 SQLite 构建轻量应用、数据分析脚本或 Jupyter 笔记本的 Python 开发者而言，这次更新让表结构演进更安全、更透明、更易维护。
