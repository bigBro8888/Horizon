uv 0.12.5发布：支持Python 3.12.14并自动屏蔽错误中的凭据

新闻时间: 2026-08-15T02:18:21.705255+00:00 · 来源: github

Astral-sh 开发的 uv — 这款以 Rust 编写、号称“极快”的 Python 包管理器 — 于 2026 年 8 月 14 日发布了 0.12.5 版本。此次补丁更新虽非大版本跃迁，却在解释器管理、安全防护和软件供应链工具链三方面带来了切实改进，进一步印证了 uv 作为 pip 和 virtualenv 替代方案的生产就绪度。

版本支持范围得到扩展：正式兼容 CPython 3.10.21、3.11.16 和 3.12.14 — 让开发者能及时使用最新稳定补丁版 Python，无需再因工具链滞后而等待。更值得注意的是，当多个 Python 解释器优先级相同时，uv 现在会默认选择更新、更标准的版本（例如排除调试版或自由线程版），除非用户显式指定。这一逻辑优化虽小，却显著降低了误用非标环境的风险。

安全性方面有明确增强：uv 现在会在报错信息中自动屏蔽私有索引 URL 中嵌入的用户名和密码等凭据。过去这类敏感信息可能意外暴露在终端输出或 CI 日志中，构成潜在泄露风险。该机制同样适用于格式错误的可编辑安装依赖（editable requirements），此时错误提示也更简洁清晰，便于快速定位 PEP 508 格式问题。

两项预览功能值得关注：其一是“按名称选择索引”（需启用 index-by-name 预览开关），允许团队通过别名（如 --index internal-pypi）而非冗长 URL 引用配置好的包源，大幅提升大型 Python 工程的可读性与可维护性；其二是 CycloneDX SBOM 导出默认包含分发包的下载地址与哈希值，为合规审计与漏洞扫描提供更完整的物料清单。此外，一个修复项确保 PEP 723 内联脚本中相对路径的包索引能正确基于脚本所在目录解析，解决了长期存在的边缘场景缺陷。
