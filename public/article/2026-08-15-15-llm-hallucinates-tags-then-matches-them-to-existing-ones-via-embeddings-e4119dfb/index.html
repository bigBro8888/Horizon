大模型先幻觉生成标签再用向量匹配现有标签

新闻时间: 2026-08-15T02:18:20.855725+00:00 · 来源: rss

许多博主和内容创作者长期面临一个棘手却未被很好解决的问题：如何为多年积累的未打标文章批量、一致地添加标签。Simon Willison（Datasette 创作者，以务实工具主义著称）近期转发了 Doug Turnbull 提出的一种巧妙解法。与其硬让大模型在 1,856 个现有博客标签中做精确匹配——这极易超出上下文长度限制并导致错误——不如反其道而行之：先让大模型“凭空想象”出语义上合理的分类路径，且完全不接触真实标签列表。

这种“幻觉式分类”是刻意开放的。提示词通过真实样例（如“家具 / 客厅家具 / 咖啡桌与边几 / 咖啡桌”）教会模型标签应有的层级结构与领域风格，而非具体词汇。面对查询“棕色咖啡桌”，模型可能输出“家具 / 客厅 / 咖啡桌 / 木纹饰面”——哪怕“木纹饰面”根本不在现有标签库中。这恰恰是设计所需：幻觉结果只需语义贴近，无需真实存在。

第二步才是关键：向量检索。将全部 1,856 个真实标签（例如用 Sentence-BERT 或 OpenAI 的 text-embedding-3-small）编码为向量；同时将幻觉生成的字符串也嵌入同一空间。再通过最近邻搜索，找出语义上最接近的真实标签——比如“家具 / 客厅家具 / 咖啡桌与边几 / 咖啡桌”。这一设计彻底解耦了提示工程与标签数量，绕开了 token 限制与僵化的精确匹配逻辑。

该方法的实用性在于对“不完美”的天然包容：幻觉结果不必真实，只需有代表性；也无需昂贵的微调或定制分类器，仅靠提示工程加现成嵌入模型即可实现。尽管原文在示例中途截断，但其核心思路对内容管理系统、技术文档站、数字档案等场景极具延展性——尤其适合那些标签体系随时间自然演化的项目。它追求的不是绝对正确，而是可扩展、符合人类直觉的近似。
