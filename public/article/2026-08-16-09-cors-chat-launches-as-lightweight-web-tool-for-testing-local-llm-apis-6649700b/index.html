CORS Chat上线：轻量级网页工具测试本地大模型API

新闻时间: 2026-08-16T02:33:37.403968+00:00 · 来源: rss

CORS Chat 是一款新发布的开源网页工具，专为简化本地大语言模型（LLM）聊天接口的开发与调试而设计，尤其适用于通过 LM Studio 等工具在个人电脑上运行的模型。该工具由开发者 Simon Willison 一天内完成，提供简洁、无需安装的浏览器界面，可直接与符合 OpenAI 格式的 API 接口通信，绕过前端代码调用本地服务时常遇到的跨域限制。

其核心价值在于对 CORS（跨域资源共享）机制的实用支持。当开发者在本地运行 LLM（例如在 LM Studio 中加载 Qwen 3.8 27B 模型）时，通常需启用 --cors 参数，才能让网页应用发起请求。CORS Chat 假设这一配置已就绪，转而专注提升交互体验：支持发送消息、流式查看响应，并将对话完整保存在浏览器本地存储中，全程无需后端服务。

一个突出亮点是 SVG 的实时渲染能力。当模型在流式输出中逐 token 生成 SVG 代码时，CORS Chat 能即时识别 <svg> 标签，并在完整响应到达前就开始渐进式渲染图像。这对需要早期视觉反馈的多模态或代码生成任务尤为实用。截图中可见，用户仅输入“画五个相交的正方形”，模型便生成了五种颜色、半透明、带白边、按不同角度旋转的正方形，在深蓝背景上形成星爆效果。

CORS Chat 兼容所有 OpenAI 格式接口，包括启用 --cors 的 LM Studio、OpenRouter，以及 vLLM、Cloudflare Workers AI 等推理服务器。对话自动保存于浏览器，支持一键导出为 JSON 用于分享或复现。它不需注册、无遥测、无服务端组件——纯前端 JavaScript 实现，因此启动快、隐私强、易于自托管或二次开发。对于构建 LLM 应用的前端工程师，或在本地快速验证模型行为的研究者，它精准填补了“本地模型”与“浏览器交互”之间长期存在的小而关键的空白。
