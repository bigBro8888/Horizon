llm 0.33 支持按次指定 API 密钥并升级至 httpx2

新闻时间: 2026-08-23T02:36:19.354790+00:00 · 来源: rss

llm 是一款广受欢迎的开源命令行工具，用于在终端中调用大语言模型。其最新版本 0.33 发布，为嵌入向量（embeddings）、模型配置和 HTTP 基础设施等场景带来了多项实用改进。

最值得关注的是，llm embed 和 llm embed-multi 命令现在支持 --key 参数，允许用户为单次嵌入调用单独指定 API 密钥，而无需修改全局设置或模型级密钥。这一设计与 llm 中常规 LLM 模型的密钥处理方式保持一致。在代码层面，Python 接口（如 EmbeddingModel.embed()、Collection.embed() 等）也新增了 key= 参数，将密钥直接透传给插件，同时通过兼容性回退机制确保旧插件（依赖 self.key）仍可正常运行。

该版本还更新了底层 HTTP 栈：将 OpenAI Python SDK 升级至 3.x，并将 HTTP 客户端从 httpx 切换为 httpx2——这是由 Pydantic 维护的新一代 HTTP 库，支持 HTTP/2、同步/异步双模式，并内置命令行客户端。此次切换提升了连接复用效率与流式响应稳定性，对高频嵌入任务尤为关键。

其他改进包括模板组合功能：llm prompt 的 -t 或 --template 参数现在支持重复使用，可叠加多个模板。例如，先保存一个含模型与参数的模板（如 gpt-5.6-luna 配 reasoning_effort high），再保存一个任务提示（如“生成一只骑自行车的鹈鹕 SVG”），最后通过 llm -t lhigh -t pelican 一键组合执行。此外，支持 OpenAI Responses API 的推理型模型新增 reasoning_summary 选项（可选 auto、concise 或 detailed），便于在测试不同响应 API 实现时灵活控制输出详略程度。

尽管不是颠覆性更新，llm 0.33 展现了稳健演进的设计哲学：统一接口抽象、增强生态兼容性、降低日常开发摩擦。它是一次安静却切实提升开发者体验的重要迭代。
