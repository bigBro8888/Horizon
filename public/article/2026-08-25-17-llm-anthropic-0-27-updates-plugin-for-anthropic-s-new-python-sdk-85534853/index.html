llm-anthropic 0.27 版本适配 Anthropic 新版 Python SDK

新闻时间: 2026-08-25T02:22:44.623900+00:00 · 来源: rss

llm-anthropic 插件是 LLM 命令行工具的轻量扩展，用于连接 Anthropic 的 Claude 系列大模型。最新发布的 0.27 版本，核心目标是适配 Anthropic 全新推出的 Python SDK v1.0.0。该 SDK 进行了一次底层重构：将 HTTP 客户端从 httpx 切换为新一代的 httpx2。这一变动与 OpenAI 在两周前发布的 Python SDK v3.0.0 中的同类升级高度一致。

这不是一个新增功能的版本，而是一次关键的兼容性维护更新。任何使用 llm 命令行工具调用 Anthropic 模型的开发者——比如通过 llm -m claude-sonnet-5 '告诉我萝卜的冷知识' 这类命令进行本地实验——若不升级，将面临导入失败或运行时异常。

项目维护者 Simon Willison 采用了一种高效务实的方式完成迁移：他将 Anthropic 官方提供的 MIGRATION.md 迁移指南喂给 Claude Code（基于 Fable 5 模型），并提示其“升级至 anthropic>=1，并让所有测试通过”。最终生成的 PR #84 展现了借助 AI 辅助完成技术债清理的现代开发实践。

httpx2 并非简单改名：它是由 Pydantic 团队主导重构的新一代 HTTP 客户端，强化了类型安全、异步体验和与 Pydantic V2 等现代 Python 工具链的协同能力。终端用户虽看不到界面变化，但底层稳定性、错误提示清晰度和长期可维护性均得到提升。

对开发者而言，结论明确：若你正在使用 llm-anthropic 插件，现在必须升级到 0.27 版本，才能继续对接 Anthropic 最新版 SDK。在 SDK 快速迭代的生态中，这类及时、平滑的依赖升级，正是保障命令行 AI 工具持续可用的关键一环。
