uv 0.12.6 发布：缓存清理优化与工作区元数据同步新功能

新闻时间: 2026-08-26T02:38:28.489403+00:00 · 来源: github

Astral-sh 团队于 2026 年 8 月 25 日发布了 uv 0.12.6 版本，这是其用 Rust 编写的高性能 Python 包管理器的一次常规维护更新。相比重大功能迭代，本次发布聚焦于稳定性、准确性和开发者体验的渐进式提升。用户升级后会发现缓存清理报告更精确、警告信息更克制、虚拟环境初始化和依赖解析中的边界情况处理更可靠。

性能方面，所有主流平台的预编译二进制文件（Linux x86-64/ARM64、Windows x86-64、macOS ARM64）均已启用基于实际使用场景训练的“配置文件引导优化”（PGO），使 uv sync 和 uv pip compile 等高频操作响应更快。命令行输出也更友好：小于 1 KiB 的字节数不再显示小数部分，避免冗余信息干扰。

两个预览功能值得关注：uv workspace metadata --sync --exact 可精准移除工作区中未被当前解析方案选中的包，强化可重现性；而新引入的 artifact-hash-filtering 预览功能，则让 uv pip compile --generate-hashes 在生成哈希时真正尊重 --only-binary 和 --no-binary 参数——此前该命令会为所有候选包生成哈希，即使其中部分包根本不会被安装。这标志着 uv 正在向更精细的构件（artifact）溯源与构建一致性方向演进。

修复项覆盖广泛：从修复 RISC-V 架构下 TLS 引发的段错误，到确保 40 位 Git 提交哈希严格匹配目标对象（而非误判为同名分支）；从正确保留带环境标记的递归 extras 依赖关系，到在工具升级时复用已配置的索引认证凭据。项目还升级了最低 Rust 支持版本至 1.96，并新增 Python 3.15 发布候选版的 Docker 镜像，体现对上游语言生态的主动适配。单个改动虽不震撼，但整体显著提升了 uv 在生产环境中的稳健性与专业度。
