Asahi Linux 实现苹果 M3 Mac 的 USB 3.0 和雷电支持

新闻时间: 2026-08-27T11:10:18.562904+00:00 · 来源: hackernews

Asahi Linux 在开源硬件适配领域取得重大突破：现已为苹果 M3 系列 Mac（包括 M3、M3 Pro 和 M3 Max）完整启用 USB 3.0 与雷电（Thunderbolt）接口。这一成果并非依赖苹果官方文档或技术支持，而是通过逆向工程解析其专有电源管理控制器 ACE3，并实现其在 SPMI（系统电源管理接口）总线上的驱动支持。

开发重点在于理解 ACE3 —— 这颗负责协调 USB、雷电及 PCIe 子系统供电状态的关键芯片 —— 如何与整个 SoC 协同工作。开发者 mildsunrise 和 chaos_princess 发现，ACE3 的寄存器布局与前代 CD3217 控制器高度一致，仅通信方式由 I²C 改为 SPMI。这一关键洞察使团队得以复用既有驱动逻辑，并为 Linux 内核新增完整的 SPMI 总线支持，最终产出稳定、可合入主线的代码。

这不仅关乎“能否插上设备”：它标志着 Asahi Linux 底层固件与电源管理栈的实质性成熟。USB 3.0 和雷电的可靠运行，需精确协同时钟门控、链路训练、唤醒信号与温控节流——全部由 ACE3 统一调度。驱动就绪意味着系统能正确进入和退出低功耗状态，降低待机功耗并提升整体稳定性。对用户而言，M3 版 MacBook Pro 已从“Linux 实验品”转变为可日常使用的主力设备。

尽管电池续航与 GPU 加速仍在持续优化中，但此次更新首次实现了 M3 平台所有主要 I/O 子系统的 Linux 全功能支持。它更传递出一个明确信号：苹果封闭的自研芯片生态并非不可逾越的壁垒，而是一个可通过开放协作、逐层破解的工程挑战——从一行寄存器定义开始。
