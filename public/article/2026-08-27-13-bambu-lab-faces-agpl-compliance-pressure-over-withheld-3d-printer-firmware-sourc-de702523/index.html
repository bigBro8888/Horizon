Bambu Lab因未公开联网固件源码被指违反AGPL协议

新闻时间: 2026-08-27T11:10:18.562957+00:00 · 来源: hackernews

Bambu Lab 是一家总部位于中国的桌面级高速3D打印机制造商，其 X1C 和 P2S 等机型广受用户欢迎，但目前正因涉嫌违反《Affero通用公共许可证》（AGPL）而持续受到社区质疑。争议焦点在于其联网固件组件——尤其是支撑云连接、远程监控和 Bambu Studio 集成的部分——据信使用了 AGPL 授权的开源代码，却始终未按要求向公众开放完整可构建的源代码。据 LWN.net 订阅报道，这一合规缺口已持续存在于多个固件版本中，包括截至2025年12月发布的最新版，而 AGPL 明确规定：任何通过网络提供服务的修改版软件，必须向所有网络用户公开对应源码。

AGPL 比标准 GPL 更严格：它不仅覆盖分发行为，还延伸至“网络即服务”场景。当用户通过局域网 API 或云端接口与 Bambu 打印机交互时，即触发该许可证的源码公开义务。尽管 Bambu 在官网维基和固件下载页公布了二进制文件与更新日志，但并未提供包含网络栈、引导程序或 Web 界面等关键模块的完整、可编译源码仓库——而这些模块已知依赖 AGPL 授权库。

作为回应，开源社区已开发出切实可行的替代方案。一种主流做法是完全禁用云连接，改用 OrcaSlicer 的纯局域网模式，并搭配 GitHub 上开源的逆向工程网络插件。多名用户证实，该组合能彻底阻断打印机与 Bambu 服务器的所有通信（经网络抓包验证），同时保留本地切片与控制功能。另有声音建议诉诸法律手段，例如在美国国际贸易法院提起诉讼，利用其对进口商品发布临时禁令的权力施加商业压力。

这场争议也折射出全球自由软件合规执行的深层困境。评论者指出，在缺乏国内 GPL/AGPL 执法机制的背景下，追究中国厂商责任尤为困难。但倡导者强调，唯有依靠社区工具开发、公开曝光与协同法律行动，才能真正捍卫著佐权许可的精神内核。对依赖 Bambu 硬件的创客与专业用户而言，此事提醒我们：“开源”标签不等于合规实践——用户的自主权，终究建立在持续监督而非厂商承诺之上。
