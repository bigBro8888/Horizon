py-evoFE 0.3.0发布：用遗传算法自动构建表格特征

新闻时间: 2026-08-28T12:44:25.690643+00:00 · 来源: reddit

一款名为 py-evoFE 的新开源 Python 库正式发布，旨在解决表格机器学习中最顽固的瓶颈之一：人工特征工程。该库以 MIT 协议开源，当前版本为 0.3.0，采用遗传编程——一种受生物进化启发的搜索方法——自动发现高价值特征变换，例如嵌套分组聚合、非线性比值、目标编码以及流形投影。与暴力式特征生成器不同（后者会一次性生成数千个冗余或共线特征），py-evoFE 通过迭代的选择、交叉与变异，在模型性能和内置复杂度惩罚的双重引导下，演化出简洁、可解释的特征配方。

该库在速度与可扩展性上做了深度优化。它基于 Polars 和 PyArrow 实现向量化、内存高效的计算，并引入多项创新机制：矩阵哈希与近邻缓存技术，避免在交叉验证各折中重复执行昂贵操作（如 UMAP 嵌入或 k-NN 查找）；多保真度筛选机制先用快速低精度代理评估候选方案，再对优质个体启用全保真评估；岛模型并行搜索则将演化任务分布到多个种群中，支持环形、环面、网格等多种拓扑结构及吉布斯迁移策略。演化结束后，系统还会基于各岛最优模型的留出预测结果，采用 Caruana 风格集成进一步提升鲁棒性，且不增加推理延迟。

对已熟悉 scikit-learn 的用户而言，集成极为平滑。py-evoFE 完整实现了 fit、transform、predict 和 predict_proba 等标准接口，可直接嵌入 sklearn.pipeline.Pipeline 或参与 GridSearchCV 超参调优。一大亮点是交互式 HTML 回放查看器：调用 view(evo.get_recipe()) 即可生成一个零依赖的本地网页，动态展示最优特征配方在各代演化中的演变过程。在乳腺癌数据集上的示例仅需不到 20 行代码，即可完成从 Polars DataFrame 输入到 LightGBM 预测的全流程。

py-evoFE 的真正优势不仅在于“自动化”，更在于“有原则的自动化”。它融合了层级链式构造（已演化特征可作为后续变换的输入）、40 多种领域感知型变换器（包括 MinHash 字符串相似度、适用于混合数据的 FAMD、Genie 聚类等），并与现代表格工具链紧密协同，成功弥合了表达力强的特征合成与生产级效率之间的鸿沟。对于 Kaggle 参赛者、MLOps 工程师，以及厌倦了手写比值特征或调试易泄漏的 group-by 逻辑的研究人员，py-evoFE 提供了一种严谨、可组合、完全开源的新选择。
