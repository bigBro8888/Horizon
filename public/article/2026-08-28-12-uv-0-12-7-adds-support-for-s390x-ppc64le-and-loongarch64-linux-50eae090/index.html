uv 0.12.7 正式支持 s390x、ppc64le 和龙芯架构 Linux

新闻时间: 2026-08-28T12:44:26.068450+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 正式发布 0.12.7 版本，显著提升了跨平台兼容性、安全性和缓存可靠性。该版本于 2026 年 8 月 27 日发布，首次原生支持三种长期缺乏主流工具链覆盖的 Linux 架构：IBM 主机常用的 s390x、高性能计算与嵌入式领域常见的 PowerPC 64 位小端（ppc64le），以及中国龙芯科技自主研发的 64 位指令集架构 LoongArch64。此举为金融、政务及国产化信创环境中的 Python 应用部署扫清了关键障碍。

在架构扩展之外，uv 对 Azure Storage 的集成也更稳健：当通过 UV_AZURE_ENDPOINT_URL 配置私有存储端点时，若匿名访问被拒绝，uv 将自动使用用户配置的凭证重试下载，无需手动干预。同时，两个关键可靠性修复同步落地：源码包在校验哈希不匹配时，会在解压和写入缓存前直接拒绝；升级同版本 Python 时，uv 也能正确替换已安装的托管 Python 解释器，避免残留旧二进制文件。

另一个值得关注的预览功能是“内容寻址缓存”（content-addressed cache）。启用 --preview 标志后，uv 将基于轮子（wheel）解压后目录的实际内容生成哈希，而非仅依赖文件名或 URL。这意味着不同来源但内容完全一致的包，将共享同一份缓存副本，大幅提升磁盘空间利用率与构建可重现性，尤其适用于持续集成和多租户场景。

尽管只是小版本迭代，0.12.7 却体现了 uv 从“快”走向“稳”与“广”的演进重心——它不仅提供 powerpc64le-unknown-linux-gnu 和 loongarch64-unknown-linux-gnu 等完整预编译二进制包，更在底层加固了校验逻辑与认证流程。对于运行在混合基础设施（从公有云虚拟机到大型机）上的 Python 工程团队而言，这次更新悄然消除了多个长期存在的适配痛点。
