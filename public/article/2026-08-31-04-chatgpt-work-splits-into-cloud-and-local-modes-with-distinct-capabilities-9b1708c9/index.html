ChatGPT Work 实质上是云版与本地版两个产品

新闻时间: 2026-08-31T07:00:59.690322+00:00 · 来源: rss

OpenAI 于2026年7月9日发布 ChatGPT Work，但其本质并非单一新产品，而是两种截然不同的实现方式：一种完全运行在云端，另一种则直接在用户本地设备上执行。西蒙·威利森（Simon Willison）的深度分析厘清了这一被 OpenAI 品牌策略刻意模糊的关键区分。云版 Work 可通过 chatgpt.com 网站或移动应用访问，提供多项高级智能体功能，包括联网代码执行、无头 Chrome 浏览器、跨会话持久化共享文件系统，以及定时提示自动化。它还支持精细的模型选择：用户可选用 GPT-5.6 的 Sol、Luna 或 Terra 模型，并调节推理强度（从“轻量”到“超强度”）——这些能力在标准 Chat 界面中均不可用。

本地版 Work 仅存在于新版 ChatGPT 桌面应用中（即原 Codex 应用），可直接读取本地文件、访问文件夹、运行系统程序，全程无需上传数据至云端。威利森指出，它更像是“面向非开发者重新设计界面的 Codex”，保留了原有智能体的自主性，却弱化了开发者专属风格。值得注意的是，两个版本均需订阅 $20/月及以上套餐；免费用户及 $8/月的 ChatGPT Go 用户完全无法使用。

Work 与普通 Chat 的真正差异，远不止官方宣传中“回答问题”与“完成任务”的模糊划分，而在于底层架构：完整的浏览器沙箱、跨会话持久文件系统、以及可同时调用 Sol/Luna/Terra 的子智能体协同机制。这些能力支撑起全新工作流——例如自动填写政府电子旅行授权表（调用本地护照文件），或结合 Gmail 连接实时撰写带附件的邮件回复。但强大功能也伴随代价：Cloudflare 直接屏蔽 Work 的浏览器模式；安全研究者更警告，将不可信网页内容、私有文件访问权限与外发通信通道三者结合，构成高风险攻击面。

此次发布折射出企业级 AI 的激烈竞争格局。随着 Anthropic 的 Claude Cowork 迅速占领企业市场——成功之至，微软甚至直接授权并白标为 Copilot Cowork——OpenAI 显然加速推出 Work 以重夺企业心智份额。然而混乱仍在：命名混淆技术边界、文档语焉不详、连资深用户也难以判断何时该用 Chat、何时该用 Work。对企业而言，采用决策已不再仅关乎功能，更取决于风险偏好：是选择云端便利，还是本地可控；是拥抱自动化效率，还是坚持审计可追溯。
