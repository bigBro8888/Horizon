Python 3.15.0 第二版候选发布，十月正式版将至

新闻时间: 2026-09-02T05:47:14.737734+00:00 · 来源: rss

Python 开发团队已发布 Python 3.15.0 第二版候选版本（RC2），这是十月份正式稳定版发布前的最后一个预发布版本。Python 3.14 和 3.15 的发布经理 Hugo van Kemenade 明确表示，从 RC2 到最终版之间，仅允许合并经过严格审查、明确属于修复性缺陷的代码变更。这一冻结策略意味着语言核心功能与行为已基本锁定，RC2 成为开发者测试工具、库和持续集成流程最可靠的预览版本。

此阶段对第三方包维护者尤为关键。公告中特别强调：维护者应立即用 Python 3.15 测试自身项目，并尽快在 PyPI 上发布兼容的二进制轮子（wheels）。重要的是，所有基于 3.15 任一候选版本（包括 RC2）构建的轮子，均可直接用于最终发布的 3.15.0 及后续所有 3.15.x 小版本——该兼容性保证大幅降低了早期适配门槛，助力整个生态更快就绪。

对于使用 GitHub Actions 的用户，RC2 尚未进入其默认 Python 版本列表，但可通过 setup-python 动作配合两个参数启用：allow-prereleases: true 和 check-latest: true。配置后，测试矩阵中写入 "3.15" 即可自动依次拉取 RC1、RC2，最终无缝切换至正式版——无需手动更新配置，显著简化多版本验证流程。

技术作者 Simon Willison 分享了实际测试结果：他的项目 Datasette 和 sqlite-utils 已顺利通过 RC2 测试；而 LLM 项目则暂时受阻，正等待 scikit-learn 发布其 3.15 兼容轮子。这种依赖链问题恰恰说明 RC 阶段的价值：它能提前暴露集成瓶颈，将潜在的上线故障转化为可协作解决的前置任务。归根结底，RC2 不仅是一个技术节点，更是一场全生态协同的“彩排”——而这场彩排的成功，取决于维护者是否在此刻行动。
