Jujutsu 创始人马丁·厄格伦加入开源 GitHub 替代项目 ERSC

新闻时间: 2026-09-02T05:47:15.248252+00:00 · 来源: hackernews

Jujutsu 的创建者马丁·厄格伦（Martin Ågren）已正式加入东河源码控制（East River Source Control，简称 ERSC）——一个旨在重塑协作式软件开发的开源 GitHub 替代项目。该消息发布于 ERSC 官方博客，标志着两大前沿开源项目的深度协同：一方致力于革新开发者在命令行中操作代码历史的方式，另一方则从底层重新设计协作式代码托管平台。

ERSC 定位为可自托管、可扩展、理念清晰的 GitHub 替代方案，目标并非简单复刻，而是将源码控制视为基础设施来系统性重构。其核心主张包括对冲突的一等公民支持、细粒度访问控制（ACL），以及在保持与 Git 仓库完全兼容的前提下，采用更富表现力的数据模型。随着厄格伦的加入，ERSC 不仅获得了深厚的版本控制系统（VCS）工程经验，更获得了直接参与下一代工具如何影响平台架构设计的机会——尤其是在分支管理、合并策略、历史重写和代码评审等关键环节。

Jujutsu 的独特之处在于，它将每一次操作——提交、变基、修正、甚至修改提交信息——都视为可逆的、有状态的操作，并持久化在不可变的增量数据库（delta DB）中。与 Git 中 git rebase -i 或 git reset --hard 等高风险命令不同，Jujutsu 允许用户无惧失误地回退：忘记推送、输错分支名或搞砸变基，只需一条 jj undo 即可恢复。正如一位早期用户所言，这种能力从根本上改变了工作流的安全边界。

这一动向发生在开发者对中心化代码托管平台日益审慎的背景下。尽管 GitHub 仍占主导地位，但厂商锁定、政策不透明及架构局限等问题，正推动社区重新关注自托管、由社区治理的替代方案。ERSC 并非孤例——Gitea、SourceHut 和 Codeberg 等项目各有所长——但其明确将 Jujutsu 的数据模型作为平台基石，暗示了一条独特路径：让版本控制系统与协作平台协同演进。这一愿景能否落地，最终取决于实际易用性、大规模场景下的性能表现，以及生态支持程度——而这些问题已在 Hacker News 上引发热烈讨论。
