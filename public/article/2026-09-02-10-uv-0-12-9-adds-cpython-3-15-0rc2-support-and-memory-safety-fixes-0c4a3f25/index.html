uv 0.12.9发布：支持CPython 3.15.0rc2并修复内存安全问题

新闻时间: 2026-09-02T05:47:15.710274+00:00 · 来源: github

Astral-sh 开发的超快 Python 包管理器 uv 正式发布 0.12.9 版本，率先支持即将发布的 CPython 3.15.0rc2 —— 这对希望提前验证兼容性的开发者和持续集成系统至关重要。除版本适配外，该版本新增两个命令行标志：--no-locked 和 --no-frozen，允许用户在单次执行中临时禁用由 UV_LOCKED 或 UV_FROZEN 环境变量启用的锁定模式，特别适用于自动化脚本调试或临时绕过锁文件约束的场景。

性能方面也有实质性提升：针对“冷安装”（即轮子包未缓存、需实时下载并解压）的场景，uv 现在能更快完成 wheel 安装。优化核心在于将每个 ZIP 轮子包的流式解压重构为单个阻塞任务，并在解压内部多个文件时复用内存缓冲区，显著降低内存分配开销，尤其利于 I/O 较慢的环境。

安全性同样得到加强：修复了 async_http_range_reader 库中一个潜在的内存安全问题——该库用于通过 HTTP 分段请求读取远程 wheel 的元数据（如 pyproject.toml），升级至 0.11.1 后可防止处理不可信 wheel 时发生不安全内存访问。其他加固措施还包括：在重试诊断日志中自动脱敏签名 URL 中的密钥；当重定向跨越认证域（包括同主机但协议变更，如 http → https）时，自动移除敏感请求头（如 Authorization）。

此外，uv 还修复了并发进程重复提取同一本地或源码构建 wheel 的问题，并确保 --locked、--check 等命令行参数始终优先于冲突的环境变量。所有主流平台（Apple Silicon / Intel macOS、x86/x64/ARM64 Windows、ARM64/PowerPC/x86 Linux）均提供预编译二进制包，仅需一行脚本即可安装。随着 uv 持续作为 pip 兼容、Rust 编写的现代替代方案走向成熟，0.12.9 这类更新再次印证其核心承诺：既要极致速度，也要生产级可靠性。
