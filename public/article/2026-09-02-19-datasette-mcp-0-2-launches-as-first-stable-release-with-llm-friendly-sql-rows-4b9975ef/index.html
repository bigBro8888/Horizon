datasette-mcp 0.2 正式发布：首版稳定版，SQL结果改用命名对象

新闻时间: 2026-09-02T05:47:14.737712+00:00 · 来源: rss

西蒙·威利森（Simon Willison）正式发布了 datasette-mcp 0.2 —— 这是该插件首个非 Alpha、可用于生产环境的稳定版本。它作为 Datasette 的扩展，将关系型数据库能力接入模型上下文协议（MCP），让大语言模型（LLM）能通过标准化方式调用数据库查询功能。安装后，任意 Datasette 实例都会自动暴露一个 /-/mcp 接口，变身成为可被 AI 应用发现和调用的 MCP 服务器。

本次更新最直观的改进在于 SQL 查询结果的返回格式。过去 execute_sql 工具返回的是位置数组，例如 ['Alice', 32, 'Engineer']，模型必须严格依赖列顺序来理解字段含义；现在每行数据都以带明确键名的 JSON 对象形式返回：{"name": "Alice", "age": 32, "role": "Engineer"}。这一改动直击实际痛点：能力较弱或提示鲁棒性不足的 LLM 容易混淆列与值的对应关系，导致推理错误或虚构输出。

与此同时，插件已升级依赖至 MCP Python SDK 2.1.1 版本，确保与最新协议规范兼容。0.2 版本标记为“稳定”，不仅代表技术就绪，更反映真实使用验证——作者明确表示已在自身工作流中“频繁使用”该插件，说明其已具备实际工程价值。

作为 Anthropic 于 2024 年底推出的开放标准，MCP 致力于统一 AI 系统连接外部工具的方式。而 datasette-mcp 正是这一生态中轻量务实的典范：它不另建服务、不重写数据库，而是复用 Datasette 原有优势——零配置 SQLite 托管、自动模式识别、内置 Web 界面——仅需一行配置即可赋予其 MCP 能力。

对深耕数据库与 LLM 协同开发的工程师而言，0.2 版并非炫技之作（无向量检索、无缓存层），却精准修复了一个关键接口断点：让数据库“说人话”，也让 LLM 更可靠地“听懂话”。这种不声张却扎实的可靠性，恰是基础设施类工具走向成熟的关键标志。
