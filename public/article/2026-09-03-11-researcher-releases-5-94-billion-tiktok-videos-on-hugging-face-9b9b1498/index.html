研究者将59.4亿条抖音视频公开发布至Hugging Face

新闻时间: 2026-09-03T05:45:03.041507+00:00 · 来源: reddit

网名为 /u/DataShack 的研究者发布了迄今规模最大的公开抖音（TikTok）数据集：包含59.4亿条视频记录和32.3亿个用户档案。该数据集已免费托管于 Hugging Face，名称为 kuben-developer/tiktok-videos-4b。与多数仅限学术合作或私下共享的社交平台数据集不同，此数据集完全开放——任何人皆可下载、在线浏览，或通过 Hugging Face 基于 Apache Arrow 的零拷贝流式 API 按需加载子集。

数据采集依赖一种多年前开发的移动端 API 逆向工程方法。作者指出，该技术利用了 TikTok 安卓与 iOS 应用中暴露的 24 个无需身份验证即可访问的私有接口。这种方式绕过了官方网页端与应用端的登录与限流机制，但明显违反 TikTok 的服务条款。作者坦承这一矛盾：虽然数据本身在技术上属于“公开可见”（例如未登录用户也能看到部分视频），但自动化批量抓取仍属违规行为。

除数据集外，作者还在 tiktok-api.seeksocial.io 发布了完整技术说明与文档。但全部爬虫代码并未开源，而是以小额费用形式提供。这种“方法透明 + 代码收费”的混合模式，正成为网络爬虫社区的一种新实践。数据不仅含视频 ID、时间戳、字幕等元信息，还涵盖关联账号、评论、话题标签及音频轨道，对多模态研究极具价值。

Reddit 讨论区迅速引发伦理争议。评论者就“是否应将数十亿条含人脸、声音与生活场景的用户生成内容无偿公开”展开激烈辩论：一方认为这是推动开放科学研究的关键资源；另一方则强调，大量视频来自设为“私密”的账号，而逆向 API 接口无视此类隐私设置，实质构成未经同意的大规模数据采集。也有观点指出其科研意义——如此规模的数据，可支撑短视频理解大模型训练、跨模态检索系统评测，或平台级行为建模等长期受限于数据匮乏的研究方向。
