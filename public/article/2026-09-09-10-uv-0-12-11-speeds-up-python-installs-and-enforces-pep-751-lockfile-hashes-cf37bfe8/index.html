uv 0.12.11 加速 Python 包安装并强化 pylock.toml 哈希校验

新闻时间: 2026-09-09T05:57:32.294555+00:00 · 来源: github

Astral.sh 发布了 uv 0.12.11 — 一次聚焦明确、影响显著的补丁更新，既提升了安装性能，又加强了锁文件的正确性保障。该版本于2026年9月8日发布，针对覆盖现有文件、合并已安装轮子（wheel）等高频场景进行了实测有效的加速。优化深入系统底层：例如，在原子化替换文件（硬链接、符号链接、reflink）时取消每个文件单独创建临时目录的开销；在本地 wheel 安装中，用定位式 ZIP 读取替代全局 ZIP 游标锁；并跨文件复用 ZIP 解析器与缓冲区。这些改动显著降低了 I/O 竞争和内存分配压力，对 CI 流水线和日常开发均有可感知提升。

在性能之外，uv 0.12.11 进一步落实 PEP 751 标准——这一旨在统一 Python 锁文件格式的新规范。当导出 pylock.toml 时，uv 现在会自动补全缺失的构件哈希值，确保每个 wheel 或源码包均附带经验证的 SHA256 哈希，满足规范核心要求。同时，若检测到哈希表为空，uv 将发出警告，提示此类锁文件将在未来版本中被拒绝——为团队预留迁移窗口。

本次更新还包含多项关键缺陷修复，增强安全性与健壮性。例如，uv 现在会在读取源码归档元数据或调用构建后端 之前，先依据 uv.lock 中记录的哈希值校验归档完整性，堵住潜在的未授权代码执行漏洞。哈希校验逻辑也扩展至严格版本钉选（===）场景，并支持在缺少本地版本哈希时，智能复用对应公开版本的哈希。其他改进包括：支持从 UNC 路径及 WSL 路径激活 PowerShell 虚拟环境、自动清理 .python-version 文件中的首尾空白字符，以及为 --no-sync 类操作静默虚拟环境不匹配警告。

作为基于 Rust 构建的 pip、pip-tools 和 virtualenv 替代方案，uv 始终致力于简化 Python 工具链而不牺牲精确性。其单个静态二进制文件支持 macOS（Intel/Apple Silicon）、Windows（x86/ARM64）和 Linux，且无需依赖 Python 运行时即可安装。0.12.11 再次印证：速度与安全并非权衡项，而是协同设计的目标。
