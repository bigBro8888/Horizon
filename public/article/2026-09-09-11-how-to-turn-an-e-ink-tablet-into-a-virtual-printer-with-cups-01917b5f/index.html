如何用CUPS将电子墨水平板变成虚拟打印机

新闻时间: 2026-09-09T05:57:31.956009+00:00 · 来源: hackernews

如果你的 reMarkable 或富士通 Quaderno 不只是一台手写笔记设备，而是一台真正可集成的‘打印机’呢？Nishant Joshi 发布的新教程就展示了如何做到这一点：不靠加装硬件，而是通过软件重配置。该指南详细说明了如何构建一个自定义 CUPS 后端，让电子墨水平板在 Linux 系统中表现为原生支持 IPP 协议的打印机。设置完成后，用户即可从任意应用程序（如 LibreOffice 或 Firefox）直接‘打印’PDF、网页或文档，内容会即时显示在电子墨水屏幕上。

其核心在于打通两个世界：已有数十年历史的 CUPS 打印架构，与专为阅读而非打印设计的现代电子墨水设备。CUPS（通用 Unix 打印系统）长期依赖‘后端程序’（backend）——即负责与物理设备通信的小型脚本。作者编写了一个轻量级后端（可用 Python 或 Shell 实现），用于截获打印任务，将其转为适配屏幕的位图格式，并通过 USB 或网络推送到平板的显示层。关键一步是让该后端声明自身符合 IPP 标准，明确通告所支持的纸张尺寸（例如 reMarkable 2 的 om_1404x1872）、输出纸盒和介质类型，从而避免桌面应用意外缩放或裁剪内容。

读者还将学到如何使用 IPP 命名规范（如 om_NNNmmxYYYmm）定义非标准纸张尺寸，通过精确匹配屏幕分辨率来规避自动缩放，并通过命令行或本地 Web 界面（localhost:631）配置 CUPS 打印队列。整个过程无需开发底层驱动，而是复用现有平板 API 和开源工具（如早期为富士通 Quaderno 开发的 dpt-rp1-cups）。

更深层看，这篇教程引发了一个关于‘打印’本质的思考：它早已不再局限于油墨与纸张，而是指以应用无关、可靠高效的方式，将排版完成的内容送达任一具备接收能力的显示终端。正如一位评论者幽默指出的那样，这相当于把平板变成了‘会响应打印指令的电子纸’。它虽无法替代激光打印机处理大批量输出，却精准填补了一个安静但日益增长的需求：零干扰、无分心、超长续航的文档审阅体验——就在你目光停留的地方。
