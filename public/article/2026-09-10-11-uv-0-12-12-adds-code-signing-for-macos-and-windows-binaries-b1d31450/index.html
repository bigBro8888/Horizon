uv 0.12.12 为 macOS 和 Windows 二进制文件启用代码签名

新闻时间: 2026-09-10T05:56:17.319276+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 正式发布 0.12.12 版本，显著提升了安全性与企业就绪能力。该版本于 2026 年 9 月 9 日发布，首次为所有 macOS 和 Windows 可执行文件启用官方代码签名——这一关键改进增强了用户信任、改善了与企业安全策略的兼容性，并大幅减少了杀毒软件和系统防护机制（如 macOS Gatekeeper）的误报。

在 macOS 上，uv 二进制文件现使用 Apple 开发者 ID 证书签名，并提交至苹果官方进行公证（notarization）。这意味着系统可验证软件来源可信且未被篡改，满足许多企业在大规模部署 Mac 软件时的强制性安全要求。在 Windows 上，uv 二进制文件则采用 Azure Artifact Signing 签发的时间戳 Authenticode 签名，使 Windows Defender SmartScreen 和企业终端防护工具能基于发布者身份可靠识别并放行该工具。

除安全增强外，本次更新还修复了一个影响依赖锁定的关键问题：exclude-newer 参数在 lockfile 中现能正确排除上传时间晚于指定截止日期的包，并在生成需求哈希（requirement hashes）时保持一致。这保障了构建结果的可重现性，避免因意外引入新版依赖而导致 CI/CD 流水线或合规环境中出现不一致行为。

该版本支持全平台架构，包括 Apple Silicon 与 Intel macOS、x86/x64/ARM64 Windows，以及多种 Linux 架构（x86_64、aarch64、RISC-V、s390x、ppc64le）。安装方式保持简洁，支持 Shell 或 PowerShell 一键脚本，所有二进制文件均附带 SHA256 校验和。尽管 Linux 版本暂未签名（符合主流开源分发惯例），但 macOS 和 Windows 的签名填补了此前生产环境部署中的关键信任空白。

随着 uv 在速度与可靠性上持续超越 pip 和 Poetry，此次更新标志着其正从“开发者喜爱的快工具”转向“企业可信赖的基础设施工具”——代码签名正是连接开发效率与安全合规的关键桥梁。
