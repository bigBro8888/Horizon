任意 Nix 软件包，一键在浏览器中启动完整 Linux 虚拟机

新闻时间: 2026-09-11T05:55:50.998429+00:00 · 来源: rss

想象一下：点击一个链接，瞬间就在你的浏览器里启动一台功能完整的 x86_64 Linux 虚拟机——拥有真正的 Shell、文件系统和网络能力，无需服务器、无需安装、无需本地配置。这已不再是设想，而是 trynix.dev 实现的现实。

trynix.dev 的核心是 qemu-wasm——一个将 QEMU 系统模拟器实验性移植到 WebAssembly 的项目。它不是轻量级沙箱或 JavaScript 解释器，而是真正的虚拟化：在浏览器中启动精简 Linux 内核，初始化用户空间，并原生运行为 x86_64 编译的 Nix 构建二进制文件。自 2011 年以来 nixpkgs 中的所有软件包（包括 python3@3.6.2 这类 2017 年的老版本）都可通过 URL 直接访问：只需在域名后加上 ?pkg=软件包@版本号，点击“加载”即可。

它的意义远超技术演示。开发者 Farid Zakaria 将其称为自己“Nix 工作的集大成之作”，实至名归。一个典型应用是 Pull Request 审查：GitHub Action trynix-preview 会自动在 PR 下评论一条链接，让审查者直接在浏览器中运行该 PR 构建出的完整环境。无需克隆代码、无需本地构建、也无需信任远程基础设施。

尤为关键的是其安全模型：所有执行完全在客户端 WebAssembly 沙箱内完成，除非显式启用，否则默认无网络访问。这从根本上规避了传统 CI 预览环境常见的供应链风险，实现了跨时间、跨机器的可复现、确定性构建评估。同时彻底摆脱了维护长期预览服务或临时云实例的运维负担。

尽管性能尚不及本地运行（启动耗时约 5–20 秒，取决于包大小与浏览器），但这项工程成就毋庸置疑。它将成熟的 Nix 可复现构建能力，与前沿的 WebAssembly 虚拟化技术深度融合，重新定义了“即时开发环境”的含义——这不是概念验证，而是一个真正可用、面向未来的开发范式基础。
