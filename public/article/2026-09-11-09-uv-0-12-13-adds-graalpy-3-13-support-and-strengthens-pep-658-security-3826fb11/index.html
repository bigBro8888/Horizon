uv 0.12.13 支持 GraalPy 3.13 并强化 PEP 658 元数据校验

新闻时间: 2026-09-11T05:55:52.165716+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 正式发布 0.12.13 版本，带来运行时兼容性、安全性和性能三方面的实质性改进。该版本于 2026 年 9 月 10 日发布，延续了 uv 以速度与正确性为核心的设计哲学，在不引入破坏性变更的前提下，提升了依赖解析效率、元数据校验强度和跨平台鲁棒性。

本次更新最重要的新增支持是 GraalPy 3.13.0——基于 GraalVM 的 Python 3.13 兼容实现。开发者现在可直接用 uv 管理 GraalPy 项目，享受其 JIT 编译加速与 JVM 生态集成优势。由于 GraalPy 在字节码格式、路径解析和环境识别上与 CPython 存在差异，uv 此次专门增强了运行时检测逻辑，确保虚拟环境创建与包安装行为准确无误。

安全性方面，uv 首次完整实现了 PEP 658 元数据侧载文件（.metadata）的哈希校验机制。当工具为节省带宽仅下载独立元数据而非完整 wheel 时，uv 会严格比对索引中声明的哈希值与实际下载内容，防止因元数据被篡改或损坏导致依赖解析错误——这一实践此前在 pip 中长期缺失，构成潜在供应链风险。

性能优化体现在依赖解析阶段：uv 现在能复用直接 URL 中嵌入的哈希（如 #sha256=...），在已有独立元数据的前提下跳过整轮 wheel 下载，显著减少网络 I/O。Windows 平台则修复了启动器在 Nano Server（轻量级容器化 Windows）上的兼容问题，并通过内存中编辑入口点资源的方式，降低杀毒软件误报率。

这些改动印证了 uv 的演进策略：不堆砌炫目功能，而是专注夯实基础——让每一次依赖安装更可信、更快、更适配真实生产环境，从云原生容器到 GraalVM 高性能场景皆可受益。
