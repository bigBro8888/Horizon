uv 0.12.15修复安装命令验证错误并提升冷缓存解析速度

新闻时间: 2026-09-16T05:58:30.539295+00:00 · 来源: github

Python 工具生态迎来一次虽小却实用的更新：uv 0.12.15 正式发布。该补丁版本于 2026 年 9 月 15 日上线，主要修复了上一版 0.12.14 中引入的一个关键可用性问题——该问题意外拒绝了多种合法且常见的 pip install 命令。例如，在基于 python:* 的 Docker 镜像中执行 uv pip install --system，或使用 uv pip install --target . 将包安装到当前目录时，用户会收到验证失败报错，尽管这些用法完全符合规范且被广泛采用。

这一问题源于一个过于严格的符号链接（symlink）检查逻辑：它错误地将所有指向符号链接的安装路径判定为不安全，而这类路径在容器环境和 CI 流水线中极为常见。本次更新通过回退该检查逻辑，既恢复了兼容性，又未牺牲安全性。此外，版本还带来一项实际性能优化：当 uv 在“冷缓存”状态下运行（例如首次在新 CI 节点或全新开发机上解析依赖）时，HTTP 缓存重新验证与元数据写入过程现在采用批量操作，显著加快了冷启动速度。

虽然这不是一个功能丰富的里程碑版本，但它体现了 uv 日趋成熟的迭代节奏：快速响应用户反馈、专注可靠性与性能平衡。对于在 CI/CD 或容器构建中重度依赖 uv 的团队而言，0.12.15 消除了近期出现的操作障碍，并悄然提升了首次运行效率。安装方式保持简洁，支持一键 Shell 或 PowerShell 脚本安装；预编译二进制文件覆盖全部主流平台，包括 Apple Silicon、x86_64 和 ARM64 Linux、Windows（x86/x64/ARM64），甚至 RISC-V、s390x 和 PowerPC 等小众架构。

uv 是一款用 Rust 编写的高性能 Python 包与项目管理工具，目标是成为 pip 和 venv 的现代化替代方案。它提供统一接口，支持依赖安装、虚拟环境管理、Python 版本安装、脚本执行、锁文件生成等功能。随着其在基础设施密集型工作流中的普及，这类精准、务实的补丁更新正变得越来越重要。
