Datasette 1.0a40 支持插件后台任务并升级至 httpx2

新闻时间: 2026-09-17T06:07:10.782822+00:00 · 来源: rss

Datasette 是一款广受欢迎的开源工具，用于通过 Web API 和交互式界面探索、分析和发布结构化数据。其最新发布的 1.0a40 版本是迈向备受期待的 1.0 正式版的关键 Alpha 里程碑。此次更新不仅强化了底层架构，还新增了多项实用功能，体现了项目团队为最终稳定版所做的集中工程投入。

最值得关注的新特性是插件对后台任务的原生支持。开发者现在可通过 datasette.add_background_task() 方法启动长时间运行的操作——例如批量数据导入、异步调用外部 API 或定期刷新缓存——而不会阻塞主应用线程。这为构建更强大的插件生态铺平了道路，例如近期在 NICAR 2024 上亮相的 datasette-extract 插件，就利用 GPT-4 模型将非结构化文本自动转为结构化表格数据。

此外，Datasette 将内部 HTTP 客户端从旧版 httpx 升级至新一代 httpx2 库。该库同时支持同步与异步调用，兼容 HTTP/1.1 和 HTTP/2，并在可靠性与性能上均有提升。这一变更直接惠及依赖 datasette.client.get() 发起内部请求的插件作者，例如在查询执行过程中拉取远程数据集或调用第三方服务。

安全性持续受到重视：1.0a40 包含了此前 0.65.5 版本中已修复的同一安全补丁，解决了用户输入处理环节的潜在风险。除此之外，该版本还整合了数十项 Bug 修复——多数源于近期围绕 1.0 正式版开展的问题梳理工作——显著提升了 SQLite 元数据探测、模板渲染及命令行工具等核心模块的稳定性。尽管仍属预发布阶段，1.0a40 已清晰展现出向生产环境就绪迈进的成熟度。
