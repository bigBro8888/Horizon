uv 0.12.16 增加轮子哈希校验和 macOS 平台标记支持

新闻时间: 2026-09-18T05:53:30.646381+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 正式发布 0.12.16 版本，为依赖解析的可靠性与安全性带来实质性增强。该补丁版本于 2026 年 9 月 17 日发布，重点不在新增功能，而在于加固核心行为——尤其是下载完整性校验、平台适配精度以及错误处理韧性。

最值得关注的改进是：uv 现在会对从 PyPI 或私有索引下载的 wheel 和源码包（source distributions）执行哈希校验。它会比对索引提供的加密哈希值（如 SHA-256），确认文件未被篡改或损坏后再安装。此外，build-constraint-dependencies 中声明的构建依赖也可附带哈希值，将校验范围延伸至构建时工具链。这一变化直击 Python 生态长期存在的供应链安全痛点。

针对 macOS 用户，uv 现在能正确解析 platform_release 标记（例如 macosx_14_0 或 macosx_15_8），并在评估锁文件中的 required-environments 时应用这些信息。这意味着为 macOS Sequoia 15.8 或 Golden Gate 27.0 构建的 wheel 将被精准匹配，避免运行时兼容性问题。同时，Git URL 解析逻辑也更健壮：当锁文件中出现不支持的协议（如格式错误的 git+ssh://）时，uv 不再崩溃，而是提前报错。

其他预览功能提升了实用性：uv check 可在非 uv 管理项目中运行，并支持 --python 参数指定 Python 版本；uv upgrade 现在尊重配置的索引凭证；lock-without-metadata 已扩展至所有依赖类型，同时为远程 URL 依赖保留 package.metadata，以支持离线验证。修复项涵盖敏感信息脱敏（如 Azure 共享访问签名）、缓存复用前校验归档大小、以及对畸形代理/索引 URL 的容错处理——全部用清晰的配置错误替代了程序崩溃。整体来看，uv 0.12.16 展现了一款成熟工具对安全性、跨平台一致性和生产环境稳定性的持续承诺。
