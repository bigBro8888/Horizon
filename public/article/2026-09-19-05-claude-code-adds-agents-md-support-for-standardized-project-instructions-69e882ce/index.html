Claude Code 支持 AGENTS.md 标准化项目指令

新闻时间: 2026-09-19T05:49:40.950868+00:00 · 来源: rss

Anthropic 工程师 Thariq Shihipar 宣布，Claude Code v2.1.277 版本正式原生支持 AGENTS.md — 这是一种轻量、开源的 Markdown 格式，已被超过 6 万个开源项目用于向 AI 编程助手提供项目指引。当用户在 Claude Code 中打开一个代码库时，工具会优先查找传统的 CLAUDE.md 配置文件；若未找到，则自动回退至读取 AGENTS.md。这一改动显著提升了项目级 AI 行为的可移植性与跨工具兼容性——因为 AGENTS.md 已被 Cursor、Continue.dev 等主流 AI 编程工具广泛采用。

该功能基于 Claude Code 即将推出的“mods”（模块）系统构建：这是一种可组合、可复用的扩展机制，用于定制助手理解上下文、生成输出或与代码交互的方式。AGENTS.md 支持作为内置 mod 随版本默认启用，无需手动安装；同时，开发者也可基于 GitHub 上公开的参考实现进行二次开发、定制或替换。该仓库不仅包含 AGENTS.md 模块，还涵盖数十种其他模块，覆盖专业技能、MCP 服务器、CLI 工具集成及会话连续性等场景。

这一更新的意义不仅在于新增一项功能，更在于其开放协作的设计理念：通过采纳社区共建标准，而非绑定私有格式。AGENTS.md 是由开发者推动的规范，明确定义了 # 项目背景、# 当前任务、# 代码库结构图 等语义区块。这使团队在引入新 AI 工具时无需重复编写说明文档，真正实现“一份文档，人机共用”。

对开发者而言，效果立竿见影：只需在任意代码库根目录放入 AGENTS.md 文件，Claude Code 即可自动理解项目的编码规范、架构决策和正在进行的任务，无需重新训练或手动配置模型。随着生态演进，类似 AGENTS.md 的跨工具通用规范有望进一步减少碎片化，加速 AI 辅助编程在真实工程场景中的落地。
