datasette-auth-github 发布 1.0 版，修复移动端会话过早失效问题

新闻时间: 2026-09-20T06:11:05.465363+00:00 · 来源: rss

西蒙·威利森（Simon Willison）正式发布了 datasette-auth-github 1.0 版本——这一里程碑标志着该广受欢迎的 Datasette 插件已具备生产就绪能力。此次发布并非仅具象征意义：它包含一项关键修复，解决了认证 Cookie 生命周期过短的问题，尤其改善了 Safari 移动版等浏览器上的会话持久性。威利森在自己的公开演示站点 agent.datasette.io 上使用该插件时发现了这一问题：用户频繁被意外登出，iOS 设备上尤为明显。根本原因在于 Set-Cookie 响应头中缺失 Max-Age 属性——导致 Cookie 默认为“会话级”，一旦 Mobile Safari 主动结束其内部会话（该行为比桌面浏览器更激进），登录状态即刻丢失。

这项修复已在 GitHub Issue #80 中完成，确保认证 Cookie 按预设时长持续有效，而非任由浏览器随意清除。此外，1.0 版本也体现了整体成熟度：该插件已持续维护多年，同时兼容 Datasette 0.65.x 稳定系列与 1.0 alpha 系列，并经过跨版本兼容性测试。威利森特别指出，他正有意识地将稳定、经充分测试的插件提升至 1.0 版本——这比长期停留在 0.x 阶段更符合开源项目的实际演进逻辑。

对于在真实场景中部署 Datasette 的开发者而言——尤其是构建需身份验证的数据看板或内部工具时——本次更新显著提升了系统可靠性与用户体验。它也契合现代 Web 最佳实践：MDN 与 RFC 标准明确推荐使用 Max-Age（相对秒数）而非旧式 Expires（绝对时间戳），因其更不易出错，且当两者共存时具有更高优先级。尽管代码改动微小，但对移动优先部署的影响却十分显著。

此次发布凸显了一个事实：HTTP 协议中看似微小的细节（如 Cookie 过期机制）可能在不同平台间造成巨大体验落差。它也是开源项目审慎维护的典范：精准识别平台特异性痛点、干净利落地修复、并郑重标记为稳定版本。随着 Datasette 自身也正迈向 1.0（近期已发布含安全补丁的 1.0a39 等 alpha 版本），此类生态插件的成熟，正不断夯实整个框架在生产环境中的可信度。
