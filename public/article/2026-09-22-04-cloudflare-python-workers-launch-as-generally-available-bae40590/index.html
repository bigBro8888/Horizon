Cloudflare Python Workers 正式全面开放

新闻时间: 2026-09-22T06:10:08.124247+00:00 · 来源: rss

Cloudflare 正式宣布 Python Workers 全面开放（GA），结束为期两年的预览阶段。开发者现在可以将生产级 Python 代码直接部署到 Cloudflare 的边缘网络，无需管理服务器、容器或虚拟机。这并非传统意义上的 Python 运行方式：Cloudflare 实际上是通过 Pyodide 将 Python 编译为 WebAssembly，并在 workerd —— 一个基于 V8、原生支持 JavaScript 和 WebAssembly 的高性能运行时中执行。

这一技术架构既新颖又务实。Pyodide 是一个成熟的面向浏览器和 Node.js 的 Python 发行版，内置了 CPython 解释器及 NumPy、SciPy 等科学计算库。Cloudflare 借此避免自研 Python 解释器，而是将 Pyodide 深度集成进 workerd，从而实现毫秒级冷启动与全球边缘节点的一致行为。该方案绕开了跨平台 Python 二进制分发的复杂性，同时保留了标准库大部分功能和生态兼容性。

但 WebAssembly 沙箱也带来切实限制。官方文档明确指出，Python 的 multiprocessing 和 threading 模块完全不可用——并非受限，而是根本无法运行。这是因为当前 WebAssembly 缺乏操作系统级线程与进程隔离能力。这意味着 CPU 密集型并行任务和传统并发 I/O 模式无法按预期工作；开发者需转向 asyncio 等异步 I/O 方式，并采用无状态、短生命周期的请求处理模型——这虽符合 Serverless 最佳实践，却要求对许多现有 Python 应用进行重构。

本地开发体验同样令人印象深刻：pywrangler 命令行工具（以 workers-py 名称发布于 PyPI）可在本地完整模拟生产环境——包括在原生 workerd 二进制中运行 Pyodide + WebAssembly。在 macOS ARM64 上，该二进制体积达 123MB，存放于 node_modules 目录下，体现了高保真模拟与工具体积之间的权衡。此次发布还凸显了 Cloudflare 对上游开源项目的深度投入：官方公告由 Pyodide 核心维护者 Gyeongjae Choi 和 Hood Chatham 共同署名——表明其投资已超越基础设施层，延伸至 Python 生态底层。

对 Python 开发者而言，GA 版本显著降低了使用边缘计算的门槛——不再需要将业务逻辑重写为 JavaScript 或 Rust，即可享受低延迟、全球分布式执行的优势。它虽不能替代所有 Python 场景，却为数据转换、API 网关、机器学习推理前置处理及轻量后端服务等场景开辟了新路径，让代码真正运行在离用户最近的地方。
