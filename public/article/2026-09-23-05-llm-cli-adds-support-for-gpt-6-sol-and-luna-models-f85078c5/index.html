LLM命令行工具支持GPT-6 Sol与Luna模型

新闻时间: 2026-09-23T05:56:01.182193+00:00 · 来源: rss

西蒙·威利森（Simon Willison）发布了 llm 命令行工具的 0.36 版本——这是一款广受欢迎的开源工具，用于与数十种大语言模型交互，涵盖 OpenAI、Anthropic、Google Gemini，以及本地运行的 Mistral、Gemma 等模型。本次更新不仅包含多项细节优化，更带来一项关键进展：正式集成 OpenAI 最新发布的两个模型——gpt-6-sol 和 gpt-6-luna。根据 OpenAI 官方数小时前发布的公告，这两个模型已真实上线，正通过 GitHub Copilot 和 OpenAI API 向开发者开放；其中 Sol 侧重复杂推理能力，Luna 则专为低延迟、高吞吐场景优化。

这一集成并非简单添加名称。llm 工具将它们作为原生支持模型，用户可直接执行 llm -m gpt-6-sol '...' 或启动交互式对话 llm chat -m gpt-6-luna。更重要的是，v0.36 引入了一项新架构机制：模型插件现在可通过设置 supports_conversation = False 明确声明“不支持多轮对话”。首个采用该机制的是 llm-typesafe 插件，它封装了 TypeSafe AI 的分类模型（如判断“是否明确要求退款”），这类模型本质是单次判断任务。当用户试图用此类模型开启 llm chat 会话时，工具会在启动前直接拒绝，避免隐性失败或误导性输出。

此外，v0.36 还提升了开发者体验：llm logs 输出中的推理链（reasoning traces）现已默认包裹在 HTML <details><summary> 折叠标签中，大幅改善长日志的可读性。版本还包含五位新贡献者提交的多个 Bug 修复，反映出项目社区持续扩大。

此次发布尤为值得关注，在于其时效性与真实性。gpt-6-sol 和 gpt-6-luna 的文档链接直指 OpenAI 官网 API 页面和定价说明，证实其非传闻而是已商用模型。对依赖 llm 构建工作流的开发者而言，这意味着无需等待官方 SDK 更新，即可立即调用最新能力；也印证了 llm 工具始终紧密追踪上游 API 演进——这是其在快速迭代的 AI 生态中保持竞争力的关键优势。
