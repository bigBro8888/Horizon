uv 0.12.18发布：支持JSON输出、安全检查模式和更快的可编辑轮子构建

新闻时间: 2026-09-23T05:56:02.211599+00:00 · 来源: github

Astral 公司发布了 uv 0.12.18 版本——这款以极速著称的 Python 包安装器与依赖解析器迎来一次务实而重要的更新。该版本于 2026 年 9 月 22 日发布，虽为补丁版本，却集中增强了自动化友好性、构建可靠性与跨平台健壮性，特别适合持续集成（CI/CD）流程、IDE 插件开发以及大规模团队落地使用。

最实用的新功能当属 --output-format json 和 --check 标志。JSON 输出现已支持 uv pip install 和 uv pip sync 命令，并兼容 --dry-run 和 --check 模式，便于脚本解析与工具链集成。而 --check 模式则允许用户在不修改环境的前提下，精确预览即将安装或卸载的包列表——这是自动化部署中至关重要的安全确认机制。这些改进让 uv 在保持超高速的同时，更贴近生产环境对确定性的严苛要求。

底层构建逻辑也更加稳健。uv 现在能准确识别 PEP 517 构建钩子（如 get_requires_for_build_wheel）中的失败原因，这对使用 setuptools、hatchling 等现代构建后端的项目至关重要。另一项预览功能 --preview-features build-dependency-check 可在禁用构建隔离时提前验证构建依赖，避免编译中途因缺失依赖而崩溃。性能方面也有明显提升：可编辑轮子（editable wheel）的生成速度加快，原理是跳过临时轮子的压缩步骤——这一优化虽小，却显著缩短了本地开发迭代周期。

修复的缺陷同样值得关注：uv 现已正确处理不同 Python ABI 轮子标签（如 stable-ABI 与 generic）的兼容性判断；在 uv add 或 uv remove 等操作意外中断时，能自动恢复项目文件、脚本及锁文件；还主动拒绝可能导致路径遍历风险的 Windows 绝对路径归一化行为。此外，它能正确解析含查询参数（如 ?v=1.2）的 URL，并为 BSD 和 Haiku 系统生成准确的小写平台标签。整体来看，uv 正从“快”走向“快且可靠”。
