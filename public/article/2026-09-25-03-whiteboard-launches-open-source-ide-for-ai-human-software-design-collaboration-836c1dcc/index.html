Whiteboard开源IDE发布：支持人类与AI协同进行可视化软件设计

新闻时间: 2026-09-25T06:08:33.874846+00:00 · 来源: hackernews

Whiteboard 是一款由 Y Combinator W26 孵化团队开发的全新开源桌面 IDE，旨在将面对面白板讨论的清晰度与共识感，带入当今以 AI 辅助为核心的软件开发流程。该工具由前技术负责人 Sid、Alex、Ketan 和 Milan 共同打造，提供一个共享可视化画布，让开发者与 AI 代理（如 Claude Code）能共同绘制系统架构图、追踪执行路径并记录关键决策——而不仅限于编写代码。与传统编辑器不同，Whiteboard 在高层设计与底层实现之间架起桥梁：点击序列图或实体关系图中的任意元素，即可直接跳转至对应源码文件，并原生支持 VS Code 级别的语言服务（LSP）和快捷键，这得益于其底层基于开源的 Code OSS 构建。

该应用直面当前智能编码中的三大痛点。第一，它内置一个用 Rust 编写的语义化差异查看器，可过滤噪音：自动折叠单元测试新增、将大型函数摘要为伪代码，并仅高亮抽象语法树（AST）层面真正有意义的变更；所有规则均可通过 WebAssembly 插件系统自定义。第二，它集成“决策日志”功能，帮助开发者追溯 AI 代理如何理解需求、在哪些环节自主做出设计选择。第三，它深度对接大模型工具链：AI 代理通过 Claude Agent SDK 实时在画布上绘图、标注与更新，将原本黑箱化的 AI 输出转化为可审计、可导航的设计资产。

Salesforce 和 Modal 等公司的工程团队已将其用于架构评审与规格级变更验证。典型工作流是：先让 AI 代理生成原型及配套 Whiteboard 会话，再同步审查代码与可视化推理过程。它也易于与其他工具组合使用——例如搭配 Greptile：自动化审查器处理小范围改动，而需人工判断的复杂变更则升级至 Whiteboard 协作会话。团队明确指出，其设计初衷正是对抗“认知债务”：即当 PR 不断合入却缺乏共享上下文时，代码交付速度与人类理解能力之间的鸿沟日益扩大。

Whiteboard 当前以 MIT 许可证开源，支持 macOS、Windows 和 Linux 桌面平台（已澄清早期社区关于仅支持 macOS 的误解）。核心功能永久免费且完全可本地部署；未来将推出托管式 Web 版本，面向企业团队提供多人评审、轨迹存储与集中会话管理等功能。其核心理念始终如一：所有功能必须可在本地运行、可扩展，并通过 WASM 插件系统支持自定义差异规则、可视化渲染器与追踪集成。
