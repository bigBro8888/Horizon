uv 0.12.19 支持 PyPy 3.11/3.12 和 GraalPy 3.13

新闻时间: 2026-09-25T06:08:34.711328+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 正式发布 0.12.19 版本，这是其作为 pip 替代方案快速演进过程中的又一重要更新。该版本于 2026 年 9 月 24 日发布，新增对多种 Python 实现的支持、优化错误提示，并引入两项面向未来的实验性功能。

最实用的改进之一是正式支持 PyPy 3.11.16 和 3.12.14 —— 这是当前最新稳定版的 JIT 编译型 Python 实现，以长期运行程序的高性能著称。uv 同时也支持 GraalPy 3.13.0（构建版本 25.4.4），即 Oracle 基于 GraalVM 开发的 Python 运行时，适用于多语言集成与原生镜像编译场景。这意味着使用非 CPython 解释器的开发者，也能享受 uv 的极致速度——在部分场景下比 pip 快达百倍——用于依赖解析、安装和发布。

用户体验方面也有提升：uv publish 命令现在会在错误信息中用反引号格式化上传 URL，便于复制调试。多个关键缺陷得到修复，例如保留直接 URL 依赖中的签名查询参数（避免无谓重装）、正确识别 ===1 等版本约束符以匹配已安装包。Rust API 层面恢复了 FlatDistributions 的公开导出，方便下游依赖解析器复用 uv 的分发逻辑。

两项预览功能则指向更长远的设计目标。build-lazy-imports 标志可在 CPython 3.15+ 上启用构建后端钩子的懒加载导入，降低大型项目的启动开销；resolution-inputs 则让锁文件更智能——自动省略未使用的解析参数（如 --python-version），并在检查锁文件是否过期时忽略这些参数的变更，显著提升多目标环境下的维护效率。两项功能均为手动启用，默认关闭，体现 uv 对新特性落地的审慎态度。

在 Astral（Ruff 团队）持续推动下，uv 正逐步整合 Python 工具链：单个静态二进制即可完成虚拟环境创建、依赖安装、锁定、发布等任务。它已全面支持 macOS、Linux 和 Windows，正被越来越多 CI 流水线与大型代码库采用——uv 不仅加速了安装过程，更在重新定义 Python 项目的可重现性、可移植性与性能边界。
