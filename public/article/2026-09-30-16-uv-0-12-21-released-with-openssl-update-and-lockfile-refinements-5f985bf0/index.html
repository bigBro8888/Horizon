uv 0.12.21 发布：升级 OpenSSL 并优化锁文件格式

新闻时间: 2026-09-30T06:39:49.803450+00:00 · 来源: github

Rust 编写的 Python 包管理器 uv 于 2026 年 9 月 29 日发布 0.12.21 版本，这是一次以稳定性与安全性为核心的维护性更新。尽管没有引入全新功能，但此次更新在 OpenSSL 升级、锁文件精简和关键边界问题修复等方面做了扎实改进，对依赖 uv 进行快速、确定性依赖解析的开发者具有实际价值。

最值得关注的变更之一是将 CPython 内置的 OpenSSL 升级至 3.5.9 版本。此举使 uv 构建的 Python 解释器能自动获得最新的安全补丁与加密算法支持，无需用户手动干预 OpenSSL 配置。对于金融、政务等高安全要求场景，该升级可有效降低已知漏洞带来的潜在风险。

在锁文件（uv.lock）处理方面，本次更新进一步提升了规范性：当 [manifest] 表仅包含子表而无实际字段时，uv 将不再写入空表，从而减少锁文件冗余；更关键的是，在启用 resolution-inputs 预览功能后，uv 会自动剔除锁文件中冗余的运行时约束条件（包括涉及预发布版本如 1.0.0a1 的约束），使锁文件更紧凑、解析更准确，避免因预发布版本规则误判引发的冲突。

修复的 Bug 同样直击开发痛点：uv python pin --rm 命令现在不会在未加 --global 参数时误删全局 .python-versions 文件，防止跨项目 Python 版本配置被意外清除；另一项修复修正了已安装包兼容性检查逻辑——此前，后发布版本（如 1.0.0.post1）会被错误判定为不满足 >1.0.0a1 这类排他性下界，导致解析失败；该问题现已解决，显著提升 CI/CD 流水线与复杂版本策略下的可靠性。

这类看似细微的更新，恰恰体现了 uv 日趋成熟的工程理念：不追求噱头，而专注正确性、安全性和开发者体验。随着越来越多团队将 uv 用于替代 pip+poetry 或加速构建流程，此类持续打磨正逐步转化为真实的效率与稳定性收益。
