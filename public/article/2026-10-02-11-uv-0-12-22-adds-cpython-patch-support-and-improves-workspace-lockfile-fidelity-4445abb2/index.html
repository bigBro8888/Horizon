uv 0.12.22 支持新版 CPython 并增强工作区锁文件准确性

新闻时间: 2026-10-02T06:58:44.799580+00:00 · 来源: github

Python 工具链生态迎来一次关键升级：Astral 开发的超快 Python 包安装与依赖解析工具 uv 正式发布 0.12.22 版本。该版本于 2026 年 10 月 1 日发布，虽为补丁更新，却显著提升了复杂 Python 项目（尤其是采用工作区结构的单体仓库）的可复现性与可靠性。

uv 是一个用 Rust 编写的现代替代方案，旨在加速并取代 pip、Poetry 等传统工具在安装、解析、虚拟环境管理及锁文件生成等核心环节的表现。0.12.22 新增对五个 CPython 补丁版本的官方支持：3.10.22、3.11.17、3.12.15、3.13.16 和 3.14.8。这意味着开发者能及时使用 Python 官方发布的安全修复与稳定性改进，无需再因工具兼容性而延迟升级。

更关键的是，该版本大幅增强了工作区成员锁文件（uv.lock）的准确性。过去，uv 在生成锁文件时可能遗漏或不一致地记录工作区成员的默认依赖组（如 test、dev）及其关联的 Python 版本要求。现在，它能可靠地记录这些信息——不仅适用于项目根目录下的工作区成员，也覆盖非项目型根目录（例如共享工具包）。因此，执行 uv sync --frozen 时将严格遵循各成员声明的依赖组与 Python 要求，显著降低单体仓库中隐性构建失败的风险。

其他改进包括：正确解析含大写发布后缀（如 cp312-cp312-win_amd64）的 wheel 平台标签；新增 UV_PYTHON_ARCH 环境变量，可独立于 Python 版本指定解释器架构（如 x86_64 或 aarch64）；通过压缩内嵌元数据使二进制体积减少约 5%；并优化命令行体验——例如从 uv publish 帮助文档中隐藏不支持的 --offline 选项，以及统一错误消息中的 URL 和路径格式。

尽管没有引入颠覆性新功能，0.12.22 充分体现了 uv 的成熟路径：专注正确性、可复现性与互操作性。对于在 CI/CD 流水线中采用 uv 或依赖锁文件进行严格部署的团队而言，这些改进意味着更少的意外故障和更强的构建确定性。
