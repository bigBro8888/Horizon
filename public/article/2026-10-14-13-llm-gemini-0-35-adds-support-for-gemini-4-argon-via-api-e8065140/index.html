llm-gemini 0.35 版本支持新发布的 Gemini 4 Argon 模型

新闻时间: 2026-10-14T06:06:19.192438+00:00 · 来源: rss

西蒙·威利森（Simon Willison）发布了 llm-gemini 0.35 版本，这是一个命令行插件，用于扩展他广受欢迎的 LLM 工具链，使其原生支持谷歌最新推出的前沿大模型 Gemini 4 Argon。该更新紧随谷歌正式向公众开放 Argon 之后推出——最初通过“Fairwind 计划”面向部分网络安全从业者，随后迅速面向所有开发者、企业和科研人员开放。作为轻量级开源工具，llm-gemini 让用户无需编写定制代码，即可在终端或 Python 脚本中直接调用 Gemini API 运行 Argon。

Gemini 4 Argon 是谷歌迄今推理能力最强的模型之一，专为长周期、高复杂度任务设计，适用于软件工程、法律分析、金融建模和网络安全防御等场景。与早期 Gemini 版本不同，Argon 强化了持续逻辑推理能力与缓存感知推理机制——这在其基准测试成本构成中清晰可见：推理耗资 815 美元、缓存写入 897 美元，而非缓存输入仅占 118 美元。正因如此，Artificial Analysis 的端到端基准总成本榜单将 Argon 列为 2407 美元，显著低于 GPT-6 Astra（5324 美元）、Claude Opus 5.5（8708 美元），甚至略低于 GLM-5.3（2503 美元）。

价格策略具有时效性：Argon 上线初期定价为每百万输入 token 2 美元、每百万输出 token 10 美元，仅为 Claude Opus 5.5 的一半、Claude Fable 5.1 的五分之一。但谷歌已宣布将于 12 月 1 日起将其价格翻倍，届时将与 Opus 5.5 持平。即便如此，按基准总成本衡量，Argon 仍比 GPT-6 Astra 等主流模型更具性价比。

此次发布还附带一组由 Argon 自主生成的 SVG 插图，被戏称为“低/中/高阶鹈鹕”。其中一幅“高阶鹈鹕”（一只骑自行车、戴围巾、表情凌厉的鹈鹕）生成成本为 0.17166 美元，直观体现了模型在多模态生成与 token 效率上的实际表现。尽管原文存在若干碎片化表述和疑似占位内容，其核心信息——及时的 API 集成、透明的价格说明及实测成本数据——对习惯使用命令行工具开发 AI 应用的工程师而言，仍具明确实用价值。
