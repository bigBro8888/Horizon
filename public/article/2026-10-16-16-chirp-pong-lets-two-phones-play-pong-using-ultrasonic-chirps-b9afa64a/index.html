Chirp Pong：两部手机靠超声波‘喊话’玩乒乓

新闻时间: 2026-10-16T05:48:25.846587+00:00 · 来源: rss

Chirp Pong 是一个既有趣又技术严谨的点对点网页游戏实验——无需 Wi-Fi、无需蓝牙、也无需服务器。两位玩家只需在各自的智能手机上打开同一个静态 HTML 页面，将手机靠近彼此，即可开始玩一款重新设计的乒乓游戏。游戏状态（如球拍位置、球速和得分）并非通过互联网同步，而是由一部手机扬声器发出短暂、人耳几乎听不见的超声波‘啁啾声’，再由另一部手机的麦克风接收并解析。整套系统完全在浏览器内运行，依赖 Web Audio API 实现实时音频分析。

它的设计远不止复刻经典乒乓：球的物理行为会根据击球位置动态变化；每次数据传输都伴有视觉脉冲反馈；两侧玩家还拥有不对称特性（例如一侧球拍加速度略快），以此鼓励玩家调整物理距离并专注聆听。这些设计让音频通道不再只是数据管道，而成为游戏体验与交互逻辑的核心部分。

Chirp Pong 的特别之处还在于它融合了创意编程、无障碍离线体验与 AI 辅助开发。开发者 Simon Willison 使用 Claude Code（Claude Opus 5.5 Extra）生成并迭代核心音频同步逻辑——展示了现代大语言模型如何帮助缺乏数字信号处理（DSP）背景的网页开发者快速实现底层音频协议原型。最终成果是一个完全离线、免安装、跨平台的体验，可在任何配备麦克风和扬声器的现代智能手机上运行。

尽管并非面向生产的软件，Chirp Pong 既是教学范例，也是一种技术提问：它证明日常硬件（麦克风与扬声器）在精心设计的 API 支持下，完全可以成为网络通信接口。在日益依赖云端连接的时代，它提醒我们——本地化、具身化、甚至可听见的交互层，仍在网页应用中等待被深入探索。
