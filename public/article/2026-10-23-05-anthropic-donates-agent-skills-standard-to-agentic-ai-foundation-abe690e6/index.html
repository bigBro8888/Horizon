Anthropic 将 Agent Skills 标准捐赠给智能体人工智能基金会

新闻时间: 2026-10-23T06:00:37.306366+00:00 · 来源: rss

Anthropic 正式将 Agent Skills 开放标准捐赠给由 Linux 基金会托管的智能体人工智能基金会（AAIF），此举标志着智能体人工智能（agentic AI）开放基础设施建设迈出关键一步。该基金会于 2025 年由 Anthropic、Block 和 OpenAI 共同创立，此前已接纳了 Anthropic 捐赠的模型上下文协议（MCP）作为首个核心规范。此次捐赠使 Agent Skills 成为真正中立、开放、由社区共同治理的技术标准，彰显了行业共建互操作性生态的共识。

Agent Skills 是一种轻量级、基于文件的能力扩展格式，允许开发者为 AI 智能体注入特定专业知识与工作流——例如查询数据库、执行代码或编排多步骤任务。其核心是一个包含 SKILL.md 文件的文件夹：该文件以 YAML 前置元数据（必填字段为 name 和 description）开头，后接智能体运行时可读的 Markdown 指令。由于格式简洁、不依赖特定工具链，技能可在不同智能体平台间自由共享、安装与组合，类似传统软件的插件机制。

交由 AAIF 管理后，该标准的技术演进将通过公开工作组、征求意见稿（RFC）和透明治理流程推进，而非由某一家公司主导。这延续了 MCP 的成功路径：自 Anthropic 去年开源 MCP 后，Firecrawl、Datasette 及多个 AI 集成开发环境（IDE）等数十个工具迅速采用。Agent Skills 目前也已获得早期生态响应，OpenCode 等框架已原生支持该标准。

此次捐赠的时机与先例尤为值得重视。Anthropic 在 2025 年 12 月首次宣布 Agent Skills 为“开放标准”，独立技术专家 Simon Willison 当月即准确预测其将纳入 AAIF。他甚至利用 Claude 自身通过 datasette-mcp 插件检索自己的博客文章验证了这一判断。这种用标准本身验证标准前景的“自指式”实践，恰恰说明这些规范已深度融入真实开发者工作流。

这远不止是单个技术规范的移交，而是构建一套可持续、协作式的智能体 AI 技术栈：数据接入（MCP）、能力封装（Agent Skills）以及未来可能的智能体间通信等层，将协同演进、避免厂商锁定。对开发者而言，意味着更少重复造轮子；对企业而言，意味着更强迁移能力；对整个生态而言，则是迈向自主执行型 AI 的坚实地基。
