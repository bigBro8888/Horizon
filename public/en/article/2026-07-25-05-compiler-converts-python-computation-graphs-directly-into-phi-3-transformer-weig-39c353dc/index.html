Compiler converts Python computation graphs directly into Phi-3 transformer weights

News time: 2026-07-25T04:25:14.954216+00:00 · Source: reddit

A researcher has built a novel compiler called TorchWright that transforms arbitrary Python-defined computation graphs into fully functional, pre-trained-equivalent weights for a standard Phi-3 transformer — with zero training, no custom inference code, and full compatibility with Hugging Face’s vanilla loading pipeline. The output is a valid PyTorch checkpoint file that loads seamlessly using transformers.AutoModelForCausalLM.from_pretrained(), requiring neither trust_remote_code=True nor architecture modifications.

This work tackles a foundational question in deep learning theory: what algorithms can transformers express, independent of what they can learn from data? Rather than relying on gradient-based optimization, TorchWright uses symbolic construction — mapping each node and edge in a Python-defined graph (e.g., loops, conditionals, arithmetic operations over sequences) to precise weight configurations in attention and feed-forward sublayers. It targets the exact architectural specifications of Phi-3: 32 attention heads, RMSNorm, SwiGLU activations, and standard positional embeddings — all implemented using only native Hugging Face building blocks.

Unlike prior systems such as RASP or Tracr, which operate on domain-specific languages or require custom transformer variants, TorchWright accepts ordinary Python code — including control flow and dynamic data dependencies — and compiles it down to weights for an off-the-shelf model. Twelve runnable examples in its GitHub repo demonstrate tasks ranging from parity checking and sorting to modular exponentiation, all executing exactly as specified when loaded and run. The compiler does not approximate or simulate; it guarantees faithful execution of the original graph via deterministic weight assignment.

The implications extend beyond program synthesis. By proving that stock transformers can embed arbitrary finite-state computations without retraining, TorchWright sharpens our understanding of transformer expressivity: it shows that architectural capacity isn’t just about scale or data, but about how cleanly computational primitives map onto fixed-weight subcircuits. While current limitations include bounded input length and reliance on hand-crafted sublayer wiring (not yet scalable to billion-parameter models), the approach opens paths toward interpretable, verifiable neural programs — and may inform future hardware-aware model design or formal verification tools.
