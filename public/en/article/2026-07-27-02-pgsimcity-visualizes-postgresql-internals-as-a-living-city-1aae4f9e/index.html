PGSimCity visualizes PostgreSQL internals as a living city

News time: 2026-07-27T04:49:50.416568+00:00 · Source: hackernews

PGSimCity is an open-source, browser-based educational tool that reimagines PostgreSQL’s complex internal architecture as a dynamic, SimCity-style 3D metropolis. Each building, road, and moving vehicle corresponds to a real PostgreSQL component: the parser becomes a city entrance gate, query planning unfolds in a central command tower, execution happens across industrial zones, and shared buffers appear as interconnected water reservoirs. As users navigate the city, animated data flows—represented by glowing vehicles—trace how a SQL query travels from input to result, passing through parsing, planning, execution, and storage layers.

The project was created by Nikolay Samokhvalov and launched publicly on GitHub Pages. It draws inspiration from pedagogical simulations like SimCity—not as a game, but as a cognitive scaffold—to help learners build mental models of systems they can’t see. Unlike static diagrams or dense documentation, PGSimCity offers spatial, temporal, and visual coherence: memory structures have physical scale, concurrency appears as traffic patterns, and background processes run continuously like utility grids.

Yet early user feedback highlights a tension between ambition and usability. Several experienced PostgreSQL developers and educators praised its vision but reported being overwhelmed by simultaneous animations, overlapping labels, and auto-advancing tours. One commenter noted it feels like “being a passive observer to so much information,” while another wished for interactive query submission—typing SELECT * FROM users and watching it animate end-to-end. Others suggested adding controls like pause, slow-motion, or selective layer toggling to reduce cognitive load.

Despite its current limitations, PGSimCity signals a growing demand for intuitive, systems-level teaching tools—especially for infrastructure software where abstractions are deep and documentation is often technical or fragmented. Its open-source nature invites contributions not just to PostgreSQL education, but potentially to other domains: one user proposed adapting the same metaphor for Kubernetes clusters or cloud networking stacks. For now, it stands as both a promising prototype and a case study in how visualization design must balance richness with clarity.
