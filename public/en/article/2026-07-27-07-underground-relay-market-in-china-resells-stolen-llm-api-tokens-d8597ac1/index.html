Underground relay market in China resells stolen LLM API tokens

News time: 2026-07-27T04:49:50.158167+00:00 · Source: rss

An investigative report by Matt Lenhard has uncovered a thriving gray-market ecosystem in China where resellers aggregate stolen, trial, or fraudulently obtained LLM API keys—and route them through open-source proxy software to offer deeply discounted token access. Buyers use these services to cut costs, bypass geographic restrictions, or even harvest prompts and responses for model distillation. The operation is largely decentralized and commercially motivated, with no central platform: instead, it runs via private WeChat groups, Chinese forums like V2EX, and Telegram channels.

The technical backbone of this market relies on two widely used open-source LLM API proxies: one-api and its more actively maintained fork, new-api. Both are legitimate tools designed for developers to load-balance requests across multiple API keys—say, to improve reliability or manage quotas. But in this underground context, they’re repurposed to pool credentials from compromised accounts, free-tier abuse, or even credit card chargeback schemes. Resellers configure the proxies to hide the origin of each request, making abuse harder to trace and attribute.

This isn’t theoretical risk—it’s operational at scale. Some resellers advertise 30–60% discounts over official OpenAI or Anthropic pricing, sustained by rotating thousands of keys. The report notes that many victims are unwitting: support bots left publicly exposed, misconfigured cloud deployments, or developers who accidentally leak keys in GitHub repos become low-hanging fruit. One forum thread on V2EX (t/1196011) details how resellers scout for such endpoints, automate key harvesting, and even offer tiered subscription plans.

For platform providers, this undermines core economic assumptions: usage-based pricing collapses when tokens can be arbitrated across jurisdictions and abuse vectors. For developers, it raises the stakes on API hygiene—exposing even a single unprotected endpoint now invites systematic exploitation by a coordinated, profit-driven adversary. As Simon Willison observes, the real fix isn’t just better detection, but enforceable, granular spending caps per API key: ‘I want my LLM apps to stop working the moment they hit a dollar threshold I’ve set.’ Without such controls, the relay market will keep growing—not as an anomaly, but as an inevitable arbitrage layer atop today’s fragmented AI infrastructure.
