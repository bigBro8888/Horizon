CheapSecurity offers lightweight self-hosted CCTV for Raspberry Pi and similar Linux SBCs

News time: 2026-07-27T04:49:50.416746+00:00 · Source: hackernews

A new open-source project called CheapSecurity has emerged as a pragmatic, do-it-yourself alternative to commercial or heavyweight surveillance solutions. Built entirely in Python and relying on OpenCV for core computer vision tasks, it transforms affordable Linux single-board computers (SBCs) — like the Raspberry Pi — into functional CCTV systems. The software captures video from USB webcams via V4L2, applies real-time image enhancements (including CLAHE for low-light correction), detects motion using frame differencing and contour analysis, and streams live footage as MJPEG over HTTP — all without requiring external daemons or complex dependencies.

Unlike full-featured platforms such as Frigate (which leverages hardware-accelerated AI inference for object detection) or Motion (a mature, C-based daemon with extensive configuration options), CheapSecurity prioritizes simplicity and minimal resource usage. It avoids deep learning models entirely, opting instead for classic computer vision techniques that run smoothly even on modest hardware like a Raspberry Pi 4 with 2 GB RAM. Its architecture is deliberately linear: video capture → preprocessing → motion detection → optional recording → streaming — making it easy to audit, modify, or extend.

The project also includes practical automation hooks: when motion is detected, it can trigger local video recording (with post-processing via FFmpeg to fix frame rate issues) and send alerts via Telegram or email. While not designed for enterprise-scale deployments, it fills a clear niche for hobbyists, homelab enthusiasts, or privacy-conscious users who want full control over their surveillance stack — no cloud accounts, no vendor lock-in, and no subscription fees.

Community feedback reflects both enthusiasm and healthy skepticism. Commenters ask how it compares to Motion’s stability and configurability, or whether it addresses known pain points like poor low-light performance of consumer USB webcams. Others note its reliance on OpenCV means it inherits that library’s trade-offs — including CPU-bound processing and sensitivity to lighting conditions. Still, the fact that 24 developers engaged with technical depth suggests growing demand for accessible, transparent, and maintainable DIY surveillance tools.
