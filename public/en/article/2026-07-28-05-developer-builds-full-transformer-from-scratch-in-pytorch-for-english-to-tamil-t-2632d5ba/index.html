Developer builds full Transformer from scratch in PyTorch for English-to-Tamil translation

News time: 2026-07-28T04:24:58.304589+00:00 · Source: reddit

A machine learning practitioner has built, trained, and thoroughly documented the entire Transformer architecture — from embedding layers to multi-head attention, positional encoding, feed-forward blocks, and final decoding — using only native PyTorch (torch.nn) modules. Unlike many simplified tutorials that skip mathematical rigor or rely on high-level abstractions like Hugging Face’s Trainer, this implementation exposes every tensor shape, derives each attention equation step-by-step, and maps theory directly to code — all while training end-to-end on real-world English-to-Tamil translation.

The model was trained on the gopi30/english-tamil dataset from Hugging Face, a curated parallel corpus containing sentence-aligned English and Tamil text drawn from diverse domains including news, cinema, and religious texts. The author manually verified tensor dimensions at each layer, annotated gradients where relevant, and included detailed commentary on why certain design choices — such as layer normalization placement or dropout scheduling — matter for stability and convergence.

Training ran across two NVIDIA T4 GPUs on Kaggle, with careful memory management and gradient accumulation to handle batch size constraints. The blog post walks readers through how tokenization interacts with vocabulary size, how positional encodings preserve sequence order without recurrence, and how masked self-attention enforces causal language modeling during decoding. Code is modular, well-commented, and tested with small synthetic inputs before scaling to real data.

What makes this work especially valuable is its pedagogical fidelity: it doesn’t assume familiarity with attention beyond basic linear algebra, yet never oversimplifies. For example, the softmax-scaled dot-product attention derivation includes explicit matrix dimension checks (e.g., Q ∈ ℝ^(seq×d_k), K^T ∈ ℝ^(d_k×seq) → scores ∈ ℝ^(seq×seq)), helping learners bridge notation and implementation. The GitHub repo also documents dual-GPU data parallelism setup — rare in beginner-facing resources.

This isn’t just another ‘Transformer in 50 lines’ demo. It’s a production-aware, mathematically grounded reference implementation designed for engineers who want to understand, not just run, large language models. As Transformers remain central to modern NLP — from translation to code generation — resources like this lower the barrier to deep technical engagement, especially for underrepresented language pairs like English–Tamil.
