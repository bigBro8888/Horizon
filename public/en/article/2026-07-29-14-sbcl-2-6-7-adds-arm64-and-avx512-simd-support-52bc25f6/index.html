SBCL 2.6.7 adds ARM64 and AVX512 SIMD support

News time: 2026-07-29T04:27:46.549173+00:00 · Source: hackernews

Steel Bank Common Lisp (SBCL) version 2.6.7 marks a major step forward for high-performance Lisp systems programming. Released with deep low-level enhancements, the update brings native SIMD support to both ARM64 and x86-64 architectures — including full AVX512 instruction coverage on Intel and AMD processors. These improvements are not just incremental: they enable developers to write vectorized numerical code directly in Common Lisp, without dropping to C or assembly, while retaining SBCL’s hallmark compilation speed and runtime safety.

The new capabilities land primarily through the sb-simd contrib library, now extended to ARM64 thanks to Sylvia Harrington’s work, and significantly expanded on x86-64 by Robert Smith and Arthur Miller. Unlike automatic vectorization found in some optimizing compilers, SBCL’s current SIMD support is explicit: programmers use intrinsics — functions mapping directly to CPU instructions — rather than relying on the compiler to auto-vectorize loops. This gives fine-grained control but requires manual effort and domain knowledge of vector lanes, data alignment, and register constraints.

Beyond raw performance, the release sparks broader reflection across the Lisp community. Commenters debate foundational questions: what would software deployment look like if Lisp images — self-contained, running snapshots of memory and code — were the standard unit instead of containers or binaries? Others highlight practical gaps, such as sparse documentation for newer features like memory arenas, urging maintainers to prioritize usability alongside capability. The discussion reveals a mature ecosystem balancing cutting-edge systems work with enduring concerns about accessibility and sustainability.

For developers building scientific computing tools, real-time signal processing pipelines, or high-throughput data analyzers in Lisp, SBCL 2.6.7 lowers the barrier to hardware-accelerated computation. It also signals SBCL’s continued relevance in domains where performance, predictability, and expressive power intersect — from embedded Lisp machines to modern cloud infrastructure. As one commenter noted, Hacker News itself runs on SBCL, underscoring its production readiness despite its academic roots.
