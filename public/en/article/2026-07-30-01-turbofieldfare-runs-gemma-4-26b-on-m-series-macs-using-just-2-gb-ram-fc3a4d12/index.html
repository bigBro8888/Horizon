TurboFieldfare runs Gemma 4 26B on M-series Macs using just 2 GB RAM

News time: 2026-07-30T04:17:07.063854+00:00 · Source: hackernews

A new open-source inference engine called TurboFieldfare enables the 26-billion-parameter Gemma 4 26B-A4B-IT model to run smoothly on consumer-grade M-series Macs — including an 8 GB M2 MacBook Air — using only about 2 GB of RAM. Developed by drumih and released on GitHub, the engine is written entirely in Swift and leverages Apple’s Metal framework for GPU acceleration. Unlike conventional LLM runtimes that load the entire quantized model into memory, TurboFieldfare takes a radically different approach: it keeps only the shared model layers and KV cache in RAM, while dynamically streaming just the routed expert weights needed for each token directly from SSD during inference.

This breakthrough hinges on the model’s Mixture-of-Experts (MoE) architecture. Though Gemma 4 26B has 25.2 billion total parameters, only ~3.8 billion are activated per token — meaning most weights sit idle at any given moment. TurboFieldfare exploits that sparsity: when a token arrives, the router selects which four experts to activate, and the engine fetches only those specific expert weight chunks from SSD using bounded parallel pread calls. While SSD reads are in flight, the GPU concurrently computes the shared layer operations — effectively hiding I/O latency behind computation.

Benchmark results show real-world viability: on an 8 GB M2 MacBook Air, TurboFieldfare delivers 5–6 tokens per second; on a high-end M5 MacBook Pro, it achieves 31–35 tokens per second. The project also includes an experimental OpenAI-compatible local API server supporting streaming responses and tool calls — and even reuses cached prompt prefixes to accelerate repeated interactions. Installation is straightforward: users download a Mac app, which automatically fetches the 15 GB GGUF-weight file from Hugging Face on first launch.

The engineering choices reflect deep systems awareness. Instead of relying on OS-level mmap, TurboFieldfare implements custom, inference-aware SSD streaming — tightly synchronizing disk reads with GPU compute cycles. Community feedback confirms its significance: developers report successful builds on older macOS versions (with minor Swift syntax tweaks), compare trade-offs against llama.cpp’s mmap strategy, and even propose cross-project kernel sharing with emerging diffusion-LLM hybrids. As on-device AI pushes beyond toy models, TurboFieldfare demonstrates that memory isn’t destiny — clever orchestration of storage, compute, and model structure can unlock capabilities once thought impossible on laptops.
