Mitchell Hashimoto launches Superlogical to build MIT-licensed terminal tools on libghostty

News time: 2026-07-30T04:17:07.063889+00:00 · Source: hackernews

Mitchell Hashimoto — creator of Vagrant, Packer, and Terraform — has founded a new company called Superlogical, focused squarely on building developer tools that run inside the terminal. Unlike typical startups that wrap infrastructure in web dashboards, Superlogical embraces the terminal as a first-class interface: its tools are designed to be embedded, composed, and extended using the open-source libghostty library. Hashimoto announced the venture in a detailed essay on his personal site, framing it not as a proprietary product play but as an upstream-first engineering commitment — one where every shared component is MIT-licensed and contributions flow back into the public ecosystem.

The foundation is libghostty, a cross-platform C library extracted from Ghostty, the terminal emulator Hashimoto also created. Released earlier in 2025, libghostty provides a minimal, correct, and fast virtual terminal emulator API — supporting features like IME integration, search, theming, and native rendering across Linux, macOS, and Windows. Crucially, Hashimoto transferred ownership of Ghostty to a non-profit before launching Superlogical, ensuring libghostty remains a neutral, community-owned building block — not a vendor-controlled dependency.

Superlogical’s early work appears aligned with composability trends in terminal tooling: commenters on Hacker News drew parallels to historical component models like COM and OLE, where applications could embed and interoperate with rich subcomponents (e.g., editing an Excel chart inside Word). Others noted similarities to newer projects like herdr (an agentic TUI multiplexer), pi-web (a web frontend for distributed Pi coding sessions), and firstmate (a meta-coding environment). These comparisons highlight growing demand for modular, embeddable terminal surfaces — not just full-screen emulators.

What sets Superlogical apart is its licensing and governance discipline. Rather than forking or maintaining private forks of libghostty, the company commits to consuming it exactly as shipped — same MIT license, same public API — and upstreaming improvements so all users benefit. This avoids the fragmentation common in open-source toolchains, where companies quietly diverge from upstream while claiming open-source alignment. For developers who rely on stable, embeddable terminal primitives — from IDEs to remote dev environments — Superlogical signals a rare bet on interoperability over lock-in.
