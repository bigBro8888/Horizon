PostSlate cuts face inference latency by 10x using ncnn Vulkan backend

News time: 2026-07-30T04:17:07.285178+00:00 · Source: reddit

A production ML engineering team behind PostSlate—a desktop video editing application—has solved a persistent edge AI challenge: delivering fast, consistent on-device machine learning across wildly different GPUs. Unlike cloud-based inference, their models must run locally for privacy and responsiveness, supporting users with NVIDIA GeForce, AMD Radeon, Intel Iris Xe, and Apple M-series chips—all without installing vendor-specific drivers or runtimes.

The team rejected CUDA outright because it only works on NVIDIA hardware, and OpenVINO or ROCm were similarly limited to Intel and AMD respectively. Instead, they adopted ncnn’s Vulkan backend, a lightweight, open-source inference framework originally developed by Tencent. Vulkan is a cross-platform graphics and compute API supported natively on Windows, macOS, and Linux—and crucially, its drivers ship pre-installed with every major GPU vendor’s operating system distribution.

Benchmarking two core models—ArcFace R50 for face embeddings and SCRFD for face detection—they measured dramatic improvements. On an RTX 4070 running fp16 precision, ArcFace inference dropped from 30 ms (ONNX CPU) to just 3 ms; SCRFD fell from 25 ms to 2.5 ms. Model size also halved: the ArcFace R50 ONNX file shrank from 174 MB (fp32) to 87 MB (fp16 quantized weights in ncnn format). These gains weren’t just about raw speed—the real win was deployment simplicity: zero user-facing install steps, no driver prompts, and guaranteed runtime availability.

This approach reflects a broader shift in edge AI: moving away from vendor-locked stacks toward portable, standards-based backends. While Vulkan doesn’t execute every layer on GPU (some ops may fall back to CPU), ncnn’s Vulkan support is mature enough for production vision workloads. As Hui Ni of Tencent noted at W3C China’s WebEvolve 2024 conference, Vulkan-based inference is increasingly viable for low-latency, cross-platform scenarios where consistency matters more than peak theoretical throughput.
