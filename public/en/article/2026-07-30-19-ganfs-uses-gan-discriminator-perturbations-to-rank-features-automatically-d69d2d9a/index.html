ganfs uses GAN discriminator perturbations to rank features automatically

News time: 2026-07-30T04:17:07.284897+00:00 · Source: reddit

A new open-source Python package called ganfs aims to tackle one of machine learning’s most persistent practical hurdles: automated feature selection in high-dimensional data. Unlike traditional methods—such as correlation-based filters, recursive feature elimination, or L1-regularized models—ganfs doesn’t rely on statistical assumptions, domain knowledge, or labeled targets. Instead, it leverages the adversarial dynamics of generative adversarial networks (GANs) to identify which input features are most critical for distinguishing real data from synthetic samples.

The core idea is elegantly simple yet technically nuanced. ganfs trains a GAN on the raw dataset—no labels required—and then systematically perturbs individual features in the input space while monitoring how the Discriminator’s output changes. Features whose perturbation causes the largest drop in the Discriminator’s confidence (i.e., makes fake samples harder to distinguish from real ones) are deemed most informative. This ‘hard-to-fake’ principle yields a ranking without supervision, making it especially useful for unsupervised or semi-supervised scenarios like network intrusion detection, where the original developer applied it to DDoS traffic analysis.

Installation and usage mirror scikit-learn conventions: after pip install ganfs, users can fit and transform datasets with just a few lines. The package supports both CPU and GPU backends, though the author notes ongoing work to reduce GPU memory overhead for smaller datasets. Under the hood, the method draws from recent advances in perturbation-based interpretability—treating the Discriminator not just as a classifier but as a sensitivity probe for feature importance.

While promising, ganfs remains early-stage. The arXiv preprint (v1, April 2025) reports improved downstream classifier accuracy and reduced dimensionality on the CIC-DDoS2019 dataset—but lacks ablation studies, runtime benchmarks against established baselines (e.g., Boruta, SHAP-GAN hybrids, or deep embedded selection), or tests on non-network domains. Community feedback on Reddit highlights these gaps, asking pointed questions about computational cost, reproducibility, and whether rankings align with known domain priors. Still, by reframing feature selection as an adversarial learning problem—not a statistical or optimization one—ganfs opens a fresh conceptual pathway for automation in high-dimensional ML pipelines.
