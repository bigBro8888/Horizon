YC-backed qm launches multiplayer AI agent harness for collaborative work

News time: 2026-08-01T04:33:02.670033+00:00 · Source: hackernews

Y Combinator–backed startup yc-software has open-sourced qm — a production-ready framework designed to coordinate multiple AI agents in shared, context-aware work environments. Unlike single-user agent systems, qm treats collaboration as first-class: it introduces per-person scopes (isolating individual context and permissions), shared rooms (persistent, team-level workspaces), and built-in enforcement mechanisms like 'anti-slop' design guardrails. The project is not just theoretical — it ships with working examples, including a frontend skill that audits and generates UI code meeting strict aesthetic and structural standards, explicitly banning overused premium-consumer palettes.

The architecture reflects deep operational awareness of real-world workflows. Rather than assuming agents operate in isolation, qm models identity, channel history (e.g., Slack threads or Cowork sessions), and cross-agent memory as core primitives. This means an agent can recognize that you’re the same person whether you message via web interface, Slack bot, or email plugin — and recall your prior requests across those channels. As one practitioner noted, the hardest challenge isn’t the agent loop itself, but scoping: knowing whose context applies where. qm’s per-person scopes plus shared rooms offer a pragmatic answer for enterprise-scale assistants.

qm also embraces interoperability by design. It supports pluggable harness frameworks and aims to integrate with existing MCP (Model Communication Protocol) clients — including tools like Cowork — so agents aren’t locked into one interface or vendor stack. This aligns with a broader industry shift toward composable, protocol-based agent ecosystems rather than monolithic platforms. Early adopters are already building adjacent tools: one team runs Claude Code and Codex together in a multiplayer coding harness; another reports agents autonomously scheduling meetings across Slack channels — unintentionally replicating middle-management duties.

What sets qm apart is its focus on enforcement, not just capability. Its 'anti-slop' skill — inspired by the Taste Skill ecosystem — enforces typographic rhythm, spacing consistency, and image prompt hygiene before any UI code ships. It’s not about making things 'pretty'; it’s about preventing low-signal, template-driven outputs that erode trust in AI-generated work. In short, qm doesn’t just enable multi-agent collaboration — it defines how that collaboration must behave to remain useful, accountable, and human-aligned.
