uv 0.12.1 adds package-specific pre-release control and Xonsh support

News time: 2026-08-01T04:33:03.230481+00:00 · Source: github

Astral-sh’s uv — the Rust-powered, high-performance Python package installer and resolver — has released version 0.12.1 on July 31, 2026. This update delivers practical improvements for developers managing complex dependency workflows, especially those using modern Python packaging patterns like PEP 723 inline scripts or custom index sources.

The most immediately useful enhancement is package-specific pre-release policy control via --prerelease-package. Unlike global --prerelease flags, this lets developers opt individual packages (e.g., requests or numpy) into pre-release versions while keeping others stable — a granular approach long needed in real-world projects where some libraries ship breaking changes early but others require strict stability.

Also notable is native support for local HTML flat indexes: developers can now point uv directly to a local index.html file serving as a simple, offline-compatible package repository — ideal for air-gapped environments, CI caching, or internal tooling. Complementing this, uv now generates activate.xsh scripts, enabling seamless virtual environment activation in Xonsh, a popular shell blending Python and shell syntax. This fills a longstanding gap for Xonsh users who previously had to manually source bash/zsh scripts or rely on workarounds.

On the robustness front, preview features improve lockfile handling in metadata-light scenarios — such as PEP 723 scripts — by better respecting direct URL constraints and avoiding false rejections when workspace dependencies share sources. Performance gains include faster SHA-256 hashing on ARM64 Windows and macOS, plus more efficient parsing of canonical lockfiles. Several bug fixes further tighten reliability: uv add --index now preserves filesystem paths in pyproject.toml, --find-links paths resolve correctly relative to requirements files, and shell startup updates flush properly before command exit.

While not a major version leap, uv 0.12.1 reflects disciplined, user-driven iteration — addressing concrete pain points around ergonomics, reproducibility, and cross-shell compatibility. As uv continues gaining adoption (often cited as 10–100× faster than pip), each minor release strengthens its role as a foundational tool for modern Python development.
