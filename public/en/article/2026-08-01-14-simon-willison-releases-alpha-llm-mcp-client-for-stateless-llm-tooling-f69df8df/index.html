Simon Willison releases alpha llm-mcp-client for stateless LLM tooling

News time: 2026-08-01T04:33:02.137229+00:00 · Source: rss

Simon Willison, a well-known developer and technical blogger, has released llm-mcp-client 0.1a0 — the first alpha implementation of a client library designed to interact with large language models (LLMs) using the Model Context Protocol (MCP). This lightweight Python package is not a model itself, but a bridge: it lets applications send standardized, stateless requests to MCP-compliant servers and receive structured responses. The release coincides with growing industry interest in decoupling LLM logic from tool integration — a shift toward interoperability, portability, and reduced vendor lock-in.

The Model Context Protocol, originally introduced by Anthropic in late 2024, defines how LLMs can securely and consistently access external tools, databases, APIs, and real-time data sources. Unlike ad-hoc plugin systems or proprietary extensions, MCP is an open specification built on JSON Schema and designed to work across frameworks and languages. Willison’s client implements the latest 2026-07-28 revision of the protocol — notably its newly formalized stateless core, which means each request carries all necessary context, eliminating server-side session state and simplifying scaling and caching.

In his accompanying blog post titled 'Stateless MCP', Willison explains why statelessness matters: it enables predictable retries, transparent auditing, easier load balancing, and safer multi-tenant deployments. The client currently supports basic request/response cycles over HTTP, with plans to add streaming, authentication, and extension discovery in future versions. It’s intentionally minimal — no built-in LLM, no UI, no orchestration — focusing solely on correct protocol adherence.

This release fills a practical gap. While the MCP specification has existed for over a year and several servers are now available, few lightweight, production-ready clients existed for developers building MCP-aware tools or integrations. llm-mcp-client lowers the barrier for Python-based AI tooling — from IDE plugins to custom agent runtimes — to adopt the standard without reimplementing low-level protocol details. As more teams adopt MCP, having reference implementations like this one helps prevent fragmentation and encourages consistent behavior across the ecosystem.
