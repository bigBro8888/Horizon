Datasette-apps 0.2a0 adds invisible sandboxed iframe debugging

News time: 2026-08-02T04:34:48.929110+00:00 · Source: rss

Datasette-apps 0.2a0 — an alpha release of the plugin that lets users create, edit, and host HTML/JavaScript apps directly inside Datasette — introduces two powerful new tools designed specifically for integration with Datasette Agent, the LLM-powered assistant for Datasette. The most notable addition is app_debug(), a novel debugging mechanism that loads an app inside a fully sandboxed iframe with zero visibility and no user interaction: it uses CSS opacity: 0 and pointer-events: none to hide the iframe while keeping it live in the DOM. This allows Datasette Agent to execute JavaScript inside the app’s context — checking functionality, measuring element dimensions, or validating rendering — without disrupting the user interface or requiring visible test windows.

The second new tool, app_list(), enables Datasette Agent to programmatically discover which apps a signed-in user has permission to edit. This powers automation: instead of hardcoding app names or relying on manual discovery, the agent can now dynamically enumerate editable apps and act on them — for example, editing, testing, or regenerating them based on natural-language instructions. Both tools rely on Datasette Agent 0.4a0’s new context.browser_task() infrastructure, which provides secure, isolated browser execution contexts for agent-initiated tasks.

This release reflects a deeper shift toward treating Datasette not just as a data explorer, but as a lightweight, collaborative application platform. By embedding apps inside Datasette — stored as single HTML files with version history tracked in SQLite — and now enabling AI agents to safely test and manage them, the ecosystem bridges low-code development with programmatic, LLM-driven workflows. The invisible iframe technique is especially clever: unlike hidden display: none or visibility: hidden elements (which pause rendering and JavaScript), opacity: 0 preserves full execution — though developers should be aware that some browsers may still throttle inactive iframes, as noted in recent web performance research.

For developers building data-centric tools or internal dashboards, datasette-apps + Datasette Agent lowers the barrier to creating, iterating, and verifying custom UIs — all within the same trusted environment where their data already lives. It’s a small but meaningful step toward making Datasette a true 'data-native' application runtime.
