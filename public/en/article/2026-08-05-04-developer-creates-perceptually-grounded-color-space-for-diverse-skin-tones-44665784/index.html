Developer creates perceptually grounded color space for diverse skin tones

News time: 2026-08-05T04:26:41.154371+00:00 · Source: hackernews

A developer named Tony Alexander has released an open, interactive tool that rethinks how digital creators select and generate skin tones — not as arbitrary RGB values, but as points within a carefully designed, perceptually informed color space. Built on Oklab — a modern, perceptually uniform color model — the system maps real-world skin tone distributions into a smooth, crescent-shaped region. This shape emerges from analysis of publicly available datasets, including The Pudding’s foundation shade survey and Pantone’s skin tone references, revealing how human skin tones cluster in lightness-chroma space rather than filling a full rectangle or circle.

The core innovation lies in how the space is parameterized: instead of using raw PCA axes, Alexander fits smooth mathematical functions to the boundaries of the observed skin tone distribution. This allows procedural generation — for example, sampling evenly across hue and chroma while respecting natural limits — and enables intuitive controls like sliders for "warmth" and "depth" that map meaningfully to perception. The web interface includes live demos: a color picker constrained to the skin tone region, animated transitions between tones, and visualizations showing how lighting shifts affect perceived color within the space.

What makes this more than a neat demo is its transparency and grounding. Every step — from data sourcing and Oklab conversion to ellipse fitting and function approximation — is documented with code snippets, derivations, and caveats. The author openly acknowledges limitations: the current model doesn’t yet account for melanin concentration gradients, age-related changes, or lighting-dependent metamerism (where colors match under one light but differ under another). Still, it avoids common pitfalls like oversimplifying skin as a single hue or relying solely on sRGB, which distorts perceptual distances.

The project resonates because inclusive representation in digital media remains technically thorny. Many generative AI tools still default to narrow, biased palettes; game engines often lack built-in support for diverse skin rendering; and UI designers struggle to pick accessible, realistic tones without falling back on stereotypes. By offering both a usable tool and a teachable framework — one rooted in color science, not guesswork — Alexander provides a practical bridge between perceptual research and everyday creative work.
