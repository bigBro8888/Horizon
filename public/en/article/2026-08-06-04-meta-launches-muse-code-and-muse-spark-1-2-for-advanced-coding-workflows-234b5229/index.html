Meta launches Muse Code and Muse Spark 1.2 for advanced coding workflows

News time: 2026-08-06T04:28:17.431538+00:00 · Source: rss

Meta has unveiled Muse Code — its first dedicated AI coding agent — alongside Muse Spark 1.2, an upgraded version of its general-purpose agentic model. Unlike standalone code completers, Muse Code is designed as a terminal-based assistant that navigates, reasons across, and modifies large codebases end-to-end. It works in tandem with Muse Spark 1.2, which has been co-trained to serve as both a reasoning engine and orchestrator for complex developer tasks — from generating entire repositories to debugging multi-file systems and conducting autonomous technical research.

The technical leap lies not just in scale but in architecture: Meta employed rejection-sampled harness trajectories during training — a method where low-quality or redundant agent execution paths are discarded before learning, improving signal quality. Recipe optimizations were also applied to goals, compaction (reducing redundant steps), and subagent delegation, enabling more efficient long-horizon planning. Crucially, Muse Spark 1.2 was trained on full-repository generation and auto-research tasks — moving beyond single-file edits toward holistic software engineering support.

A playful yet telling demonstration is Muse Spark 1.2’s ability to generate an SVG of a pelican riding a bicycle — a whimsical but nontrivial multimodal output requiring precise syntax, layout logic, and compositional awareness. Compared to the July 9th Spark 1.1 version, the 1.2 iteration shows improved fidelity in rendering details like helmet geometry and pedal placement — subtle evidence of better spatial and structural reasoning.

Pricing introduces a notable trade-off: the standard muse-spark-1.2 API costs $1.25 per million input tokens and $4.25 per million output tokens — competitive with Gemini 3.6 Flash. But users who opt in to let Meta use their inputs and outputs for model improvement gain access to muse-spark-1.2-contributor, priced at just $0.10/$0.20 — roughly one-tenth the cost and comparable to DeepSeek-V4 Flash. This ‘data-for-discount’ model echoes broader industry tensions around data rights, transparency, and trust in production-grade AI tooling.
