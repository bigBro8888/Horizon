Monodratic introduces learned product-hash routing for sparse causal attention

News time: 2026-08-06T04:28:18.364316+00:00 · Source: reddit

Monodratic is a new sparse attention architecture designed to scale causal modeling—especially for long-context tasks—without sacrificing accuracy or violating causality. At its core lies learned product-hash routing, a mechanism that replaces brute-force global attention with intelligent, data-driven selection of remote token blocks. After applying Rotary Positional Embeddings (RoPE) to preserve relative position information, Monodratic assigns source token blocks to bounded causal 'posting lists'. Each query then computes a compact product hash address, retrieves candidate blocks from those lists, reranks them using learned scores, selects exactly two remote blocks (from up to five eligible), and guarantees inclusion of local context. Final attention is computed only over this small, dynamically assembled set—making it both causal and highly efficient.

The architecture was evaluated on associative recall, a synthetic but rigorous test of memory and long-range dependency modeling. With just two selected remote blocks, Monodratic achieved 99.35% mean accuracy across three random seeds—far surpassing untrained routing (55.3%) and local-only attention (19.7%). Notably, when the ground-truth target block was manually forced into the selection (while keeping the same total attention budget), performance reached perfect 100%—suggesting the bottleneck lies not in attention computation, but in routing fidelity. The sparse attention outputs also matched dense oracle outputs to within 1.43e-6 absolute error, confirming numerical reliability.

Implementation-wise, Monodratic is deliberately modular: it operates as a stateless mixer transforming [batch, seq, width] tensors, leaving normalization, residuals, feed-forward layers, and inference scheduling to the host model. Its CPU-based routing scales nearly linearly—timing exponent 0.993 from 4K to 32K tokens—with zero posting overflows under balanced configurations. However, the work remains experimental: evaluations use synthetic tasks, the PyTorch implementation isn’t kernel-fused, and no claims are made about natural language fluency or real-world latency.

What makes Monodratic distinctive is its tight coupling of learnability, sparsity, and hard causality guarantees—unlike many sparse attention methods that trade off one for another. It doesn’t approximate softmax over all tokens; instead, it learns where to look, then computes exact attention over the selected subset. This bridges the gap between routing efficiency (as in mixture-of-experts or retrieval-augmented models) and the precision required for causal sequence modeling—offering a promising path toward scalable, interpretable, and memory-efficient transformers.
