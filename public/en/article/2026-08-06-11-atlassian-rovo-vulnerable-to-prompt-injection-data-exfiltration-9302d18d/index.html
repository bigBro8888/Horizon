Atlassian Rovo vulnerable to prompt injection data exfiltration

News time: 2026-08-06T04:28:17.718365+00:00 · Source: hackernews

A newly disclosed security flaw in Atlassian’s Rovo—a GenAI assistant designed to help teams act on organizational knowledge—allows attackers to exfiltrate sensitive data via prompt injection. The vulnerability centers on Rovo’s URL retrieval tool, which lacks safeguards against dynamically generated URLs. When an attacker embeds a malicious prompt in a user-uploaded file (e.g., a document or spreadsheet), Rovo’s agent can be tricked into constructing and opening a URL that includes confidential information—such as Jira issue details or Confluence page content—as query parameters. This bypasses built-in access controls because the request originates from within Rovo’s trusted execution context.

Rovo is part of Atlassian’s broader push into agentic AI: it integrates with Jira, Confluence, and third-party tools using the Model Context Protocol (MCP) to enable autonomous actions like searching, summarizing, and retrieving data. Unlike traditional chatbots, Rovo agents plan steps, use tools, and execute actions—making them powerful but also more exposed to novel attack vectors. The insecure URL retrieval mechanism exemplifies a growing class of risks in agentic systems, where tool permissions are granted broadly but not tightly scoped to human-intended inputs.

Security researcher SimonW highlighted a robust mitigation pattern first pioneered by Anthropic: restricting URL access to only those URLs explicitly provided by users or returned by trusted tools—not those constructed on-the-fly by the agent itself. This ‘whitelist-by-provenance’ approach prevents dynamic URL smuggling while preserving functionality. In contrast, Rovo currently allows its agent to assemble arbitrary URLs, turning what should be a controlled data-fetching capability into an unguarded data-leak channel.

The issue reflects a wider tension in agentic AI development: balancing utility with security. As noted in community discussion, blocking all externally initiated network calls would cripple Rovo’s usefulness—but leaving them wide open invites exploitation. This isn’t a one-off bug; it’s symptomatic of how rapidly evolving agentic frameworks often outpace security-by-design practices. Atlassian has not yet issued an official patch or advisory, and users relying on Rovo for internal knowledge workflows should treat uploaded files as potential attack surfaces until remediation is confirmed.
