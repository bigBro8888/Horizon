Claude Fable 5 builds playable Raccoon Heist game from 2022 tweet

News time: 2026-08-06T04:28:17.431620+00:00 · Source: rss

Four years after tweeting a whimsical game concept—two raccoons sneaking past a futuristic building, dreamed up with GPT-3 and DALL-E—developer Simon Willison revisited the idea using Anthropic’s newly released Claude Fable 5. This time, instead of sketching ideas manually, he fed the original 2022 tweet screenshots into Claude Code for web and asked it to build a fully playable browser game. Within minutes, the AI generated HTML, CSS, and JavaScript code, committed it to a GitHub repository, and produced a working game where players control raccoons stealing loot while dodging guards and alarms.

The resulting 'Raccoon Heist' is a lightweight but functional 2D platformer: players jump, crouch, and collect coins while avoiding patrolling security bots. It runs entirely in the browser—no backend, no frameworks, just vanilla HTML/CSS/JS—and includes responsive controls, sound effects, and a simple win/lose condition. Willison didn’t write a single line of code; he only set up the GitHub repo, launched Claude Code for web, and prompted it to “build the game described in this tweet.” The AI autonomously created assets (including inline SVGs for raccoons and buildings), implemented game logic, and even added polish like keyboard shortcuts and visual feedback.

What makes this experiment notable isn’t just that an LLM wrote code—it’s how end-to-end the process was. Unlike earlier AI coding demos requiring heavy human iteration, Fable 5 operated as an autonomous agent: interpreting ambiguous visual+text input, planning file structure, writing and debugging code, committing to Git, and enabling GitHub Pages deployment—all without real-time human intervention. Willison configured GitHub Pages manually once, but after that, Claude handled versioning, branching, and incremental updates on its own.

This isn’t a AAA title—but it is a self-contained, shareable web app built from a four-year-old social media fragment in under an hour. The source code is public, the demo is live, and the video walkthrough shows the AI reasoning step-by-step: rejecting over-engineered frameworks, choosing canvas over DOM animation for performance, and even commenting its own code. For developers watching the rise of agentic tool use, Raccoon Heist is less about graphics or gameplay depth, and more about a milestone in intent-to-execution fidelity: turning a vague, nostalgic idea into shipped software—with zero manual coding.
