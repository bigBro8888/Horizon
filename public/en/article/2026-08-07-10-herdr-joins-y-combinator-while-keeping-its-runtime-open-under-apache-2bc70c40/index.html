Herdr joins Y Combinator while keeping its runtime open under Apache

News time: 2026-08-07T04:02:59.122148+00:00 · Source: hackernews

Herdr, an open-source terminal multiplexer designed specifically for multi-agent coding workflows, has been accepted into Y Combinator’s latest batch — a milestone that signals growing industry validation for infrastructure built to orchestrate AI coding agents inside the terminal. Unlike traditional tools like tmux or screen, Herdr treats AI agents as first-class runtime objects: it maintains live terminal panes, enables state inspection, supports direct agent attachment, and provides a pure socket API so agents themselves can spawn panes, read output, and coordinate asynchronously.

The announcement doubles as a reaffirmation of Herdr’s open-source commitment. Founder Can Yıldırım explicitly confirmed that the core runtime will remain under the permissive Apache 2.0 license — a deliberate shift from the earlier AGPL license. This change reflects a strategic choice to prioritize broad adoption and integration, especially by commercial users and embedded toolchains wary of AGPL’s copyleft requirements. As one commenter noted, the switch was made so developers could “use Herdr freely, without any problem.”

Herdr sits at the intersection of two fast-evolving domains: terminal-native developer tooling and multi-agent AI systems. In contrast to in-editor agents (e.g., Cursor or Claude Code CLI), Herdr operates entirely in the terminal — agnostic to editors, IDEs, or GUI layers — and emphasizes process visibility, shared memory coordination, and keyboard/mouse-first interaction. Its architecture enables real-time agent collaboration within isolated workspaces, each backed by its own git worktree — a design that helps avoid the overlapping, conflicting edits that plague uncoordinated parallel agents in large codebases.

The YC acceptance arrives amid increasing competition: YC itself has funded at least six other terminal- or agent-focused startups (including Superset, cmux, Orca, and Conductor), while non-YC players like Superlogical and Agentastic.dev are also pushing similar ideas. Community discussion reflects both enthusiasm and healthy skepticism — ranging from requests for clearer TUI demos and rate-limiting features, to nuanced debates about licensing trade-offs and long-term open-source sustainability. Ultimately, Herdr’s dual focus — on technical rigor and open accessibility — positions it not just as another multiplexer, but as foundational infrastructure for the next generation of collaborative, agent-driven development.
