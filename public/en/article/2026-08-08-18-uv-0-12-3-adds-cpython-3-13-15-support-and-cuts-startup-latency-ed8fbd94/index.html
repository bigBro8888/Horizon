uv 0.12.3 adds CPython 3.13.15 support and cuts startup latency

News time: 2026-08-08T02:59:47.745909+00:00 · Source: github

Astral has released uv 0.12.3 — a focused, high-impact patch that strengthens uv’s position as the fastest modern Python package manager. Released on August 7, 2026, this version delivers tangible improvements for developers working with large codebases, CI/CD pipelines, and automation scripts. Most notably, it officially supports CPython 3.13.15, aligning uv with the latest stable Python release just days after its announcement — a sign of tight integration with the upstream Python ecosystem.

Beyond Python version support, performance gains are front and center. On Linux, uv now initializes its workspace cache before spawning threads, shaving off measurable startup latency. It also avoids expensive /proc filesystem reads during Python interpreter discovery — a known bottleneck on heavily loaded or containerized systems. For dependency resolution, especially in projects with many conflicting version constraints, uv skips costly materialized range complement calculations, speeding up resolution without changing correctness.

The release also improves developer ergonomics and tooling interoperability. A new --output-format flag for uv cache size lets users choose between human-readable, raw bytes, or auto-detected output — useful for scripting and monitoring. Meanwhile, uv workspace metadata now streams JSON instead of buffering it entirely in memory, dramatically reducing peak RAM usage for monorepos with dozens or hundreds of packages. And when used with --quiet, it preserves clean JSON output while suppressing diagnostics — a small but critical fix for CI integrations expecting structured data.

Documentation updates reflect real-world usage: examples now follow PEP 740 attestation best practices for GitHub Actions publishing, and CLI argument names have been corrected (e.g., --pin-python instead of --python-pin). These may seem minor, but they reduce friction for teams adopting uv in production environments. As uv continues to replace pip, pip-tools, and pipx in Rust-powered workflows, releases like 0.12.3 show how deliberate, low-risk optimizations compound into meaningful developer velocity — without requiring major version upgrades or workflow overhauls.
