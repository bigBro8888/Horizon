Fru: Rust-powered random forest library outperforms scikit-learn by up to 100×

News time: 2026-08-11T03:10:09.506496+00:00 · Source: reddit

A new open-source machine learning library called Fru has emerged as a serious contender in the fast-growing space of high-performance tree-based models. Developed by researchers and recently published in the peer-reviewed journal Software X, Fru is a Random Forest implementation written entirely in Rust — a systems language known for memory safety and speed. Unlike traditional Python or R implementations, Fru leverages Rust’s zero-cost abstractions and parallel execution model to deliver dramatic runtime improvements, especially on large tabular datasets.

The library isn’t just fast — it’s designed for interoperability. Fru provides native Python and R bindings, enabling seamless integration without forcing users to abandon their existing data science workflows. In Python, it uses the Arrow PyCapsule interface, a standardized protocol that lets Fru exchange structured tabular data directly with pandas, Polars, PyArrow, and other Arrow-compatible libraries — all without requiring pyarrow as a hard dependency. This design avoids serialization overhead and enables zero-copy data sharing across language boundaries.

Benchmarks show striking performance gains: in Python, Fru routinely outperforms scikit-learn’s RandomForestClassifier by several-fold — and in some configurations, over 100 times faster. In R, it surpasses the widely used ranger package by dozens of percent, with speedups reaching several times depending on dataset size and feature count. Crucially, these gains aren’t limited to training alone — Fru also accelerates inference and includes an optimized, novel implementation of permutation importance, a popular technique for interpreting model behavior.

Permutation importance works by shuffling each feature’s values and measuring how much model performance drops — higher drops mean greater feature relevance. While scikit-learn and others compute this via repeated predictions (which can be slow), Fru’s version avoids redundant computation through careful caching and vectorized evaluation, yielding both speed and accuracy. Its layered architecture — separating core logic (Rust), data interchange (Arrow C Data Interface), and language-specific wrappers — makes future extensions (e.g., Julia or CLI tools) straightforward. For practitioners juggling scalability, interpretability, and ecosystem compatibility, Fru offers a rare combination of raw speed, cross-language flexibility, and scientific rigor.
