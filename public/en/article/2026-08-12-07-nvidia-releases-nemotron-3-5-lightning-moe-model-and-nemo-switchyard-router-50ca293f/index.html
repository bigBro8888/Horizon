Nvidia releases Nemotron 3.5 Lightning MoE model and NeMo Switchyard router

News time: 2026-08-12T03:28:47.092561+00:00 · Source: hackernews

NVIDIA has unveiled two complementary open-source tools designed to accelerate and optimize large language model (LLM) deployment: Nemotron 3.5 Lightning, a fast 30-billion-parameter Mixture-of-Experts (MoE) model, and NeMo Switchyard, a Rust-based library for intelligent, dynamic routing of inference requests across multiple models.

Nemotron 3.5 Lightning is engineered for high-throughput, low-latency tasks—especially those suited for always-on AI agents. With only ~3 billion parameters active per token (out of its total 30B), it achieves up to 4× higher output tokens per second than comparable dense models of similar scale. It’s available in BF16 and NVFP4 quantized variants on Hugging Face, and its evaluation recipes are published in the NeMo Gym framework for reproducibility.

NeMo Switchyard operates as a lightweight proxy that sits between user applications and backend LLMs. It supports both tuning-free and tunable routing strategies—balancing capability, latency, and cost without requiring changes to existing agent code. For example, a simple query might route to a small, fast model, while a complex coding task could be directed to a larger, more capable one. The system is designed to integrate seamlessly into production AI stacks, including those built with LangChain or LlamaIndex.

The announcement arrives amid growing industry focus on efficiency—not just raw scale. As hardware constraints tighten and inference costs mount, techniques like MoE sparsity and smart model selection are becoming essential infrastructure primitives. Still, early hands-on testing by developers reveals real trade-offs: several users report that MoE models—including Nemotron 3.5 Lightning and Qwen 3.6-35B—struggle with nuanced, multi-step coding tasks, despite their speed advantage. This highlights a persistent gap between throughput metrics and functional reliability in specialized domains.

Ultimately, Nemotron 3.5 Lightning and NeMo Switchyard don’t replace dense models—they reframe how we compose systems from them. By decoupling speed from capability and enabling adaptive routing, NVIDIA offers a pragmatic path toward scalable, cost-aware AI operations—where the right model runs the right job at the right time.
