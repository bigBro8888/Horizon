AAAI 2027 reviewers flag widespread lack of code submissions

News time: 2026-08-12T03:28:47.167456+00:00 · Source: reddit

A reviewer for AAAI 2027 has raised alarms about an unexpectedly low rate of code submissions among submitted papers — a development that contradicts the conference’s long-standing and publicly stated emphasis on reproducibility. In a candid Reddit post, the reviewer notes they expected nearly all submissions to include working code and detailed appendices, given AAAI’s explicit reproducibility checklist requirements and repeated policy statements since at least AAAI 2025. Instead, they found many papers arriving without any accompanying implementation — prompting them to pause and seek community guidance on how heavily to weigh this omission during scoring.

This isn’t merely a procedural hiccup. AAAI has required authors to complete a formal reproducibility checklist since 2025, covering data availability, hyperparameter settings, computational environment details, and — critically — whether code is publicly shared. The checklist is mandatory for submission, yet its enforcement appears uneven: while some authors voluntarily release code (often later on arXiv alongside their paper), others treat it as optional or omit it entirely. The reviewer underscores their own practice — sharing code early, then publishing it with the preprint — as both ethically sound and strategically safe, dismissing fears of idea theft as unfounded in today’s collaborative AI research culture.

The timing adds urgency. With generative AI tools now capable of drafting empirical sections and even simulating results, the absence of verifiable code makes it harder to distinguish rigorously validated work from plausible but untestable claims. As one arXiv study from August 2024 observed, early-career researchers often want to share code but lack training in packaging, documentation, or ethical curation — suggesting the gap may stem less from unwillingness than from structural support deficits. Meanwhile, broader trends show code-sharing rates remain modest: a scoping review estimated only 15.8% of AI-related prediction studies shared code in 2025, varying widely by venue and region.

What’s at stake goes beyond peer review fairness. Reproducibility is foundational to scientific credibility — especially in fast-moving fields like AI, where real-world deployments hinge on trustworthy methods. If conferences like AAAI fail to consistently enforce code disclosure, they risk normalizing opaque research practices. The reviewer’s call for collective reflection signals not just frustration, but an opening: a chance to align policy, incentives, and infrastructure so that sharing code becomes routine — not exceptional.
