uv 0.12.4 adds post-quantum TLS support and PEP 723 parsing fixes

News time: 2026-08-14T03:28:58.233860+00:00 · Source: github

The Python tooling ecosystem just got a quiet but meaningful security upgrade: uv 0.12.4, released on August 13, 2026, introduces experimental support for post-quantum TLS key exchange — a forward-looking step to protect package downloads against future quantum computing attacks. While still opt-in, this change reflects growing industry awareness that cryptographic agility matters long before quantum computers break current standards. Alongside security, the release sharpens developer ergonomics: it now parses PEP 723 inline script metadata more robustly — catching malformed closing tags with trailing whitespace — and improves PEP 508 dependency string handling, especially around nonstandard version wildcards like >= 3.5.*.

Beyond correctness, uv continues its performance push. Two resolver optimizations stand out: one coalesces gaps in version ranges during dependency resolution, speeding up cases where many consecutive versions are unavailable; another skips intermediate JSON parsing when reading PyPI’s Simple API metadata, deserializing directly from raw bytes. These tweaks matter most in large or constrained environments — think CI pipelines or embedded toolchains — where milliseconds add up across thousands of installs.

The release also ships several preview features aimed at advanced workflows. A new --no-install-project flag for uv check lets developers verify dependencies without building or installing their project — useful for pre-commit hooks or isolated linting. Meanwhile, uv check now inherits uv’s color and progress settings (including quiet mode) when invoking the ty subprocess, making output consistent and script-friendly.

Bug fixes round out the update: virtual environment launchers now correctly use pythonw.exe on Windows for GUI apps; uv lock no longer fails if .venv exists but is unusable; and interpreter cache isolation has been tightened to prevent cross-contamination when PYTHONEXECUTABLE or __PYVENV_LAUNCHER__ are overridden. Even small details — like preserving inline comments during uv add or showing proper error formatting for invalid uv version --bump inputs — signal mature CLI design discipline.

For users, installation remains frictionless: shell or PowerShell one-liners fetch prebuilt binaries across macOS (Intel/Apple Silicon), Windows (x86-64/ARM64), and Linux (x86-64/aarch64). No compilation required — just download, verify checksums, and go. As uv solidifies its role as a drop-in replacement for pip and Poetry, releases like 0.12.4 quietly reinforce why speed, correctness, and proactive security matter — not just in headlines, but in every uv install.
