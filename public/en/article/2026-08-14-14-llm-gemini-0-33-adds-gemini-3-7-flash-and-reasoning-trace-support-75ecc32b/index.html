llm-gemini 0.33 adds Gemini 3.7 Flash and reasoning trace support

News time: 2026-08-14T03:28:57.121195+00:00 · Source: rss

The open-source LLM plugin llm-gemini has released version 0.33 — its first major update in months — significantly expanding model support and developer capabilities. Most notably, it now integrates Google’s newly launched Gemini 3.7 Flash, alongside earlier Flash variants (3.6 Flash and 3.5 Flash Lite) and two embedding models: gemini-embedding-2 and gemini-embedding-001. This brings the plugin up to date with Google DeepMind’s latest lightweight, high-performance models optimized for speed and cost-efficient reasoning across knowledge-intensive domains like finance and biosciences.

Beyond model coverage, the release unlocks powerful features enabled by compatibility with the core LLM framework version 0.32. Developers can now visualize reasoning traces — intermediate steps a model generates while solving complex problems — directly in CLI output. More practically, server-side tool execution is now supported: users can invoke tools like CodeExecution from the command line, letting Gemini 3.7 Flash run Python code remotely and return results. For example, llm -m gemini-3.7-flash -T CodeExecution 'use python to calculate (factorial of 13) * 3' executes the calculation on the provider’s infrastructure, not locally.

The update also highlights real-world quirks in multimodal output. Simon Willison tested Gemini 3.7 Flash’s image generation by prompting it to draw pelicans riding bicycles — a whimsical but revealing stress test. While Safari rendered the SVG output correctly (including filters and styling), Chrome and Firefox failed to display the pelican entirely due to stricter parsing of empty <filter> elements. This illustrates how model outputs interact unpredictably with browser rendering engines — a subtle but important caveat for developers building UIs around generated assets.

Though lightweight and fast, Gemini 3.7 Flash isn’t just about speed: benchmarks show it outperforms 3.6 Flash by over 12 percentage points on GDP.pdf (34.0% vs 22.0%), a complex document understanding task, and nearly doubles success rates on AutomationBench (30.4% vs 17.0%). For developers using llm-gemini in automation pipelines, data analysis workflows, or CLI-based AI agents, this release delivers both broader model choice and deeper operational control — all without requiring changes to existing tooling or infrastructure.
