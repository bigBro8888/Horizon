LLM hallucinates tags then matches them to existing ones via embeddings

News time: 2026-08-15T02:18:20.855725+00:00 · Source: rss

Many bloggers and content creators face a tedious, unsolved problem: how to consistently tag years’ worth of untagged posts. Simon Willison—creator of Datasette and a longtime advocate for pragmatic tooling—recently highlighted an elegant workaround proposed by Doug Turnbull. Instead of wrestling with the combinatorial explosion of matching new content against 1,856 existing blog tags directly, Turnbull suggests flipping the task: ask an LLM to imagine plausible, semantically appropriate category names from scratch, without seeing the real tag list.

This 'hallucinated classification' step is deliberately open-ended. The prompt guides the model using realistic examples—like 'Furniture / Living Room Furniture / Coffee Tables & End Tables / Coffee Tables'—to teach it the hierarchical, domain-specific shape of tags, not their exact vocabulary. For a query like 'brown coffee table', the model might output something like 'Furniture / Living Room / Coffee Tables / Wood Finish', even if 'Wood Finish' doesn’t exist in the tag corpus. That’s fine—the hallucination only needs to be semantically close.

The second, crucial step is vector-based retrieval. Each of the 1,856 real tags is embedded (e.g., using Sentence-BERT or OpenAI’s text-embedding-3-small), and the hallucinated tag string is embedded too. A nearest-neighbor search then finds the existing tag(s) most similar in semantic space—say, 'Furniture / Living Room Furniture / Coffee Tables & End Tables / Coffee Tables'. This decouples prompting from vocabulary size, sidestepping token limits and brittle exact-match logic.

What makes this approach especially practical is its tolerance for imperfection: hallucinations don’t need to be real tags, only representative. It also avoids expensive fine-tuning or custom classifiers—just prompt engineering + off-the-shelf embedding models. While the original post cuts off mid-example, the core idea has clear legs for CMSs, documentation sites, and archival projects where tag taxonomies evolve organically over time. It’s less about correctness and more about scalable, human-aligned approximation.
