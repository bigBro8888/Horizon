Identical GRPO training hurt medium-sized LLM most despite same setup

News time: 2026-08-20T02:21:37.165049+00:00 · Source: reddit

A researcher trained three custom LLMs from scratch—353M (V1), 316M (V2), and 672M (V3)—using identical pretraining data (FineWeb-Edu, plus code/math for V3), architecture tweaks, and a synthetic arithmetic curriculum. All models then underwent identical supervised fine-tuning (SFT) followed by Group Relative Policy Optimization (GRPO), a PPO variant that replaces the value network with group-averaged rewards. Surprisingly, GRPO degraded performance across the board on WikiText perplexity: V1 barely changed (+0.2%), V2 collapsed (+52%), and V3 declined modestly (+5%). Downstream tasks like ARC-Easy and GSM8K mirrored this non-monotonic pattern—V3 lost ~6 points on ARC-Easy, while GSM8K remained near zero for all three.

The experimental design was unusually clean: same reward function (checking only for a correct final number, no length penalty), same KL coefficient (0.02), frozen SFT policy as reference, and k3 reward estimation. Yet outcomes diverged sharply—not by scale alone, but in ways that defy simple scaling intuition. V2, the smallest in parameter count but using Differential Attention + GQA, suffered worst; V3, largest and using Exclusive Self Attention (XSA) + GQA, fared best. This suggests architectural differences—not just size—may dominate GRPO’s stability.

Several confounds complicate interpretation. First, GRPO was trained on bare solver templates, while SFT used chat formatting—so evaluating GRPO outputs with standard benchmarks may measure format mismatch, not capability loss. Second, the sequential arithmetic curriculum lacked re-evaluation of earlier stages, raising the possibility of catastrophic forgetting rather than general degradation. Third, no explicit reward penalty discouraged over-generation, leading models to output excessively long solutions without stopping—a known failure mode when reward shaping ignores token efficiency.

Still, the core finding stands: GRPO’s behavior is neither reliably beneficial nor predictably harmful across models—even under tightly controlled conditions. The author released all nine checkpoints (base/SFT/GRPO ×3) on Hugging Face and built an interactive Space to compare outputs side-by-side. Their custom GQA-aware KV cache also delivered strong inference speedups (up to 10.1×), confirming engineering rigor. Ultimately, this work highlights how alignment techniques can interact unexpectedly with model internals—urging caution before treating RLHF variants like GRPO as plug-and-play upgrades.
