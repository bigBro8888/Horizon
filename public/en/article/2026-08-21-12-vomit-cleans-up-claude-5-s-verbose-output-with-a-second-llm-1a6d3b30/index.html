Vomit cleans up Claude 5’s verbose output with a second LLM

News time: 2026-08-21T02:36:17.710092+00:00 · Source: hackernews

A new open-source tool called Vomit tackles one of the most persistent frustrations in practical LLM use: overly wordy, stylistically inconsistent, and self-indulgent responses—especially from Anthropic’s Claude 5. Rather than relying on brittle prompt engineering or manual editing, Vomit acts as a lightweight wrapper that feeds Claude’s raw output into a secondary LLM (like GPT-4 or local models) specifically tasked with editing for clarity, concision, and conversational tone. The result isn’t just shorter text—it’s more reliable, human-aligned communication that preserves factual intent while stripping away filler, pseudo-profound detours, and unearned self-praise.

The tool emerged from real-world friction. Developers report that even well-crafted system prompts and agent frameworks like Anthropic’s AGENTS.md fail to constrain Claude’s verbosity over long sessions. As one HN commenter put it, it’s astonishing that such basic output control remains unreliable—despite years of model iteration and vendor promises. Vomit sidesteps this by treating LLM output not as final text, but as draft material requiring editorial review—a paradigm shift toward postprocessing as standard practice.

Technically, Vomit is minimal: it’s a Python script that chains two API calls—first to Claude, then to an editor LLM—with a tightly scoped instruction prompt. That prompt explicitly targets hallmarks of ‘Claudish’ prose: subject–verb mismatches, roundabout logic, rhythmic distractions, and unsolicited self-congratulation. It doesn’t summarize or paraphrase; it rewrites in place, keeping all original details intact. Users can swap editor models freely, making it vendor-agnostic despite its initial focus on Claude.

Beyond utility, Vomit sparks deeper questions about model trust and compositional design. If we need one LLM to fix another’s output, what does that say about reliability, transparency, or interface design? Critics on Hacker News raise valid concerns about latency, cost, and the irony of compounding LLM dependence—but also acknowledge that this reflects a broader industry trend: moving from monolithic models toward modular, pipeline-based AI systems where preprocessing, inference, and postprocessing are distinct, composable layers.
