repo2nb 0.2.0 adds dependency resolution reverse mode and incremental sync

News time: 2026-08-22T02:20:09.072287+00:00 · Source: reddit

repo2nb 0.2.0 is a major update to an open-source command-line tool designed to bridge the gap between GitHub repositories and interactive notebook environments like Kaggle and Google Colab. Instead of manually copying code, installing dependencies, and restructuring files—often a tedious and error-prone process when reproducing someone else’s ML research or tutorial—the tool now automates the entire conversion pipeline. It walks the repository’s file tree, intelligently resolves dependencies using multiple fallback strategies, and generates a fully runnable notebook with properly ordered cells, including setup instructions and executable code.

What sets version 0.2.0 apart are three novel capabilities: smart dependency resolution, reverse-mode reconstruction, and one-way incremental syncing. The dependency resolver tries Poetry’s export first, then uv (a fast Python package installer and resolver), then requirements.txt, and finally falls back to static AST-based import scanning if no lock or manifest file exists. Crucially, all paths produce the same output: a plain %pip install cell—meaning Poetry or uv are only needed during notebook generation, not at runtime on Kaggle or Colab. This keeps notebooks portable and environment-agnostic.

The new reverse mode (repo2nb reverse <notebook>) lets users reconstruct the original source repository from a generated notebook. Every cell embeds metadata—including its original file path and content hash—so repo2nb can faithfully restore directory structure and contents. Safety checks prevent accidental overwrites: it refuses to write into non-empty directories unless --force is explicitly used. Meanwhile, incremental sync (repo2nb sync <repo>) enables lightweight updates: newly added files become new cells, modified files update in place, and deleted files vanish from the notebook—all previewable with --dry-run.

A Colab-specific target has also been added, complete with its own authentication cell using google.colab.userdata.get, decoupling it from Kaggle’s secrets flow. Installation remains simple: pip install repo2nb. The project is hosted on GitHub and welcomes feedback—especially on whether the current dependency fallback order matches real-world usage patterns across diverse Python projects.
