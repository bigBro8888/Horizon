llm-openrouter 0.7 adds Shell, WebFetch, and WebSearch tools

News time: 2026-08-22T02:20:08.251250+00:00 · Source: rss

Simon Willison has released llm-openrouter 0.7, a major update to his popular Python plugin that bridges the LLM command-line tool with OpenRouter’s model marketplace. The release significantly improves integration with reasoning-focused large language models — especially those requiring structured tool calling — by aligning with LLM 0.32, the latest version of the foundational CLI utility. This compatibility upgrade isn’t just cosmetic: it unlocks native support for server-side tool execution, a capability introduced in LLM 0.32 that shifts tool logic from client-side Python functions to provider-hosted capabilities.

The most tangible change is the addition of three new built-in server-side tools: Shell (for executing system commands on the server), WebFetch (for retrieving raw HTML or JSON from URLs), and WebSearch (for performing real-time web queries via OpenRouter’s backend). These tools are invoked directly from the command line using flags like -T WebSearch, eliminating the need for users to write and maintain custom Python handlers. Crucially, they rely on OpenRouter’s Responses API — a beta feature that provides OpenAI-compatible interface access to dozens of models while also exposing standardized tool-calling semantics across providers.

This shift reflects a broader trend in the LLM CLI ecosystem: moving away from purely client-side orchestration toward hybrid workflows where the server handles complex, stateful, or external operations. For developers building automation scripts, research pipelines, or local AI assistants, these tools reduce boilerplate and improve reliability — for example, fetching live documentation before prompting a model, or running diagnostic commands during debugging. The plugin remains lightweight and installable via pip or uv tool install, preserving its appeal to developers who value simplicity and composability.

While llm-openrouter doesn’t replace full-stack frameworks like LangChain, it fills a distinct niche: empowering command-line users to leverage production-grade model routing and emerging tool standards without writing code. With OpenRouter’s growing model catalog and LLM’s expanding tooling infrastructure, this release positions the plugin as a pragmatic bridge between terminal-based workflows and modern, tool-aware AI APIs.
