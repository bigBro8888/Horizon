By-Its-Cover uses CLIP embeddings and NER to recommend books from cover images

News time: 2026-08-22T02:20:09.072119+00:00 · Source: reddit

A new open-source recommendation system called By-Its-Cover lets users discover books by uploading or dragging book cover images — no title or author required. Built by a solo developer aiming to sharpen software engineering and ML skills, the site (by-its-cover.com) combines computer vision, natural language processing, and collaborative filtering into one lightweight, deployed application. At its core, it treats book covers not just as pictures, but as rich semantic signals — using CLIP embeddings to encode visual meaning and match books based on visual similarity alone.

The system operates in two parallel modes: semantic cover search and personalized recommendations. For search, users can upload a cover image or type keywords. Behind the scenes, CLIP generates an embedding for the image, then retrieves visually similar books from a vector database. Simultaneously, a GLiNER model extracts named entities (e.g., 'Neil Gaiman', 'fantasy', 'Norse mythology') from the query text, which are used to search the Hardcover API — a real book metadata source. The results from both paths are fused using Reciprocal Rank Fusion, a standard technique that balances ranking confidence across heterogeneous sources.

Personalization kicks in once users sign up and rate books with 'Dislike', 'Like', or 'Love'. A two-tower neural collaborative filtering model learns user–book preferences from this feedback, and a Determinantal Point Process diversifies the final list — preventing repetitive editions of the same book from clustering together. Recommendations update every two hours for fine-tuning, while full model retraining runs daily at 8:30 AM EST. The entire stack — frontend, backend, vector storage, auth, and async jobs — runs on AWS, orchestrated via Terraform and GitHub Actions.

Despite its functional polish, By-Its-Cover remains intentionally modest in scope: it currently indexes only a few thousand books, limiting coverage. Its growth is organic — each keyword search triggers asynchronous scraping and embedding of newly discovered titles, gradually expanding the vector database. Future plans include swapping CLIP for SigLIP, adding cover preference selection for implicit feedback, and overhauling the UI with frontend help. As a portfolio project, it prioritizes clean architecture and practical deployment over algorithmic novelty — making it a rare example of a fully shipped, multimodal recommendation system built end-to-end by one person.
