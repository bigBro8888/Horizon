Person trains a perceptron by hand on a Casio scientific calculator

News time: 2026-08-22T02:20:09.072187+00:00 · Source: reddit

In a striking demonstration of machine learning fundamentals, a Reddit user trained a single-neuron perceptron entirely by hand—using only a Casio FX-82CE X scientific calculator. This device has no programming capability, no graphical interface beyond a basic monochrome LCD, and no memory for storing scripts or iterative loops. Every weight update, every pixel multiplication, every sum across the 3×3 downsampled MNIST images had to be computed manually, recorded on paper, and verified step-by-step.

The task was binary classification: distinguishing handwritten digits '0' and '1'. To make it feasible on hardware with no automation, the user reduced each MNIST image to just nine pixels (3×3), binarized them (0 or 1), and fed them into a fully connected layer that collapsed directly to one output neuron. Classification was threshold-based: output > 0 meant '1', otherwise '0'. With no bias term, the decision boundary always passed through the origin—a known limitation—but the model still learned meaningful patterns.

Using only six training examples—three zeros and three ones—the user performed perceptron-style updates by hand, adjusting weights whenever a prediction was wrong. The final hand-calculated weights were 0 0 1 -1 2 -1 -1 1 -1. When tested on a held-out validation set from MNIST, this minimal model achieved 67.04% accuracy—remarkably, it classified all '1's correctly but struggled with '0's, suggesting the learned decision boundary favored positive activation for vertical stroke features common in '1'.

For comparison, the same architecture trained computationally with stochastic gradient descent (SGD) over 1,000 epochs on the full MNIST 0/1 training split reached 98.96% validation accuracy. Its learned weights—like 10.651 for the center pixel and large negative values for corners—reveal how SGD exploits spatial structure more systematically. Yet the hand-trained version remains pedagogically powerful: it strips away abstraction, forcing direct engagement with weight initialization, error signals, and the geometric meaning of linear separation. It’s not about performance—it’s about making the invisible machinery of ML visible, one keystroke at a time.
