MS Paint and Photos embed invisible GUID watermarks in all locally edited images

News time: 2026-08-25T02:22:44.911583+00:00 · Source: hackernews

A recent technical investigation by Xusheng Li has revealed that Microsoft Paint and Microsoft Photos—two long-standing, seemingly simple Windows applications—are silently embedding invisible, non-removable GUIDs into images users create or edit locally. This occurs even when no cloud AI services are involved: for example, when using a local AI model to remove a background or enhance a photo, the app still contacts a Microsoft server to moderate the prompt, receives a unique GUID in response, and writes it into the image’s metadata as an invisible watermark.

The watermark is not visible to the eye and cannot be toggled off in settings. It resides in the C2PA (Coalition for Content Provenance and Authenticity) manifest—a standardized structure used to record image provenance—but unlike typical C2PA use cases (e.g., verifying AI-generated content), this implementation embeds a server-issued identifier without user knowledge or consent. Crucially, the GUID is tied to the user’s Microsoft account infrastructure, meaning it could, in theory, be linked back to personal information if subpoenaed.

This behavior contradicts longstanding expectations of MS Paint as a lightweight, offline-first tool. Unlike visible watermarks added intentionally by creators, this one operates entirely in the background—no dialog, no opt-in, no documentation. Even users who disable Copilot, avoid cloud features, or run fully local AI models are affected, because the watermarking logic is baked into the apps’ core editing flow. The discovery was made through reverse engineering, not official documentation, underscoring how opaque the mechanism is.

Privacy advocates and developers have raised alarms about the implications: from eroding digital anonymity to enabling mass identification via legal requests. As one commenter noted, a copyright claimant could serve Microsoft with a subpoena and potentially obtain the user’s full name, address, email, and phone number—simply based on a meme shared online. While Microsoft has previously rolled back similar overreaches (e.g., auto-stamping Copilot labels on Azure DevOps commits), this GUID watermarking appears persistent and deeply integrated. For now, there is no known way to disable or strip it without damaging image integrity or losing metadata entirely.
