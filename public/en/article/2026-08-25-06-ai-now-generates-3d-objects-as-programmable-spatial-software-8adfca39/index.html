AI now generates 3D objects as programmable spatial software

News time: 2026-08-25T02:22:45.061473+00:00 · Source: reddit

A new research paradigm reimagines AI-generated 3D content—not as static meshes, but as spatial software: executable, hierarchical code that encodes geometry, articulation, animation logic, and environment-aware behavior from the moment of creation. The work, introduced by a co-author on Reddit and demonstrated live at nova3d.xyz, shows 3D objects that naturally bend, rotate, and adapt—no manual rigging or post-processing required. Each object is built from logical parts (e.g., hinges, sockets, parent-child hierarchies), enabling real-time responsiveness to hardware constraints: the same object renders simply on a mobile browser yet unlocks rich physics and deformation in a high-end game engine.

This approach diverges sharply from mainstream AI 3D generators like Luma, Spline, or Kaedim, which output monolithic triangle meshes—essentially inert digital sculptures. Those require separate steps for rigging, skinning, LOD management, and interactivity. In contrast, spatial software objects embed those capabilities natively. Under the hood, large language models are guided—not to describe shapes, but to write structured, topologically aware spatial programs using domain-specific abstractions (e.g., 'articulated armature', 'adaptive render policy'). The result resembles object-oriented programming extended into 3D space: classes define not just data and methods, but spatial relationships and physical affordances.

The trade-off is clear: current implementations lag in rendering highly organic, free-form surfaces (e.g., flowing hair, wrinkled fabric) compared to diffusion-based mesh generators. But the authors argue this is a temporary gap—one that will narrow as LLMs improve at spatial reasoning and multimodal code generation. What’s more compelling is the long-term vision: treating 3D authoring as coding, where designers write or prompt spatial logic instead of sculpting vertices. This bridges generative AI, real-time graphics, and edge deployment—enabling lightweight, adaptive assets for AR/VR, simulation, and industrial design.

Live demos at nova3d.xyz illustrate the concept concretely: rotating robotic arms adjust joint limits based on device capability; modular furniture reconfigures its LOD tree when zoomed; a character’s facial expression changes resolution dynamically without breaking topology. A public GitHub repository supports further exploration. If successful, this could shift how engines like Unity and Unreal ingest AI content—not as static imports, but as executable modules with built-in APIs.
