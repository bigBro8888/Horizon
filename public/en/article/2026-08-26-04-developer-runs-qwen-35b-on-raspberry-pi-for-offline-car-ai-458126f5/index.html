Developer runs Qwen-35B on Raspberry Pi for offline car AI

News time: 2026-08-26T02:38:28.019209+00:00 · Source: hackernews

A developer has built a functional, offline-capable automotive AI assistant that runs entirely on a Raspberry Pi—powered by a quantized Qwen-35B large language model. Unlike typical cloud-dependent car apps, this system reads real-time vehicle data via OBD-II, pulls remote commands (like locking doors or adjusting AC) from manufacturer cloud APIs, and consults a full digital copy of the car’s owner manual. It answers practical maintenance questions—such as 'When and what oil should I use?'—without needing internet access.

The project, named CarWatch and hosted on GitHub, leverages recent advances in LLM quantization and inference optimization. Using a custom llama.cpp build and MagicQuant GGUF quantization, the developer achieved stable inference of Qwen 3.6-35B-A3B on a Raspberry Pi 5 with 16GB RAM—a feat previously considered impractical for models of this scale. The system operates as a local 'car agent' that can function autonomously but also collaborates with a cloud-based 'agent family' when online, enabling features like automatic train booking if the car breaks down.

What makes CarWatch distinctive is its hybrid architecture: deep local reasoning grounded in vehicle-specific knowledge (OBD telemetry + manual + service history), plus optional coordination with more powerful frontier models in the cloud. This bridges two often-opposed paradigms—privacy-preserving edge AI and scalable multi-agent intelligence. For example, if the car stalls, the local agent detects the fault, shares context with cloud agents, and triggers downstream actions (e.g., checking transit schedules) without user intervention.

Still, the project faces real-world constraints. Community feedback highlights concerns about model accuracy on fine-grained automotive details—like year-specific oil specs or engine variants—and questions whether the offline capability is undermined by reliance on a proprietary 'Groupmind' service for inter-agent messaging. Others note hardware cost inflation: a 16GB Raspberry Pi now costs significantly more than early models, raising accessibility questions. Yet racing-car developer Robdel12 called it 'really freaking sweet', underscoring its technical ambition and tangible utility.
