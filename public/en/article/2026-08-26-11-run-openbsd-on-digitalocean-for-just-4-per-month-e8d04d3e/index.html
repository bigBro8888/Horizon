Run OpenBSD on DigitalOcean for just $4 per month

News time: 2026-08-26T02:38:28.019183+00:00 · Source: hackernews

A new hands-on tutorial demonstrates how to deploy OpenBSD—a security-focused, Unix-like operating system—on DigitalOcean’s entry-level $4/month droplet. The guide walks readers through creating a custom droplet using DigitalOcean’s FreeBSD image as a base, then replacing its kernel and userland with OpenBSD via manual installation over SSH. It emphasizes minimalism: stripping down services, disabling unused daemons, and configuring only what’s needed for lightweight web hosting—such as httpd and acme-client for HTTPS.

This setup is notable because DigitalOcean has historically prioritized Linux distributions, with official OpenBSD support absent from its marketplace. While OpenBSD isn’t natively listed among one-click apps, the tutorial exploits DigitalOcean’s flexibility—specifically its ability to boot from custom kernels and accept manual OS installations on KVM-based droplets. Users must first launch a FreeBSD droplet (to gain SSH access and disk control), then overwrite it with OpenBSD binaries and configuration. The process demands comfort with command-line tools, partitioning, and OpenBSD’s install philosophy—but avoids requiring physical hardware or dedicated servers.

The article also highlights trade-offs inherent in this approach. For example, it advises removing most OpenBSD ‘sets’ (prepackaged software bundles) to save space and reduce attack surface—a suggestion that later drew criticism from experienced users in the comments. Others point out that while $4/month sounds appealing, competing providers like Vultr, OVH, and smaller indie hosts often offer more RAM (e.g., 2 GB for ~$5), better DDoS mitigation, or native OpenBSD support. Still, DigitalOcean’s API, documentation, and global infrastructure make it an accessible starting point for BSD newcomers experimenting with cloud-hosted Unix systems.

Ultimately, the tutorial reflects a broader trend: renewed interest in lightweight, auditable OSes for small-scale infrastructure. OpenBSD’s emphasis on correctness, proactive security, and clean code appeals to developers and sysadmins seeking alternatives to bloated Linux stacks. Though not suited for high-traffic or complex applications, this $4 droplet serves well for static sites, personal blogs, CI test runners, or learning modern BSD administration—especially when paired with OpenBSD’s built-in httpd, relayd, and letskencrypt tooling.
