uv 0.12.6 released with cache optimizations and new workspace metadata sync

News time: 2026-08-26T02:38:28.489403+00:00 · Source: github

Astral-sh has released uv version 0.12.6, the latest maintenance update to its high-performance Python package manager written in Rust. Released on August 25, 2026, this patch builds on uv’s reputation for speed and reliability—offering refinements rather than revolutions. Users upgrading from earlier versions will notice subtle but meaningful improvements: faster cache cleanup reporting, more precise warning suppression, and better handling of edge cases in dependency resolution and virtual environment setup.

The release includes several performance enhancements powered by profile-guided optimization (PGO), now enabled across all major platforms—including Linux x86-64 and ARM64, Windows x86-64, and macOS ARM64. This means binaries shipped with 0.12.6 are not just compiled efficiently, but trained on real-world usage patterns to deliver measurable latency reductions during operations like uv sync and uv pip compile. Additionally, a long-standing issue with byte-size formatting—where values under 1 KiB showed unnecessary decimal places—has been fixed, improving CLI readability.

Two preview features stand out for developers managing complex Python workspaces. First, uv workspace metadata --sync --exact allows users to prune packages that fall outside a specific dependency resolution, helping enforce strict reproducibility. Second, the new artifact-hash-filtering preview ensures that hash generation during uv pip compile --generate-hashes respects binary-only or source-only constraints—addressing a prior mismatch where hashes were generated for packages that wouldn’t actually be installed. These previews signal uv’s direction toward tighter control over artifact provenance and build-time fidelity.

Bug fixes cover a wide surface: from preventing segfaults in RISC-V binaries to correctly resolving Git commit pins (avoiding accidental branch matches), preserving recursive extra dependencies with mixed environment markers, and fixing credential reuse during tool upgrades. The team also raised the minimum supported Rust version to 1.96 and added Docker images for Python 3.15 release candidates—showing proactive alignment with upstream language evolution. While no single change is transformative, the cumulative effect strengthens uv’s role as a robust, production-ready alternative to traditional Python tooling.
