Experiential launches open-source Rust LLM gateway with traffic-powered model training

News time: 2026-08-28T12:44:25.523728+00:00 · Source: hackernews

Experiential, a new open-source model routing gateway built in Rust, has launched on Hacker News — offering developers a unified interface to manage local, frontier (e.g., OpenAI, Anthropic), and open-weight LLMs. Unlike commercial gateways that charge markup or lock users into proprietary infrastructures, Experiential is fully open source, runs on your own hardware, and charges zero fees — even on its hosted version. Its core promise is simplicity without compromise: one configuration format across 1000+ models, automatic daily updates via a codex agent that opens GitHub PRs, and sub-2ms latency overhead — whether you bring your own API keys (BYOK) or use Experiential’s managed keys.

What sets Experiential apart is its opt-in, privacy-conscious approach to learning from real usage. By ingesting standardized OpenTelemetry (OTel) traces — structured records of request flows, latency, and errors across distributed systems — it identifies representative user tasks. Then, using text-based world models (simulated environments where LLMs predict next states), it runs rollouts across candidate models, evaluates outputs with an LLM judge, and trains a nearest-neighbor classifier over prompt embeddings. The result? A dynamic, per-request model selector that balances cost and quality better than static routing — and can also suggest cache optimizations or fine-tuning opportunities.

The project explicitly avoids vendor lock-in: it supports local inference backends like vLLM and Ollama, integrates seamlessly with major cloud providers, and allows mixing self-hosted and API-based models in the same pipeline. Its architecture is built for concurrency and resilience, with detailed documentation on high-availability deployment patterns. Importantly, all traffic-based model training is strictly opt-in, transparent, and designed to work within existing encryption boundaries — no raw prompts are stored or shared without consent.

While competitors like LiteLLM and Bifrost focus on protocol translation and load balancing, Experiential adds a layer of adaptive intelligence — turning operational telemetry into actionable model improvements. It doesn’t replace inference engines; instead, it sits upstream, learning from how models actually perform in production. For teams tired of manually tuning routing rules or paying for opaque ‘smart’ layers, Experiential offers a rare combination: open code, measurable latency, and a path toward self-improving infrastructure.
