uv 0.12.7 adds support for s390x, ppc64le, and loongarch64 Linux

News time: 2026-08-28T12:44:26.068450+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.7, delivering meaningful improvements in portability, security, and cache reliability. Released on August 27, 2026, this patch release expands uv’s hardware support to three historically underrepresented Linux architectures: IBM’s s390x (used in mainframes), PowerPC 64-bit little-endian (ppc64le, common in high-performance and embedded systems), and LoongArch64 (the domestically developed 64-bit ISA from China’s Loongson Technology). This marks a concrete step toward broader enterprise and sovereign-cloud adoption — especially where legacy or specialized infrastructure remains critical.

Beyond architecture support, uv 0.12.7 strengthens its integration with Azure Storage. When configured via the UV_AZURE_ENDPOINT_URL environment variable, uv now automatically retries downloads using explicitly provided credentials if anonymous access is denied — eliminating manual workarounds for private or restricted endpoints. Equally important are two robustness fixes: source archives with hash mismatches are now rejected before extraction and caching, preventing corrupted or tampered packages from polluting the local cache; and managed Python installations are correctly replaced during upgrades to newer builds of the same Python version, avoiding stale interpreter binaries.

A notable preview feature also arrives: the content-addressed cache. Enabled via the --preview flag, it uses cryptographic directory hashes (not just wheel filenames) to deduplicate extracted wheels — meaning identical packages built from different sources but with identical contents will share one cached copy. This improves disk efficiency and reproducibility, especially in CI/CD and multi-tenant environments.

While not a major feature release, 0.12.7 reflects uv’s maturing focus on correctness, cross-platform resilience, and real-world deployment constraints. It ships prebuilt binaries for all newly supported targets — including powerpc64le-unknown-linux-gnu and loongarch64-unknown-linux-gnu — and maintains uv’s signature speed and low-resource footprint. For teams managing Python workloads across heterogeneous infrastructure — from cloud VMs to on-prem mainframes — this update quietly removes several friction points that previously required custom tooling or workarounds.
