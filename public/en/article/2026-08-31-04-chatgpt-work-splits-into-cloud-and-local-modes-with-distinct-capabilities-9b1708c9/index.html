ChatGPT Work splits into cloud and local modes with distinct capabilities

News time: 2026-08-31T07:00:59.690322+00:00 · Source: rss

OpenAI launched ChatGPT Work on July 9, 2026 — not as a single new tool, but as two functionally separate experiences: one running entirely in the cloud, the other executing directly on users’ machines. Simon Willison’s deep dive clarifies this duality, which OpenAI itself has obscured through branding. The cloud version — accessible via chatgpt.com or mobile apps — offers advanced agent capabilities like internet-connected code execution, headless Chrome browsing, persistent shared file storage, and scheduled prompt automations. It also unlocks granular model selection: users can choose among GPT-5.6 Sol, Luna, or Terra, each with reasoning levels from Light to Ultra — features absent in the standard Chat interface.

The local version runs only in the newly rebranded ChatGPT desktop app (formerly Codex), granting direct access to files, folders, and system programs without uploading data to the cloud. Willison notes it feels like Codex “re-skinned for non-developers” — retaining its agent-like autonomy while softening the developer-centric UI. Crucially, both versions are gated behind the $20/month subscription tier; free users and $8/month ChatGPT Go subscribers remain excluded.

What sets Work apart from regular Chat isn’t just marketing language about “tasks vs answers.” It’s concrete infrastructure: a full browser sandbox, cross-session filesystem persistence, and sub-agent orchestration using multiple models simultaneously. These features enable workflows previously impossible in Chat — such as automatically filling out government forms using locally stored passport scans, or drafting email replies with live Gmail integration and attached documents. Yet this power comes with trade-offs: Cloudflare blocks Work’s browser mode outright, and security researchers warn that combining untrusted web content, private file access, and outbound communication creates a potent attack surface.

The launch reflects broader enterprise AI dynamics. As Anthropic’s Claude Cowork gained rapid traction in business settings — so much so that Microsoft licensed and rebranded it as Copilot Cowork — OpenAI appears to have accelerated Work’s release to reclaim enterprise mindshare. Still, confusion persists: the naming blurs technical boundaries, documentation is sparse, and even seasoned users struggle to distinguish when to use Chat versus Work. For enterprises weighing adoption, the choice now hinges less on capability than on risk tolerance: cloud convenience versus local control, automation power versus auditability.
