Fastpotify launches as a fast native Spotify client built with Rust and egui

News time: 2026-09-01T06:13:45.551892+00:00 · Source: hackernews

Fastpotify is a new open-source desktop client for Spotify that stands out by avoiding web technologies entirely. Instead of embedding Chromium or relying on Electron-like frameworks, it renders its entire interface using egui — a lightweight, immediate-mode GUI library written in Rust. The result is a snappy, low-memory application that runs natively on Windows, macOS, and Linux, with experimental WebAssembly support enabling potential browser deployment without HTML, CSS, or JavaScript.

The project arrives at a pivotal moment for third-party Spotify clients. Many rely on librespot — an open Rust library that reverse-engineered Spotify’s protocol — but Spotify has recently deprecated and restricted librespot’s use, effectively cutting off authentication for new clients. Fastpotify sidesteps this by using Spotify’s official OAuth flow and web API, though it still depends on librespot for audio streaming under the hood (as confirmed by its GitHub repository). This hybrid approach reflects a pragmatic compromise: leveraging official auth while retaining local playback control.

What makes Fastpotify technically distinctive is its GUI architecture. Unlike traditional retained-mode toolkits like Qt or GTK — where widgets persist as objects with state — egui redraws the entire UI every frame based on current data. This simplifies state management and enables seamless cross-platform rendering: the same Rust code compiles to native binaries and WebAssembly, using WebGL or WebGPU for GPU-accelerated rendering. No DOM, no JS interop, no CSS layout engine — just textured triangles drawn directly from Rust.

Community reaction highlights both enthusiasm and concern. Developers praise egui’s elegance and performance, calling it a sign that native desktop software is finally getting faster. Others worry about Spotify’s tightening grip on its ecosystem, noting that librespot’s deprecation signals broader industry shifts toward closed platforms. Some users have already migrated to self-hosted alternatives like Navidrome, which implements the OpenSubsonic API and offers full control over music libraries and discovery. Fastpotify doesn’t replace that model — it’s a Spotify client, not a server — but it represents a rare, well-executed effort to keep open, performant clients alive within Spotify’s increasingly restrictive walls.
