Python 3.15.0 release candidate 2 arrives ahead of October final launch

News time: 2026-09-02T05:47:14.737734+00:00 · Source: rss

The Python development team has released Python 3.15.0 Candidate 2 — the final pre-release version before the official stable launch scheduled for October. Hugo van Kemenade, the release manager for both Python 3.14 and 3.15, confirmed that only rigorously reviewed, non-breaking bug fixes will be accepted between RC2 and the final release. This strict freeze signals that the core language features and behavior are now locked in, making RC2 the most reliable preview yet for developers preparing their tools, libraries, and CI pipelines.

This phase is especially critical for third-party package maintainers. As emphasized in the announcement, they’re strongly urged to test their projects against Python 3.15 and publish compatible binary wheels on PyPI now. Crucially, wheels built against any 3.15 release candidate — including RC2 — will remain fully functional with the final 3.15.0 and all future 3.15.x patch versions. That compatibility guarantee lowers the barrier to early adoption and helps accelerate ecosystem readiness.

For CI users, RC2 isn’t yet available in GitHub Actions’ default Python version list — but it’s already usable via the setup-python action by enabling two flags: allow-prereleases: true and check-latest: true. With those set, a matrix entry like "3.15" will automatically pull RC1, then RC2, then the stable release as each becomes available — no manual updates needed. This automation simplifies cross-version testing significantly.

Early adopter Simon Willison shared real-world validation: his projects Datasette and sqlite-utils already pass tests on RC2, while LLM is temporarily blocked waiting for scikit-learn to publish its own 3.15 wheel. That dependency chain illustrates how RC testing exposes integration bottlenecks early — turning potential post-launch breakage into manageable, collaborative fixes. Ultimately, RC2 isn’t just a technical checkpoint; it’s a coordinated ecosystem rehearsal — one that depends on maintainers acting now, not after the final release drops.
