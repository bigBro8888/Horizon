Jujutsu creator Martin Ågren joins ERSC open-source GitHub alternative

News time: 2026-09-02T05:47:15.248252+00:00 · Source: hackernews

Martin Ågren, the developer behind Jujutsu — a modern, Git-compatible version control system gaining traction for its intuitive workflow and built-in undoability — has officially joined East River Source Control (ERSC). The announcement, published on ERSC’s blog, marks a significant alignment between two ambitious open-source efforts: one reimagining how developers interact with history at the command line, and the other rebuilding the collaborative code-hosting platform from first principles.

ERSC positions itself as a self-hosted, scalable, and philosophically grounded alternative to GitHub — not just a clone, but a deliberate redesign focused on source control as infrastructure. Its stated goals include first-class conflict modeling, fine-grained access controls, and deep compatibility with Git repositories while building atop more expressive primitives. With Ågren now on board, ERSC gains not only deep VCS expertise but also direct insight into how next-generation tooling can shape platform design — especially around operations like branching, merging, rewriting history, and reviewing changes.

Jujutsu stands out by treating every action — commits, rebases, amends, even edits to commit messages — as reversible, stateful operations stored in an immutable delta database. Unlike Git, where commands like git rebase -i or git reset --hard carry irreversible risk, Jujutsu lets users step backward without fear. As one early adopter noted, this transforms workflows: forgetting to push, misnaming a branch, or botching a rebase no longer means scrambling for reflogs or git fsck. Instead, it’s a single jj undo away.

The move comes amid growing unease about centralized code hosting platforms. While GitHub remains dominant, concerns over vendor lock-in, opaque policies, and architectural constraints have spurred renewed interest in self-hosted, community-governed alternatives. ERSC isn’t alone — projects like Gitea, SourceHut, and Codeberg fill niches — but its explicit integration with Jujutsu’s model suggests a unique path: building a platform where the version control layer and collaboration layer co-evolve. Whether that vision translates into broad adoption will depend less on technical novelty and more on real-world usability, performance at scale, and ecosystem support — questions already being debated vigorously on Hacker News.
