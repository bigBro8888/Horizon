uv 0.12.9 adds CPython 3.15.0rc2 support and memory-safety fixes

News time: 2026-09-02T05:47:15.710274+00:00 · Source: github

Astral-sh’s ultra-fast Python package manager uv has released version 0.12.9, delivering timely support for the upcoming CPython 3.15.0rc2 release — a critical step for early adopters and CI systems testing against Python’s next major version. Beyond compatibility, this patch introduces fine-grained control over dependency locking behavior via two new CLI flags: --no-locked and --no-frozen. These allow developers to temporarily override environment variables like UV_LOCKED or UV_FROZEN for a single command — useful in automation scripts or debugging workflows where lock-file constraints need selective relaxation.

Performance gains are also notable: cold wheel installations — those where wheels aren’t cached and must be fetched and extracted on-demand — now run significantly faster. The improvement comes from rearchitecting ZIP archive extraction to happen in a single blocking task per wheel, while reusing memory buffers across individual files inside the archive. This reduces allocation overhead and improves throughput, especially on systems with slower I/O.

Security remains a priority. A memory-safety issue in the async_http_range_reader library — used when fetching metadata (like pyproject.toml) from remote wheels via HTTP range requests — has been patched by upgrading to version 0.11.1. The flaw could theoretically allow unsafe memory access when processing untrusted wheel sources. Additional hardening includes redacting secrets in signed URLs during retry diagnostics and stripping sensitive headers (e.g., Authorization) when redirects cross authentication realms — even on same-host scheme changes like http → https.

Other reliability enhancements include preventing concurrent uv processes from redundantly extracting the same local or source-built wheel, and ensuring CLI flags like --locked or --check always take precedence over conflicting environment variables. With prebuilt binaries available for all major platforms — including Apple Silicon, x86/x64 Windows and Linux, ARM64 Linux, and PowerPC — adoption requires only a one-liner install script. As uv continues to mature as a pip-compatible, Rust-powered alternative, releases like 0.12.9 reinforce its dual focus: raw speed and production-grade robustness.
