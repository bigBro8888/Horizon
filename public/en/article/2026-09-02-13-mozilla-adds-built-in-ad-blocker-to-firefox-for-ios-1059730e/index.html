Mozilla adds built-in ad blocker to Firefox for iOS

News time: 2026-09-02T05:47:15.248121+00:00 · Source: hackernews

Mozilla has rolled out a built-in ad blocker for Firefox on iOS — its first native content-blocking feature on Apple’s mobile platform. Available as an optional setting in the latest version of the app, the feature blocks many third-party display ads and ad-related trackers before they load, using Apple’s WebKit Content Blocker API and the widely adopted EasyList filter list. Unlike browser extensions on desktop, iOS restrictions prevent full-featured ad blockers from running independently; instead, Mozilla integrates filtering rules directly into Safari’s underlying engine, which Firefox for iOS must use per Apple’s App Store policy.

The ad blocker is turned off by default, requiring users to manually enable it in Settings > Privacy & Security > Ad Blocker. Once activated, it works across all websites visited in Firefox for iOS — reducing visual clutter, speeding up page loads, and improving privacy by preventing known ad networks from tracking browsing behavior. However, it does not block ads served by major search engines like Google or Bing on their results pages, nor does it affect YouTube video ads — two prominent gaps noted both in Mozilla’s official documentation and user feedback.

These omissions stem from technical and strategic constraints. Because Firefox for iOS relies entirely on WebKit — Apple’s proprietary rendering engine — it cannot inject custom JavaScript or run background processes like desktop browsers can. That limits what kinds of ads can be blocked: only those matched by static filter rules (e.g., URLs containing '/ad/' or known ad domain patterns) are caught. Search and YouTube ads often appear as first-party content or are embedded via complex, dynamically generated code that static filters struggle to identify reliably.

User reactions have been mixed. Some welcome the move as overdue progress toward parity with privacy-focused competitors like Brave and DuckDuckGo Browser. Others express frustration over the staggered rollout — reporting delays of days or weeks before the toggle appears — and disappointment at the exclusions. A recurring theme in community comments is concern about Mozilla’s financial reliance on Google, whose search deal accounts for the majority of Mozilla’s revenue; this dependency, users argue, may explain why search ads remain untouched. Still, the launch marks a meaningful step: for the first time, iOS Firefox users gain a zero-install, no-extension way to reduce ads without switching browsers.
