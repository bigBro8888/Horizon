ChatGPT Desktop bundles LibreOffice and full runtime stack locally

News time: 2026-09-02T05:47:14.737606+00:00 · Source: rss

While auditing disk usage with OmniDiskSweeper, developer Simon Willison discovered that the ChatGPT Desktop app — formerly known as Codex — caches a massive 1.7 GB of dependencies under ~/.cache/codex-runtimes/codex-primary-runtime. This isn’t just a few helper binaries: it includes a complete local installation of Python, Node.js, git, Poppler (a widely used PDF rendering library), and, most notably, the full LibreOffice suite — specifically its headless mode (libreoffice-headless), which enables silent, script-driven document conversion and parsing.

This bundling strategy reveals a deliberate architectural choice: rather than relying on cloud-based document processing or lightweight parsers, the app performs complex file operations entirely on-device. That’s especially valuable for legacy formats like binary .xls (Excel 97–2003), .doc, and older PowerPoint files — formats notoriously difficult to parse reliably with generic libraries. As one commenter noted, LibreOffice remains one of the few mature, open-source tools capable of consistently opening decades-old office documents without corruption or data loss.

The inclusion of Poppler complements this by handling PDFs robustly — extracting text, metadata, and even digital signatures — while git and Node.js likely support plugin management, skill execution, and local toolchain orchestration. The documents plugin folder explicitly contains logic for locating and invoking these bundled binaries, confirming they’re not optional add-ons but core infrastructure. This approach trades disk space and initial install size for reliability, privacy, and offline capability — critical for users handling sensitive or air-gapped documents.

Still, the decision invites scrutiny. Some developers question whether such heavy bundling is justified for every user, especially when many prompts don’t involve document processing. Others point out the irony: an AI app built by a proprietary company depends deeply on open-source projects — yet contributes little back. There’s also UX friction: users report confusing settings, inconsistent behavior, and a glossy interface masking underlying complexity. Ultimately, this discovery reframes ChatGPT Desktop not as a thin client, but as a sophisticated local agent — one that quietly ships its own mini Linux workstation inside macOS and Windows.
