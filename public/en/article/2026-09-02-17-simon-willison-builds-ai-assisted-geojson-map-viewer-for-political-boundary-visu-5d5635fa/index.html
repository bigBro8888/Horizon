Simon Willison builds AI-assisted GeoJSON Map Viewer for political boundary visualization

News time: 2026-09-02T05:47:14.737660+00:00 · Source: rss

Simon Willison, a well-known developer and technical writer, has released a new open-source tool called the GeoJSON Map Viewer — a simple, browser-based application that loads, overlays, and exports GeoJSON geographic data as static PNG images. The tool was built to solve a concrete local need: visualizing political boundaries for community organizations like the Granada Community Services District (GCSD) and the Midcoast Community Council (MCC) near Half Moon Bay, California. Rather than searching for or configuring existing GIS software, Willison turned to AI models to help design and iterate on a custom solution.

The development process highlights an emerging pattern of pragmatic human-AI collaboration. Willison first asked GPT-5.6-Sol — OpenAI’s most capable model as of mid-2026 — for suggestions on tools to render GeoJSON. Instead of just recommending existing libraries, the model proactively generated working code for a minimal viewer. Willison then refined it using Claude Code (part of Anthropic’s Fable 5.1 series) for web-specific improvements and debugging, and leveraged Fable 5.1’s enhanced agentic coding capabilities for multi-step iteration. The final result is a self-contained, single-page app with no backend, zero external dependencies beyond Leaflet and OpenStreetMap, and full client-side rendering.

The viewer supports multiple GeoJSON layers with customizable colors and opacity, live URL loading (e.g., from GitHub Gists), and one-click PNG export via HTML canvas. A demo link shows two overlapping polygons — one blue for the MCC area covering Montara and Moss Beach, another red for the GCSD boundary around El Granada — rendered precisely over coastal terrain, complete with road labels, elevation markers, and marine reserve names. Crucially, all GeoJSON used in the demo was itself generated by AI: ChatGPT Work extracted, cleaned, and stitched together official government boundary data to produce ready-to-use files.

This project doesn’t replace professional GIS tools like QGIS or ArcGIS, but fills a valuable niche: fast, privacy-respecting, no-install visualization for non-experts who need to share or present geographic boundaries quickly. It also demonstrates how modern LLMs — especially those tuned for coding and geospatial reasoning — can accelerate prototyping without sacrificing transparency or control. As Willison notes in his colophon, the tool stays entirely in the user’s browser; no data leaves the device. That combination of simplicity, openness, and AI-augmented iteration makes it a compelling example of what’s possible when developers treat LLMs as collaborative co-pilots rather than black-box solutions.
