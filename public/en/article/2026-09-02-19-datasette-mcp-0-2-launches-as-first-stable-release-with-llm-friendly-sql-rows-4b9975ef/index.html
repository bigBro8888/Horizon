datasette-mcp 0.2 launches as first stable release with LLM-friendly SQL rows

News time: 2026-09-02T05:47:14.737712+00:00 · Source: rss

Simon Willison has released datasette-mcp 0.2 — the first non-alpha, production-ready version of this Datasette plugin that bridges relational data with the Model Context Protocol (MCP). Designed to let large language models interact with databases through standardized tooling, the plugin adds an /-/mcp endpoint to any Datasette instance, turning it into an MCP server that can expose database queries as callable tools for AI agents.

The most user-facing improvement in this release is how SQL query results are structured in API responses. Previously, the execute_sql tool returned rows as positional arrays — for example, ['Alice', 32, 'Engineer'] — forcing LLMs to rely on column order alone. Now, each row is a JSON object with explicit keys: {"name": "Alice", "age": 32, "role": "Engineer"}. This change directly addresses a known pain point: weaker or less consistent LLMs often misalign values with columns when only positional indexing is available, leading to incorrect reasoning or hallucinated outputs.

Alongside this usability upgrade, datasette-mcp now depends on MCP SDK version 2.1.1, ensuring compatibility with the latest protocol features and security updates from the official MCP specification. The move to a stable 0.2 release signals more than just technical readiness — Willison notes he’s been using it “quite a bit himself” in real workflows, suggesting it’s already proving valuable for practical LLM-augmented data exploration.

As part of the broader MCP ecosystem — an open standard launched by Anthropic in late 2024 to unify how AI systems connect to external tools — datasette-mcp exemplifies how lightweight, open-source integrations can lower the barrier to building context-aware agents. Unlike heavyweight orchestration frameworks, it leverages Datasette’s existing strengths: zero-config SQLite hosting, automatic schema introspection, and built-in web UI — all extended with one line in a configuration file or plugin install.

For developers working at the intersection of databases and LLMs, datasette-mcp 0.2 represents a small but meaningful step toward robust, maintainable tool integration. It doesn’t add flashy new capabilities — no vector search, no caching layers — but it fixes a subtle yet critical interface mismatch between how databases speak and how many LLMs understand. That kind of quiet reliability is exactly what makes infrastructure tools mature.
