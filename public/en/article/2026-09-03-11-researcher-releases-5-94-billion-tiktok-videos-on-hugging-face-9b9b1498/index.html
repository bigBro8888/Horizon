Researcher releases 5.94 billion TikTok videos on Hugging Face

News time: 2026-09-03T05:45:03.041507+00:00 · Source: reddit

A researcher known online as /u/DataShack has released what appears to be the largest publicly available TikTok dataset to date: 5.94 billion video records and 3.23 billion user profiles. The data is now hosted for free on Hugging Face under the dataset name kuben-developer/tiktok-videos-4b. Unlike many scraped social media datasets that remain private or are shared only with academic collaborators, this one is fully open — anyone can download, inspect, or stream subsets using Hugging Face’s zero-copy Arrow-based streaming API.

The collection was made possible by a reverse-engineered mobile API method developed years ago, which bypasses TikTok’s official web and app interfaces. According to the author, the technique exploits 24 publicly exposed endpoints in TikTok’s Android/iOS app — all accessible without authentication. This approach avoids rate-limiting and login requirements but skirts TikTok’s Terms of Service. The author explicitly acknowledges this tension, noting that while the data is technically public (e.g., visible to any logged-out user), automated bulk access violates TikTok’s policies.

Alongside the dataset, the researcher published a detailed technical write-up and documentation at tiktok-api.seeksocial.io. However, the full scraping code is not open source — it’s offered for a small fee. This hybrid model reflects a growing trend in the scraping community: transparency about methodology paired with monetization of implementation. The dataset includes not just video metadata (IDs, timestamps, captions) but also associated profiles, comments, hashtags, and audio tracks — making it unusually rich for multimodal research.

Ethical concerns have quickly surfaced in the Reddit discussion thread. Commenters debate whether releasing billions of user-generated clips — many containing faces, voices, and personal context — qualifies as responsible open science or constitutes large-scale consent-free data harvesting. Some point out that TikTok’s own privacy controls (e.g., ‘private account’ settings) are effectively nullified when data is scraped via mobile API endpoints that ignore those restrictions. Others emphasize the scientific value: such scale enables training foundation models for short-video understanding, benchmarking retrieval systems, or studying platform-level behavioral patterns — tasks previously hindered by data scarcity.
