Developer ports 1993 Amiga game to Godot using Claude 3.5

News time: 2026-09-04T05:50:51.986088+00:00 · Source: hackernews

In July 2024, a developer successfully ported their own 1993 Amiga game—written entirely in Motorola 68000 assembly language in Baghdad—to the modern Godot engine, using Claude 3.5 Fable as a collaborative reverse-engineering partner. What began as a nostalgic experiment over a single evening evolved into a meticulous multi-week analysis: the developer fed Claude their original binary, handwritten notes, decades-old memory of the development process, and Git repositories, then carefully edited the model’s output line by line. The result wasn’t just functional—it preserved the tactile feel of the original, from scrolling behavior to sprite timing.

The technical core of the effort was rigorous validation. Before translation, Claude used vasm—a portable, retargetable assembler—to reassemble the original source and iteratively refine it until the generated binary matched the 1993 release byte-for-byte. A persistent 108-byte discrepancy led to a key insight: the shipped Amiga binaries weren’t clean assembler output, but memory snapshots taken after the game had already run under AsmOne, the assembler used at the time. This subtle distinction—between assembled code and live-memory state—was critical for fidelity and highlights how deeply context-dependent retro software preservation really is.

Beyond translation, Claude helped reconstruct missing documentation, interpret obscure hardware register interactions, and generate Godot GDScript that mirrored the original’s tight, cycle-aware logic. The developer also revived their 1993 map editor for the first time in over three decades—running it on modern hardware to verify assumptions. Crucially, they’re releasing the original Amiga game for free, turning a personal project into an open artifact for software archaeology.

This work sits at a rare intersection: deeply personal (a creator revisiting their teenage work), technically precise (binary-level validation, 68k instruction semantics), and historically urgent (much pre-internet software lacks source code or documentation). It reframes LLMs not as creative substitutes, but as context-aware interpreters—bridging gaps in knowledge, tooling, and institutional memory that would otherwise make such ports nearly impossible.
