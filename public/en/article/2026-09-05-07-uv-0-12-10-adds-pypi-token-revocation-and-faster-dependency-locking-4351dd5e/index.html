uv 0.12.10 adds PyPI token revocation and faster dependency locking

News time: 2026-09-05T05:42:59.628446+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.10, delivering meaningful improvements in security, usability, and performance. Released on September 4, 2026, this patch builds on uv’s reputation for speed and reliability—offering developers a leaner, safer alternative to traditional Python tooling like pip and pip-tools. The update arrives at a time when secure, automated publishing workflows are increasingly critical, especially as more teams adopt PyPI’s Trusted Publishing mechanism powered by OpenID Connect (OIDC) tokens.

One of the most notable changes is automatic revocation of short-lived PyPI trusted-publishing tokens after uv publish completes—even if the upload fails. This closes a subtle but real security gap: previously, tokens could linger unnecessarily after publishing attempts, increasing exposure surface. Now, uv proactively invalidates them, aligning with zero-trust principles without requiring manual cleanup or CI script tweaks.

Usability gains include clearer dependency cycle detection via uv tree --invert, which now surfaces terminal cycles directly in terminal output—helping developers quickly spot circular dependencies that might break builds or cause runtime surprises. Meanwhile, lockfile robustness improves significantly: --locked mode no longer fails when exclude-newer-package settings differ for packages outside the current resolution scope, and uv lock --check now tolerates updates to absolute or package-specific exclude-newer cutoffs. These fixes make lockfile-driven workflows more predictable in large, evolving monorepos.

Performance optimizations target real-world pain points: locking large workspaces with conflicting extras is now faster thanks to smarter conflict simplification that excludes unrelated dependency groups; and uv publish speeds up artifact hashing by reusing buffers and consolidating I/O into single blocking tasks. Combined with deterministic ordering of exclude-newer entries in uv.lock, these changes reinforce uv’s role as a production-grade foundation for modern Python development pipelines.
