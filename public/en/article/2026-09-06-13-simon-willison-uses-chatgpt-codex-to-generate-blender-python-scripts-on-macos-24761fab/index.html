Simon Willison uses ChatGPT Codex to generate Blender Python scripts on macOS

News time: 2026-09-06T05:53:55.795671+00:00 · Source: rss

Simon Willison, a well-known developer and technical blogger, recently shared a playful yet practical demonstration of how large language models can accelerate 3D content creation — specifically, using ChatGPT Codex to write and refine Python scripts for Blender on macOS. Rather than manually coding scene setups or wrestling with Blender’s API documentation, he prompted the AI with plain English instructions like “Use the already installed /Applications/Blender to render a scene of a pelican riding a bicycle.” The result wasn’t just a rough sketch: after two follow-up prompts — “OK add a background and a lot of flair” and “OK make it a whole lot better” — Codex produced a polished, runnable Python script that generated a richly detailed 3D illustration.

This workflow hinges on Blender’s mature Python API, which has long allowed users to automate modeling, animation, lighting, and rendering via scripts. What’s new is not the API itself, but how easily an LLM can now act as a high-level interface to it — translating natural language intent into syntactically correct, context-aware code. Willison didn’t need to install special plugins or run local models; he simply used the official Blender macOS app (downloaded from blender.org) and interacted with Codex in ChatGPT as a coding agent.

The final output — a pastel-hued seaside scene featuring a white pelican cycling a turquoise bicycle, complete with boater hat, coral scarf, floating balloons, and striped beach huts — was rendered entirely through Blender’s built-in Cycles engine. The underlying script, publicly hosted on GitHub, shows real-world use of core Blender Python patterns: object creation, material assignment, camera positioning, and environment lighting setup. It’s not production-grade industrial automation, but it is a compelling proof-of-concept for creative prototyping.

For designers, educators, or indie developers who want to explore 3D without deep scripting expertise, this approach lowers the barrier meaningfully. It doesn’t replace learning Blender’s API — but it does turn exploration into dialogue. As Willison notes, the magic lies in iterative refinement: each prompt builds on the last, letting users steer the output like a collaborator rather than a compiler. That shift — from writing code to conversing with a coding agent — may quietly reshape how non-programmers engage with procedural 3D tools.
