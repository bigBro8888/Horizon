OpenAI launches ChatGPT Images 2.5 with two new API models

News time: 2026-09-09T05:57:31.463350+00:00 · Source: rss

OpenAI has officially released ChatGPT Images 2.5 — its latest iteration of image generation technology, now powering over 3 billion images monthly across ChatGPT and the OpenAI API. This update marks a meaningful leap beyond incremental refinement: it significantly improves how well the model follows complex, multi-turn editing instructions — for example, when users iteratively refine an image by adding, removing, or modifying elements across successive prompts. It also delivers faster response times, with latency reportedly cut by up to 50% compared to Images 2.0, and shows marked improvement in preserving key subjects when editing from reference images — a longstanding pain point in image-to-image workflows.

What makes this release especially developer-friendly is the introduction of two distinct API models: gpt-image-2.5-sunburst and gpt-image-2.5-flare. According to OpenAI’s official guidance, Sunburst prioritizes precision — ideal for tasks requiring faithful subject retention, fine-grained control, and consistency across multiple edits. Flare, by contrast, is optimized for speed without sacrificing quality, making it suitable for high-volume or real-time applications like rapid prototyping or UI mockup generation. The distinction isn’t just marketing: developers must now choose deliberately based on use case, not default to a single ‘best’ model.

The practical impact is already visible in real-world tooling. Developer Simon Willison — a widely respected voice in the Python and AI tooling community — upgraded his open-source CLI tool openai_image.py to support multi-reference-image editing using these new models. In one demonstration, he took a line chart showing AI agent usage trends and instructed the model to “add a raccoon scientist studying the chart thoughtfully.” Using gpt-image-2.5-sunburst, the output preserved the original chart’s layout, labels, and data fidelity while seamlessly integrating a detailed, contextually appropriate cartoon raccoon — complete with glasses, lab coat, clipboard, and even book titles referencing AI and software engineering. The result wasn’t just plausible; it was semantically coherent and visually consistent.

This release reflects a broader industry shift toward specialized, task-optimized foundation models — moving away from monolithic ‘one-size-fits-all’ approaches. For developers building creative tools, design assistants, or educational content generators, ChatGPT Images 2.5 offers tangible improvements in reliability and workflow flexibility. While pricing details are still emerging, early comparisons suggest Sunburst carries a higher per-image cost than Flare — reinforcing that performance trade-offs are now explicit, transparent, and actionable.
