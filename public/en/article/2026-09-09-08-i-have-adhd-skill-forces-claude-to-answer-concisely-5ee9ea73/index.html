I-have-ADHD skill forces Claude to answer concisely

News time: 2026-09-09T05:57:31.956290+00:00 · Source: hackernews

A lightweight but widely adopted prompt engineering technique called 'I-have-ADHD' is gaining traction among developers frustrated with Claude’s tendency to bury key information under layers of self-reference, caveats, and unnecessary negations. Unlike traditional system instructions that fade over long conversations, this skill uses a deliberately informal, human-like assertion — 'I have ADHD, so please give me the answer directly without explanations, disclaimers, or what you didn’t do' — to override Claude’s default verbosity. The GitHub repository, launched by developer Ayghri, includes ready-to-use prompts, integration guidance for coding agents, and documentation (AGENTS.md) showing how to embed it into CLI workflows or agent orchestration layers.

This isn’t just stylistic preference: users report that Claude often responds with sentences like 'I modified file.py but did not touch README.md or commit the changes' — delivering the action and its omissions in equal weight, even when only the action matters. Similarly, code comments generated by Claude frequently include redundant qualifiers ('returns true if clicked on button — not on the list view'), which hurt readability and violate engineering norms. These patterns degrade reliability in automated coding agents, where downstream tools expect clean, parsable output — not prose meant for human reassurance.

The technique works by exploiting how Claude interprets role-based framing and instruction persistence. Rather than relying on brittle system prompts or token-count limits, 'I-have-ADHD' leverages the model’s strong alignment with user identity cues. Early adopters note it improves first-response concision significantly — especially for code-generation and diff-summary tasks — though its effect tends to decay after two or three conversational turns unless reapplied. Some developers now auto-inject it before every agent step, while others combine it with structured output rules (e.g., JSON-only responses) for maximum predictability.

Still, adoption comes with caution. As one commenter pointed out, blindly pasting CLI installation commands from unvetted repos — even well-intentioned ones — carries security risk. And while Anthropic has published updated prompt engineering best practices for 2026, none officially endorse or address this specific behavioral hack. That gap reflects a broader tension: as LLMs grow more capable, their default communication style increasingly clashes with engineering workflows demanding precision, brevity, and machine-readability. 'I-have-ADHD' may be a stopgap — but it’s one built, tested, and refined by the people who ship real AI tools every day.
