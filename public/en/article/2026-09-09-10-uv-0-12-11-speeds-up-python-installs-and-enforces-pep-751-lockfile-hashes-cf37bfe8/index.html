uv 0.12.11 speeds up Python installs and enforces PEP 751 lockfile hashes

News time: 2026-09-09T05:57:32.294555+00:00 · Source: github

Astral.sh has released uv 0.12.11 — a focused, high-impact patch that tightens correctness and accelerates common installation workflows. Released on September 8, 2026, this version delivers measurable speedups for developers installing packages into existing environments, especially when overwriting files or merging wheels. The improvements stem from deep systems-level optimizations: eliminating per-file temporary directories during atomic file replacements (hard links, symlinks, reflinks), switching to positioned ZIP reads instead of shared locks for wheel extraction, and reusing ZIP readers and buffers across files. These changes reduce I/O contention and memory allocation overhead — not just theoretical gains, but real-world wins for CI pipelines and local development.

Beyond performance, uv 0.12.11 advances compliance with PEP 751, the emerging standard for tool-agnostic Python lockfiles. It now auto-generates missing artifact hashes when exporting pylock.toml, ensuring lockfiles meet the specification’s requirement that every downloaded wheel or source distribution include verified cryptographic hashes. To prevent future breakage, uv warns when hash tables are empty — a signal that such lockfiles will be rejected in upcoming versions. This nudges teams toward reproducible, verifiable builds before enforcement lands.

The release also includes several important bug fixes that improve security and robustness. Source archives are now verified against hashes in uv.lock before reading metadata or invoking build backends — closing a timing window where untrusted code could execute. Hash verification is extended to strict pins (===) under both --verify-hashes and --require-hashes, and uv now intelligently applies public-version hashes to matching local versions when exact local hashes are absent. Other quality-of-life fixes include PowerShell activation support for UNC and WSL paths, whitespace trimming in .python-version files, and quieter warnings for no-sync operations.

As a Rust-native alternative to pip, pip-tools, and virtualenv, uv continues its mission of simplifying Python’s toolchain without sacrificing precision. Its single static binary works across macOS, Windows, and Linux — including ARM64 — and requires no Python runtime to install. With 0.12.11, Astral.sh reinforces that speed and safety aren’t trade-offs: they’re co-designed goals.
