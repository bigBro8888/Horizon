How to turn an e-ink tablet into a virtual printer with CUPS

News time: 2026-09-09T05:57:31.956009+00:00 · Source: hackernews

What if your reMarkable or Fujitsu Quaderno wasn’t just a note-taking device—but a fully integrated printer? A new tutorial by Nishant Joshi shows exactly how to do that: not by adding hardware, but by reconfiguring software. The guide walks readers through building a custom CUPS backend that makes the e-ink tablet appear as a native IPP-compliant printer to any Linux system. Once set up, users can ‘print’ PDFs, web pages, or documents from any application—just like sending jobs to a physical printer—and have them appear instantly on their e-ink screen.

The trick lies in bridging two worlds: the decades-old CUPS printing architecture and modern e-ink devices designed for reading, not printing. CUPS—the Common Unix Printing System—has long relied on backends: small programs that handle communication with physical devices. By writing a lightweight backend script (in Python or shell), the author intercepts print jobs, converts them to a suitable bitmap format, and pushes them over USB or network to the tablet’s display layer. Crucially, the backend declares itself as IPP-compliant, advertising supported media sizes (e.g., om_1404x1872 for reMarkable 2), output bins, and media types—so desktop apps like LibreOffice or Firefox don’t scale or crop unexpectedly.

Readers also learn how to define non-standard paper sizes using IPP naming conventions (om_NNNmmxYYYmm), avoid unwanted scaling by matching exact screen dimensions, and configure CUPS queues via command line or the web interface at localhost:631. The tutorial avoids low-level driver development, instead leveraging existing tablet APIs and open tools like dpt-rp1-cups, an earlier open-source backend for the Fujitsu Quaderno.

Beyond technical execution, the piece sparks reflection on what ‘printing’ means today. It’s no longer about ink on paper—it’s about reliable, app-agnostic delivery of formatted content to any capable display. As one commenter notes, this turns the tablet into ‘paper that acts like a printer’. And while it won’t replace laser printers for volume output, it fills a quiet but growing niche: frictionless, distraction-free, battery-efficient document review—right where your eyes already are.
