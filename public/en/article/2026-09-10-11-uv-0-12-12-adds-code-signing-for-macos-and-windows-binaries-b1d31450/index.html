uv 0.12.12 adds code signing for macOS and Windows binaries

News time: 2026-09-10T05:56:17.319276+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.12, marking a major step forward in security and enterprise readiness. Released on September 9, 2026, this update introduces official code signing for all macOS and Windows executables — a long-awaited feature that strengthens trust, improves compatibility with corporate security policies, and reduces false positives from antivirus software and system gatekeepers.

On macOS, uv binaries are now signed with an Apple Developer ID certificate and submitted to Apple’s notarization service. This means Gatekeeper can verify the software is from a known developer and hasn’t been tampered with — a critical requirement for many organizations deploying software across fleets of Macs. On Windows, uv binaries carry timestamped Authenticode signatures issued via Azure Artifact Signing, enabling Windows Defender SmartScreen and enterprise endpoint protection tools to confidently identify and allow the binaries based on publisher reputation.

Beyond security, the release includes a precise bug fix for dependency locking behavior: the exclude-newer flag in lockfiles now correctly excludes packages uploaded after the specified cutoff date when generating requirement hashes. This ensures reproducible builds and avoids accidental inclusion of newer, potentially incompatible distributions — especially important in CI/CD pipelines and regulated environments where build consistency is non-negotiable.

The release supports a wide range of platforms, including Apple Silicon and Intel macOS, x86/x64/ARM64 Windows, and multiple Linux architectures (x86_64, aarch64, RISC-V, s390x, ppc64le). Installation remains simple via shell or PowerShell scripts, and all binaries include SHA256 checksums for integrity verification. While Linux binaries remain unsigned — consistent with common open-source distribution practices — the macOS and Windows signing fills a key gap for users who previously had to manually verify or repackage uv for production use.

As uv continues gaining traction as a faster, safer alternative to pip and Poetry, this release signals a maturing focus on real-world deployment constraints — not just raw speed. Code signing bridges the gap between developer tooling and enterprise IT policy, making uv more viable for teams where security compliance isn’t optional.
