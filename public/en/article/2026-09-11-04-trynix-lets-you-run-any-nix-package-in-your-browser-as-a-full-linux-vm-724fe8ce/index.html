Trynix lets you run any Nix package in your browser as a full Linux VM

News time: 2026-09-11T05:55:50.998429+00:00 · Source: rss

Imagine clicking a link and instantly launching a fully functional x86_64 Linux virtual machine — complete with a shell, filesystem, and networking — all inside your web browser, with no server, no install, and no local setup. That’s now possible thanks to trynix.dev, a groundbreaking tool that brings the entire 13-year history of Nix packages into immediate, interactive reach.

At its core, trynix.dev uses qemu-wasm — an experimental WebAssembly port of QEMU — to emulate a full Linux system directly in the browser. Unlike lightweight container-like sandboxes or JS-based interpreters, this is real virtualization: it boots a minimal Linux kernel, initializes userspace, and runs unmodified Nix-built binaries compiled for x86_64. Every package from nixpkgs since 2011 (including legacy versions like python3@3.6.2) is URL-addressable: just append ?pkg=package@version to the domain and hit Load.

The implications go far beyond curiosity. Farid Zakaria, the creator, calls it his "magnum opus of Nix work" — and for good reason. One powerful application is pull request review: the trynix-preview GitHub Action automatically posts a comment on any PR with a link to a live, sandboxed environment running exactly the code built by that PR. Reviewers can inspect behavior, test APIs, or verify UI changes without cloning, building, or trusting remote infrastructure.

What makes this especially compelling is its security model. Because execution happens entirely client-side in a WebAssembly sandbox — with no network access unless explicitly enabled — untrusted code runs in isolation. This eliminates supply-chain risks common in CI preview environments and enables reproducible, deterministic evaluation of builds across time and machines. It also sidesteps the complexity of maintaining long-lived preview servers or ephemeral cloud instances.

While performance isn’t desktop-native — boot times range from 5–20 seconds depending on package size and browser — the engineering achievement is undeniable. By combining mature Nix reproducibility with cutting-edge WebAssembly virtualization, trynix.dev redefines what “instant dev environment” means. It’s not a demo; it’s a working foundation for safer, more transparent, and truly portable software development.
