uv 0.12.13 adds GraalPy 3.13 support and strengthens PEP 658 security

News time: 2026-09-11T05:55:52.165716+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.13, delivering targeted improvements across compatibility, security, and performance. Released on September 10, 2026, this patch builds on uv’s reputation for speed and correctness—offering faster dependency resolution, tighter integrity checks, and broader runtime support without breaking changes.

A major addition is native support for GraalPy 3.13.0, the Python 3.13-compliant implementation built on GraalVM. This enables developers using GraalPy—especially those seeking JIT-compiled Python performance or polyglot JVM integration—to leverage uv’s fast resolver and installer directly. Unlike CPython, GraalPy requires distinct tooling support due to differences in bytecode, path handling, and environment detection; uv now detects and configures environments for it automatically.

Security sees a meaningful upgrade via PEP 658 metadata sidecar verification. When installers fetch .metadata files separately from wheels (to avoid downloading full packages just to read dependencies), uv now validates that the hash of the downloaded sidecar matches the one declared in the index—closing a gap previously noted in pip where mismatched metadata could lead to incorrect resolution. This change implements a long-standing best practice for supply-chain integrity.

Performance gains come from smarter wheel resolution: uv now reuses hash information embedded in direct URL fragments (e.g., #sha256=...) when metadata is available separately, avoiding redundant full-wheel downloads during dependency analysis. On Windows, uv fixes launcher compatibility with Nano Server—a minimal Windows container OS—and reduces false positives from antivirus software by editing entry-point resources in memory instead of on disk.

These updates reflect uv’s pragmatic evolution: not chasing headline features, but tightening correctness, expanding ecosystem reach, and removing friction for real-world deployments—from cloud-native containers to high-performance GraalVM runtimes.
