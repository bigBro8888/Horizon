Radar object classifier learns range bias, not true classes

News time: 2026-09-12T05:44:44.875854+00:00 · Source: reddit

A machine learning practitioner working on automotive radar point cloud classification has raised a subtle but critical concern: when range (distance to object) is included as an input feature, model F1 scores improve consistently across all validation folds and the final test set — yet this boost may reflect spurious correlation, not genuine class separation. The issue stems from a well-known physical property of automotive radar: farther objects return fewer reflected points due to signal attenuation and beam spread. As a result, range strongly correlates with point cloud density — and, unintentionally, with object size or type in the dataset. The model may thus learn that ‘large range → sparse points → large vehicle’, rather than recognizing intrinsic geometric or kinematic features of cars, trucks, or pedestrians.

This isn’t classic overfitting — cross-validation stability and test-set performance rule that out. Instead, it’s range-induced confounding: range acts as a hidden proxy variable that entangles environment-dependent sensor behavior with semantic labels. The practitioner suspects their model is generalizing to the deployment environment (e.g., highway vs. urban layouts), not to object categories themselves — undermining real-world robustness when encountering new scenes or unseen range distributions.

To diagnose this, they propose several pragmatic stress tests: stratifying train/test splits by range bins to see if performance collapses when range distributions diverge; ablation studies removing range as a feature entirely; or using causal inference tools like backdoor adjustment or invariant risk minimization. They also consider whether domain randomization — synthetically varying range–density relationships during training — could help decouple sensor artifacts from semantics. Crucially, they’re not asking how to maximize metrics, but how to ensure those metrics reflect meaningful, deployable intelligence.

The question resonates beyond radar: any sensor modality with systematic physical biases — lidar dropouts in rain, camera motion blur at low light, thermal camera saturation near heat sources — risks similar confounding. Addressing it requires moving past accuracy-as-truth toward ecological validity: does the model succeed because it understands objects, or because it memorized the data collection setup? For autonomous driving systems, where safety-critical decisions hinge on perception, mistaking correlation for causation isn’t just academically unsatisfying — it’s potentially hazardous.
