Simon Willison used GPT-6 Astra to generate OSM-based running routes

News time: 2026-09-13T06:05:41.572015+00:00 · Source: rss

Simon Willison, a well-known developer and technical writer, recently demonstrated a practical application of cutting-edge large language models: generating custom running routes using natural language. In a September 2026 blog post, he described asking ChatGPT Work — powered by the newly released GPT-6 Astra (Max) model — to produce 5K and 10K looped running routes starting and ending at his home address in El Granada, California. The request was simple and declarative: 'I live at [my address]. Figure out 5K and 10K running routes from me that loop from my house. Use OSM data.'

The model took 27 minutes to complete the task — notably longer than typical LLM responses — and delivered three outputs: an embedded interactive map visualization, a downloadable GPX file (standard for GPS devices), and a GeoJSON file (widely used in web mapping). The resulting 5.1 km route winds through coastal streets and trails near El Granada harbor, labeled with real street names like Avenue Granada and Coastal Trail, and clearly credits OpenStreetMap contributors.

Willison probed how the system worked, and ChatGPT explained it had used Nominatim for geocoding his address and Overpass API to fetch local OpenStreetMap road and trail geometries. It then performed local pathfinding — likely using graph-based routing logic — to construct closed loops matching the requested distances. The visualization was rendered via a built-in 'visualize' skill that generated an HTML file hosted in the agent’s workspace, embedding a lightweight map interface.

However, transparency proved limited. Willison noted he couldn’t see the actual Python code executed behind the scenes — a consequence of ChatGPT Work’s thread compaction feature, which discards earlier intermediate steps to save context. When he later asked for the code, the model could no longer retrieve it. He argues this is a design flaw: systems using compaction should preserve and expose pre-compacted reasoning traces, especially when executing external tools or generating reproducible artifacts like GPX files.

This experiment sits at a meaningful intersection: it’s not just another chatbot demo, but a working integration of LLMs with open geospatial infrastructure. Unlike proprietary routing APIs, it relies entirely on free, community-maintained OpenStreetMap data — making it replicable, auditable, and privacy-respecting. While still experimental and lacking fine-grained control (e.g., elevation smoothing or surface filtering), it signals a shift toward AI agents that don’t just describe maps — but compute and deliver them.
