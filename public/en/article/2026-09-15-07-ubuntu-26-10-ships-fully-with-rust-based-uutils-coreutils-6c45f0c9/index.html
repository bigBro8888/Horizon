Ubuntu 26.10 ships fully with Rust-based uutils coreutils

News time: 2026-09-15T06:08:50.109744+00:00 · Source: hackernews

Ubuntu 26.10 has officially replaced GNU coreutils with uutils — a cross-platform, Rust-based reimplementation — across all default installations. This marks the first Ubuntu release where ls, cp, rm, mv, and other foundational Unix utilities are no longer provided by GNU’s C-based implementation but instead by uutils version 0.10.0. The switch is part of Canonical’s multi-year effort to improve memory safety in system-critical components, leveraging Rust’s compile-time guarantees against buffer overflows, use-after-free, and null pointer dereferences.

However, the transition is not without serious friction. Users have quickly uncovered critical stability issues: one widely reproduced test case triggers a segmentation fault in rm -rf when deleting deeply nested directories — a failure that leaves files intact and breaks basic filesystem hygiene. As demonstrated in containerized Ubuntu 26.10 environments, the crash occurs even after full system updates, while the legacy GNU gnurm command succeeds without error. This suggests uutils’ recursive deletion logic still lacks robustness under real-world path-depth or edge-case conditions.

The problem isn’t theoretical. It affects build toolchains: because build-essential now depends on coreutils-from-uutils, users cannot simply downgrade to GNU coreutils without breaking package dependencies. Workarounds exist — such as installing coreutils-from-gnu alongside — but they require manual intervention and risk dependency conflicts. Meanwhile, upstream uutils maintainers acknowledge incomplete option parity and behavioral differences; their documentation explicitly states that "some options might be missing or different behavior might be experienced."

This milestone reflects broader industry momentum toward memory-safe systems programming — Microsoft also ships uutils for Windows, and Rust is increasingly used in Linux kernel modules and init systems. Yet Ubuntu’s decision to ship uutils by default in a stable release, before resolving known correctness bugs, highlights the tension between innovation and reliability. For developers and sysadmins, it means verifying tool behavior in automation scripts, especially around file operations, rather than assuming POSIX-compliant equivalence. Ultimately, Ubuntu 26.10 isn’t just a version bump — it’s a live stress test of Rust’s readiness for foundational Unix infrastructure.
