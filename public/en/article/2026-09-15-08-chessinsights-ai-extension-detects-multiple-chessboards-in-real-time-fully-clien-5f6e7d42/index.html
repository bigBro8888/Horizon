ChessInsights AI extension detects multiple chessboards in real time—fully client-side

News time: 2026-09-15T06:08:50.692731+00:00 · Source: reddit

A new open-browser extension called ChessInsights AI enables real-time, privacy-first chess analysis directly inside Chrome and Firefox—without sending a single pixel to the cloud. Unlike popular tools such as Chessvision.ai, which rely on server-side inference, this extension runs its entire vision pipeline locally: from detecting chessboards in screenshots to classifying all 64 squares and evaluating positions with Stockfish—all within the user’s browser.

The architecture prioritizes both usability and data sovereignty. Instead of continuously streaming video (which would strain CPU and raise privacy concerns), it uses the browser’s tab-capture API to grab a static screenshot on demand—either of the full visible tab or a custom-selected region via a draggable rectangle. This ‘photo mode’ is especially useful for analyzing multi-diagram content like chess articles, PDFs, or split-screen broadcasts. A lightweight YOLO-style object detector (built with TensorFlow.js) then scans the image for axis-aligned rectangular board candidates, applying non-maximum suppression to avoid duplicate detections.

Once boards are localized, each is cropped and subdivided into an 8×8 grid. A second, compact CNN classifier—trained specifically on low-resolution, compressed, and overlaid chess imagery—identifies pieces or empty squares in each cell. Augmentations included simulated Twitch overlays, YouTube UI elements, JPEG artifacts, and varied board themes (2D/3D, light/dark). The resulting piece layout is converted into a standard FEN string, which feeds into a WebAssembly-compiled version of Stockfish running in a background Web Worker—delivering engine evaluations without any network dependency.

What sets ChessInsights AI apart isn’t just technical execution—it’s design philosophy. Every component is built around the principle of zero data exfiltration: no frames, no metadata, no telemetry. It’s also fully free and open in scope—no paywalls, no feature gating. For educators, streamers, and casual learners, it bridges passive consumption (watching a grandmaster stream or reading a tactics PDF) with active analysis, all in one click. While perspective correction for skewed boards remains on the roadmap, the current implementation already handles most real-world web content robustly—and proves that performant, privacy-respecting computer vision is viable in today’s browsers.
