Capsule packs web apps and SQLite data into single portable files

News time: 2026-09-16T05:58:30.208590+00:00 · Source: hackernews

Capsule is a new desktop application that solves a surprisingly persistent problem: how to build truly self-contained, offline-first web apps that save user data locally—and share it easily. Unlike traditional web apps that rely on remote servers or browser-based storage (like localStorage), Capsule uses Tauri 2.0—a lightweight, Rust-powered framework—to wrap HTML, CSS, JavaScript, and SQLite-persisted data into one portable .capsule file. This means the entire app—including its interface, logic, assets (images, PDFs), and structured user data—lives inside a single SQLite database file, ready to run without installation, internet, or external dependencies.

The approach bridges a gap between web simplicity and desktop reliability. Developers can write standard HTML pages, then choose how data is stored: as simple key-value pairs (like localStorage), or as flexible JSON documents in MongoDB-style collections—all backed by SQLite tables. Users can export any data to CSV or JSON, and even embed AI features using local or remote models. Crucially, Capsule enforces strict privacy: apps have no default filesystem access and must request explicit permission for network use—making it safer than typical web views.

One clever design detail addresses versioning and collaboration: every data entry includes a UUID and timestamp, enabling future merge logic across divergent copies of the same .capsule file. While multi-user real-time sync isn’t built in yet, this foundation supports eventual conflict resolution. The developer also plans to publish an open file format specification before v1.0, inviting interoperability—so other tools could read or write .capsule files without relying on the official app.

Capsule isn’t just theoretical—it’s already usable. A web preview lets users test pre-built templates or generate custom apps via AI prompts guided by documented instructions. Under the hood, it leverages Tauri 2.0’s cross-platform support (including mobile) and Rust’s memory safety, while avoiding Electron’s resource overhead. For developers tired of choosing between browser limitations and desktop complexity, Capsule offers a third way: web-native, portable, and persistently local.
