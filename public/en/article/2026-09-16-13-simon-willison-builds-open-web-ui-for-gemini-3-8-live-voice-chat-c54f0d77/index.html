Simon Willison builds open web UI for Gemini 3.8 Live voice chat

News time: 2026-09-16T05:58:29.859886+00:00 · Source: rss

Simon Willison, a well-known developer and technical blogger, has released a functional, open-source web interface called Gemini Live audio — a hands-on tool for experimenting with Google’s newly launched Gemini 3.8 Live speech-to-speech models. The interface is live at tools.simonwillison.net/gemini-live and requires no installation: users simply open it in a modern browser, grant microphone access, and begin speaking. Unlike traditional text-based LLM interfaces, this tool supports real-time, bidirectional voice conversation — including the ability to interrupt the AI mid-response, a feature critical for natural-feeling dialogue.

Google announced Gemini 3.8 Live and its extended-thinking variant just hours before Willison’s release, positioning them as production-grade, native speech-to-speech models capable of background tool calling, multilingual support (97 languages), and parallel reasoning during live conversations. These models are Google’s direct answer to OpenAI’s GPT-Live family — especially GPT-Realtime-2 — which similarly emphasizes low-latency, interruption-aware voice interactions. Willison’s implementation doesn’t rely on any third-party libraries; instead, it connects directly to Google’s WebSocket API endpoint (wss://generativelanguage.googleapis.com/ws/...) and uses the Web Audio API’s AudioContext for both microphone capture and audio playback.

The UI is refreshingly minimal: users choose a model and voice preset, optionally set a system prompt, then click “Start session.” A transcript appears in real time, showing both user speech (converted via browser’s built-in speech recognition) and AI responses — including markers like “Interrupted” when the user cuts in. Notably, typing a message also interrupts ongoing audio output, reinforcing the design’s focus on fluid turn-taking. Willison credits GPT-6 Astra Extra High — an internal or hypothetical advanced model — for helping him generate the initial HTML and JavaScript, though the final code is hand-audited and library-free.

This isn’t just a demo — it’s a working reference implementation that lowers the barrier for developers exploring real-time voice AI. By publishing the full source on GitHub and linking to Google’s official WebSocket tutorial, Willison invites others to learn, extend, and audit how live multimodal AI can be integrated into the open web — without proprietary SDKs or closed frameworks. For practitioners, educators, and privacy-conscious builders, it offers rare transparency into how next-generation voice agents actually behave under real-world conditions.
