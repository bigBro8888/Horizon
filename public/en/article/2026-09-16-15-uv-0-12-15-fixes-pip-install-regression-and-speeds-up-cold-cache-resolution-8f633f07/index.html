uv 0.12.15 fixes pip install regression and speeds up cold-cache resolution

News time: 2026-09-16T05:58:30.539295+00:00 · Source: github

The Python tooling ecosystem just got a small but meaningful update: uv 0.12.15 is now available. Released on September 15, 2026, this patch release addresses a critical usability regression introduced in version 0.12.14 — one that unexpectedly blocked valid pip install commands in common real-world scenarios. Specifically, users running uv pip install --system inside Python-based Docker images (e.g., python:* base images) or using --target . to install packages directly into the current directory were met with validation errors, even though those commands are both legitimate and widely used.

This regression stemmed from an overzealous symlink check that mistakenly rejected installation destinations that happened to be symbolic links — a common setup in containerized and CI environments. The fix reverts that change, restoring compatibility without compromising safety. Beyond correctness, the release also delivers a tangible performance win: cold-cache resolution — the scenario where uv must fetch and validate package metadata from scratch, such as on a fresh CI runner or new developer machine — is now faster thanks to batched cache writes during HTTP revalidation.

While not a feature-packed milestone, this update reflects uv’s maturing development rhythm: rapid iteration, responsiveness to user feedback, and attention to both reliability and speed. For teams relying on uv for fast dependency management in CI/CD pipelines or container builds, 0.12.15 removes a recent friction point and subtly improves first-run latency. Installation remains effortless via shell or PowerShell scripts, and binaries are provided for all major platforms — including Apple Silicon, x86_64 and ARM64 Linux, Windows (x86, x64, ARM64), and even niche architectures like RISC-V, s390x, and PowerPC.

uv continues to position itself as a high-performance, drop-in alternative to pip and venv — offering unified project management, lockfile support, Python version installation, script execution, and more — all built in Rust for speed and safety. As adoption grows, especially in infrastructure-heavy workflows, these targeted patches matter more than they might appear at first glance.
