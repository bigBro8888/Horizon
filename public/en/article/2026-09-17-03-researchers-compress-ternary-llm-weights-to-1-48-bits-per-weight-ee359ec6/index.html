Researchers compress ternary LLM weights to 1.48 bits per weight

News time: 2026-09-17T06:07:11.316962+00:00 · Source: hackernews

A new paper titled 'Breaking the 1.58-bit Barrier for Ternary LLMs' demonstrates a concrete advance in model compression: researchers have reduced the average bit cost of storing ternary large language model (LLM) weights from the long-assumed theoretical minimum of log₂(3) ≈ 1.58 bits per weight down to 1.48 bits per weight. This is not achieved through exotic mathematics or hardware-specific tricks, but by observing a simple, widespread empirical fact — real ternary models contain far more zeros than the uniform distribution assumes. Across 29 state-of-the-art ternary LLMs, including BitNet variants and Maple-Preview, the team measured zero densities ranging up to 51.5%, meaning over half the weights are exactly zero.

This imbalance breaks the assumption behind the 1.58-bit limit — which only holds if −1, 0, and +1 occur with equal probability (≈33.3% each). In practice, zeros dominate, so encoding schemes can exploit that skew. The authors introduce BITCOS (Bitwise Ternary COmpression Scheme), a lightweight, distribution-adaptive packing method. BITCOS uses a compact presence bitmap to flag non-zero positions, then packs the sign bits of non-zero values tightly — no arithmetic coding tables, no vector lookups, just efficient bit-level layout tuned to real model statistics.

The result is both practical and portable: BITCOS achieves lossless compression, requires no changes to inference kernels, and works across CPU and GPU backends. Unlike prior approaches like arithmetic coding or LUT-based vector quantization, BITCOS adds negligible runtime overhead while delivering measurable memory savings — roughly 6.3% smaller weight storage at identical accuracy. For hardware designers targeting ternary accelerators, this means more model capacity per SRAM block or higher bandwidth efficiency without redesigning compute units.

Importantly, the work reframes how we think about 'theoretical limits' in quantization. The 1.58-bit bound is information-theoretic only under uniformity — a mathematical ideal rarely seen in deployed models. By measuring actual distributions instead of assuming them, BITCOS shows how empirical rigor can beat textbook bounds. As one commenter noted, 'I honestly assumed that’s how they already work' — highlighting how intuitive yet overlooked this optimization was. It’s a reminder that sometimes the biggest gains come not from inventing new math, but from looking closely at what models actually do.
