Datasette 1.0a40 adds background task support and upgrades to httpx2

News time: 2026-09-17T06:07:10.782822+00:00 · Source: rss

Datasette — the popular open-source tool for exploring, analyzing, and publishing structured data via web APIs and interactive interfaces — has released version 1.0a40, a significant alpha milestone on the path to its long-awaited 1.0 stable release. This update delivers both foundational improvements and practical new capabilities, reflecting focused engineering effort ahead of final stabilization.

One of the most impactful additions is native background task support for plugins. Developers can now use datasette.add_background_task() to launch long-running operations — such as data imports, asynchronous API calls, or periodic cache updates — without blocking the main application thread. This opens doors for richer plugin ecosystems, including future integrations with AI-powered tools like the recently demonstrated datasette-extract plugin that uses GPT-4 to structure unstructured text.

The release also migrates Datasette’s internal HTTP client from the older httpx library to httpx2, a next-generation Python HTTP client supporting both sync and async modes, HTTP/1.1 and HTTP/2, and improved reliability and performance. This change directly benefits plugin authors who rely on datasette.client.get() for making internal requests — for example, fetching remote datasets or calling external APIs during query execution.

Security remains a priority: 1.0a40 includes the same fix applied earlier in version 0.65.5, addressing a potential vulnerability related to user-supplied input handling. Beyond that, the release bundles dozens of bug fixes — many identified during a recent triage effort targeting the 1.0 release — improving stability across SQLite introspection, template rendering, and CLI behavior. While still pre-stable, 1.0a40 signals growing maturity and developer readiness for production-grade deployments.
