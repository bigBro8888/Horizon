Hister launches as open-source offline search engine for personal data

News time: 2026-09-18T05:53:30.336425+00:00 · Source: hackernews

Hister is a new open-source, privacy-first search tool that lets users search their own digital footprint—browser history, bookmarks, local files, and even crawled websites—entirely offline. Unlike cloud-based search services, Hister builds and maintains a local index on the user’s machine, extracting text content and generating searchable previews without ever sending data to a remote server. The result is fast, private, full-text search over materials you’ve already encountered or saved—no internet connection required during querying.

The project was created by asciimoo, best known for co-founding Searx, the popular open-source metasearch engine. But where Searx routes queries across public search APIs, Hister takes the opposite approach: it brings search inward, treating the user’s device as the authoritative source of truth. This aligns with the growing 'local-first' software movement—a design philosophy prioritizing local data ownership, offline capability, and end-to-end control. As described in foundational work by Ink & Switch, local-first tools store primary data on-device, syncing only when needed and never requiring server round-trips for basic operations.

Technically, Hister supports indexing from multiple sources: Chromium- and Firefox-based browser histories (via SQLite parsing), bookmark exports (HTML or JSON), local directories (including PDFs, Markdown, and plain text), and optional web crawls of sites the user wants to archive. It uses lightweight, embedded full-text search capabilities—similar to SQLite’s FTS5 module—to enable efficient querying without heavy dependencies. Previews are generated at index time, so even pages that go offline or change remain searchable in their original form.

Real-world usage highlights its practical value: GTM professionals use it to track outbound messaging tactics across dozens of SEO and cold-email articles; developers integrate it into knowledge-management workflows alongside LLM-augmented wikis; and long-time Chrome users recall—and welcome back—the lost 2008-era feature of offline page search. Though still early-stage, Hister’s Hacker News reception (542 points, 142 comments) reflects strong resonance with privacy-conscious builders who want search power without surveillance trade-offs.
