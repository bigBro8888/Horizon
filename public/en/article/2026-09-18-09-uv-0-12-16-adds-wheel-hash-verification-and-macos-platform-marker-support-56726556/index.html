uv 0.12.16 adds wheel hash verification and macOS platform marker support

News time: 2026-09-18T05:53:30.646381+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.16, delivering concrete security and correctness improvements for developers relying on fast, reliable dependency resolution. Released on September 17, 2026, this patch release focuses less on flashy new features and more on hardening core behaviors—especially around download integrity, platform targeting, and error resilience.

A standout change is the introduction of hash verification for both wheels and source distributions downloaded from package indexes. This means uv now checks cryptographic hashes (e.g., SHA-256) provided by PyPI or private indexes before installing any package artifact—preventing silent substitution or corruption during transit. Complementing this, build dependencies declared in build-constraint-dependencies can now include their own hashes, extending verification to the build-time toolchain. These changes directly address longstanding concerns about supply-chain integrity in Python packaging.

For macOS users, uv now correctly interprets platform_release markers—such as macosx_14_0 or macosx_15_8—when evaluating required-environments in lockfiles. This ensures that wheels built for specific macOS versions (e.g., Sequoia 15.8 or Golden Gate 27.0) are selected accurately, avoiding runtime incompatibilities. Meanwhile, safer Git URL parsing prevents crashes during lockfile exports when malformed or unsupported schemes (e.g., git+ssh:// without proper host syntax) are encountered.

Beyond security and correctness, several usability enhancements land in preview: uv check now works outside uv-managed projects and respects --python flags; uv upgrade honors configured index credentials; and lock-without-metadata supports all dependency types while preserving metadata for remote URLs—enabling offline validation. Bug fixes span credential redaction (e.g., Azure SAS tokens), archive size validation before cache reuse, and robust handling of malformed proxy or index URLs—replacing panics with clear configuration errors. Taken together, uv 0.12.16 reflects a maturing tool prioritizing safety, portability, and predictable behavior across real-world Python environments.
