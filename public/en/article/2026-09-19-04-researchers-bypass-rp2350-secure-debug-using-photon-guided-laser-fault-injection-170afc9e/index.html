Researchers bypass RP2350 secure debug using photon-guided laser fault injection

News time: 2026-09-19T05:49:41.476512+00:00 · Source: hackernews

In a landmark hardware security demonstration, researchers at Ledger Donjon have successfully defeated the secure debug lockdown on Raspberry Pi’s RP2350 microcontroller — not through software exploits or protocol flaws, but by combining two physical attack techniques: photon emission analysis (PEA) and laser fault injection (LFI). The RP2350, designed with dual-core flexibility (Cortex-M33 or RISC-V Hazard3 per socket) and hardened secure boot, was widely seen as a promising candidate for hardware security tokens — even as a YubiKey alternative. Its debug interface is disabled by default in production firmware, and its one-time programmable (OTP) memory containing secrets is protected by Page Locks set to 'inaccessible' state.

The breakthrough lies in precision. Rather than brute-force laser targeting, the team first imaged the chip’s backside under controlled conditions to capture faint photon emissions from switching transistors during debug-enabling operations. These emissions revealed spatial and temporal signatures tied to the DEBUGEN register access — effectively mapping where and when the chip checks or modifies debug permissions. Using that map, they focused nanosecond-scale laser pulses onto a specific logic gate in the debug controller, inducing a single-bit flip that temporarily enabled Serial Wire Debug (SWD) before runtime mitigations could trigger.

This allowed them to read the OTP secret before firmware initialization — a critical window where runtime locks like periodic DEBUGEN checks or fail-safe resets are ineffective. The attack succeeded even with encrypted boot enabled and signed firmware running, demonstrating that physical-layer protections remain vulnerable when pre-firmware control flow can be altered. Notably, the team emphasized reproducibility: while initial discovery used $250k lab equipment, they confirmed the technique is feasible in a home lab for under $10,000 — citing accessible tools like PicoEMP as viable alternatives to commercial ChipShouters.

The implications extend beyond the RP2350. As embedded secure enclaves proliferate in consumer devices, this work underscores a fundamental tension: software-enforced security policies cannot fully compensate for unguarded physical execution paths. It also highlights how side-channel and fault-injection methods, once considered lab curiosities, are converging into practical, targeted attack workflows — demanding co-design of hardware, firmware, and physical countermeasures from the earliest stages of development.
