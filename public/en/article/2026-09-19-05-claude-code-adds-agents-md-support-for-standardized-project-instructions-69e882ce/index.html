Claude Code adds AGENTS.md support for standardized project instructions

News time: 2026-09-19T05:49:40.950868+00:00 · Source: rss

Anthropic engineer Thariq Shihipar announced that Claude Code v2.1.277 now natively supports AGENTS.md — a lightweight, open Markdown format used by over 60,000 open-source projects to guide AI coding agents. When a user opens a codebase in Claude Code, the tool first looks for CLAUDE.md (its traditional project configuration file); if none is found, it automatically falls back to AGENTS.md. This change makes project-specific agent behavior more portable and interoperable across tools — since AGENTS.md is already adopted by Cursor, Continue.dev, and other AI coding assistants.

The implementation is built on Claude Code’s upcoming ‘mods’ system: modular, composable extensions that customize how the assistant interprets context, generates output, or interacts with code. AGENTS.md support is shipped as a built-in mod — meaning it’s enabled by default and requires no installation — but developers can also fork, modify, or replace it using the open-source reference implementation hosted on GitHub. That mod repository includes not just AGENTS.md, but dozens of others covering skills, MCP servers, CLI integrations, and session-aware workflows.

What makes this notable isn’t just the feature itself, but its design philosophy: standardization through openness. Rather than locking users into proprietary instruction formats, Anthropic is embracing AGENTS.md — a community-driven spec that defines sections like # Project Context, # Active Tasks, and # Codebase Map. This lowers the barrier for teams to onboard new AI tools without rewriting documentation, and lets developers maintain one source of truth for both humans and agents.

For developers, the practical impact is immediate: dropping an AGENTS.md file into any repo now gives Claude Code contextual awareness about conventions, architecture decisions, and ongoing work — without needing to retrain or reconfigure the model. As the ecosystem matures, we’re likely to see more cross-tool alignment around such specs, reducing fragmentation and accelerating adoption of AI-assisted development in real-world engineering workflows.
