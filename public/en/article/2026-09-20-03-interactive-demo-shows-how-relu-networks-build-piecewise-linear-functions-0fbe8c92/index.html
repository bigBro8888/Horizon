Interactive demo shows how ReLU networks build piecewise linear functions

News time: 2026-09-20T06:11:06.276868+00:00 · Source: reddit

What does it look like when a neural network learns? Not just the loss curve or weight histograms—but the actual shape of the function it’s building, step by step? A new interactive educational tool answers that question visually and intuitively. Built by developer Luke Salamone and shared on Reddit’s r/MachineLearning, the demo lets users train small fully-connected neural networks with ReLU activations to approximate custom target functions—like sine waves, step functions, or parabolas—and watch in real time as the output evolves from noise into a jagged, piecewise linear approximation.

The core insight is geometric: because ReLU is piecewise linear (zero for negative inputs, identity for positive ones), any composition of ReLUs and linear layers remains piecewise linear. That means the entire network’s output is a function made of straight-line segments joined at 'kinks'—points where neurons switch from inactive to active. The demo makes this concrete: users input an architecture like "3" (one hidden layer of width 3) or "3 3" (two hidden layers, each width 3), and the interface displays the theoretical upper bound on how many linear segments the network can produce—4 for "3", and 16 for "3 3"—based on known theoretical bounds from deep learning theory.

Training happens in-browser using lightweight JavaScript (no backend), and users can pause, reset, or adjust learning rate and epochs. Crucially, the visualization doesn’t just show final results—it animates the emergence of kinks, revealing how early training creates coarse approximations, while later epochs refine segment placement and slopes. As the post notes, networks rarely hit their theoretical maximum segment count; real optimization favors smoothness and generalization over maximal complexity. This gap between theoretical capacity and practical behavior becomes immediately visible—and pedagogically powerful.

For educators and newcomers, the demo bridges abstract theory and tangible intuition. It transforms statements like 'depth multiplies expressivity' from textbook slogans into observable phenomena: adding a second hidden layer doesn’t just add parameters—it fundamentally changes the topology of possible outputs. And because it runs entirely client-side with no installation or setup, it lowers the barrier to exploring foundational concepts often obscured by framework abstractions. In an ecosystem saturated with black-box tutorials, this is a rare, grounded window into what neural networks actually do under the hood.
