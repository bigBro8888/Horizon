ProgramAsWeights compiles English function specs into CPU-runnable neural programs

News time: 2026-09-20T06:11:06.277050+00:00 · Source: reddit

ProgramAsWeights (PAW) is a new open-source research system that reimagines how software functions can be defined and executed. Instead of writing code or calling remote APIs, users describe a task in plain English—like 'Classify urgent emails'—and PAW compiles that description into a compact, self-contained neural program. Once compiled, the program runs entirely on the user’s machine: no internet connection, no API keys, no per-call fees, and no GPU required. It behaves like a regular Python function—import, compile, call—and works even on modest CPUs.

The core idea separates compilation from inference. A large, GPU-powered compiler model (a fine-tuned Qwen3-4B) generates a lightweight LoRA adapter tailored to the task. That adapter is then applied to a small, frozen 0.6B-parameter interpreter model—the same base model reused across all tasks. The resulting 'neural program' bundles both the adapter and a cleaned-up prompt with input/output examples. Crucially, the interpreter’s weights never change; only the adapter is swapped per function, enabling fast, deterministic local execution.

PAW was evaluated on FuzzyBench, a synthetic benchmark where test specifications are held out during training—meaning the compiler must generalize to unseen tasks. On this setup, PAW’s 0.6B interpreter achieved 73.4% exact-match accuracy, outperforming direct prompting of the much larger Qwen3-32B model (68.7%). For higher accuracy, PAW supports 'Compile by Training': the generated adapter is used as initialization for 100 steps of fine-tuning using teacher-synthesized examples—adding ~1 minute to compilation but preserving the same local runtime format.

This approach sits at the intersection of program synthesis, neural compilation, and edge AI deployment. Unlike traditional symbolic program synthesis—which produces verifiable, executable code—PAW produces differentiable, probabilistic neural programs. Yet unlike typical LLM-as-function wrappers, PAW eliminates runtime dependence on large models or cloud services. The result is a new paradigm: functions defined in natural language, compiled once, and run forever—locally, privately, and predictably.
