datasette-auth-github reaches 1.0 with critical cookie lifetime fix

News time: 2026-09-20T06:11:05.465363+00:00 · Source: rss

Simon Willison has officially released datasette-auth-github version 1.0 — a milestone that signals production readiness for this widely used Datasette plugin. The release isn’t just symbolic: it ships with a crucial fix for authentication cookie expiration, specifically addressing short-lived sessions on mobile browsers like Safari. Willison discovered the issue while using the plugin on agent.datasette.io, his public demo site: logged-in users were frequently being logged out unexpectedly, especially on iOS devices. The root cause turned out to be missing Max-Age attributes in the Set-Cookie headers — meaning cookies defaulted to “session-only” behavior, vanishing whenever Mobile Safari decided to terminate its session (which happens more aggressively than on desktop browsers).

This fix, implemented in GitHub issue #80, ensures authentication cookies now persist for a defined duration rather than disappearing at the browser’s discretion. Beyond the technical correction, the 1.0 designation reflects broader maturity: the plugin has been actively maintained for years, supports both Datasette 0.65.x and the upcoming 1.0 alpha series, and undergoes cross-version compatibility testing. Willison explicitly notes his intention to promote stable, well-tested plugins to 1.0 more deliberately — a welcome shift from the common pattern of perpetually versioning open-source tools as pre-1.0.

For developers deploying Datasette in real-world settings — especially those serving authenticated data dashboards or internal tools — this update directly improves reliability and user experience. It also aligns with modern web best practices: MDN and RFC standards strongly recommend Max-Age over the legacy Expires attribute because it’s relative, less error-prone, and takes precedence when both are present. While the change is small in code size, its impact is outsized for mobile-first deployments.

The release underscores how seemingly minor HTTP details — like cookie lifetime semantics — can disproportionately affect usability across platforms. It’s a quiet but meaningful example of thoughtful open-source maintenance: identifying a subtle, platform-specific pain point; fixing it cleanly; and marking the result as stable. As Datasette itself approaches its own 1.0 release (with recent alpha versions like 1.0a39 already shipping security patches), ecosystem plugins like this one help solidify the framework’s credibility for production use.
