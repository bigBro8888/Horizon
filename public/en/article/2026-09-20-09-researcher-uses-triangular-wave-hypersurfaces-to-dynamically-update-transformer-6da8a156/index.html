Researcher uses triangular wave hypersurfaces to dynamically update transformer weights

News time: 2026-09-20T06:11:06.277179+00:00 · Source: reddit

A solo researcher has introduced a novel parameter-efficient architecture for decoder-only language models, aiming squarely at the VRAM bottleneck in training. Instead of stacking dozens of transformer layers, the approach reuses a single decoder block across multiple iterations—like the Universal Transformer—but with a twist: rather than updating only the hidden states, it dynamically adjusts the block’s weights on each pass. These adjustments are not learned per iteration, but generated on-the-fly from compact, learnable periodic functions—specifically triangular waves—defined over low-dimensional coordinate spaces called hypersurfaces.

The core innovation lies in how weight deltas (ΔWₗ) are produced. Each weight matrix at iteration l is reconstructed as Wₗ = W₀ + ΔWₗ, where W₀ is a small base layer and ΔWₗ is derived from cross-sections of learned triangular wave hypersurfaces. Crucially, the geometry of these waves—amplitude, frequency, and phase—is modulated by a lightweight state vector computed from the input sequence using Gated Linear Attention. This makes the weight updates sequence-aware, avoiding the rigidity of static or iteration-count-only modulation.

Trained on 10 billion tokens from FineWeb-Edu, the best-performing variant—a three-loop-block model with triangular wave hypersurfaces and context modulation—used just 27.2 million parameters, only 16% the size of a standard 24-layer transformer (169.9M). Though its final loss remained higher than the full-parameter baseline, it significantly outperformed both a naive unrolled single-layer model and a sinusoidal-wave version. The author explicitly frames the goal not as beating large models outright, but achieving "good enough" performance while slashing memory and compute demands—especially relevant for edge or low-resource training.

This work sits at the intersection of several active trends: hypernetworks (which generate weights for other networks), weight tying, and iterative refinement architectures. Unlike LoRA or adapter-based methods that inject trainable modules, this method reshapes core weights themselves—using far fewer parameters than even typical hypernetworks. The GitHub repository includes full code and ablation experiments, though no pre-trained checkpoints or detailed hardware benchmarks are yet published. Future work includes scaling up the functional basis, enlarging the context vector, and running longer training runs to test convergence behavior.
