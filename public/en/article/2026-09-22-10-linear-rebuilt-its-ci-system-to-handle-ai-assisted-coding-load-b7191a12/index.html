Linear rebuilt its CI system to handle AI-assisted coding load

News time: 2026-09-22T06:10:08.660434+00:00 · Source: hackernews

Linear, the developer-first project management tool, recently overhauled its continuous integration (CI) infrastructure—not because of scaling pains from user growth, but because of a surprising new pressure: AI-assisted coding. As engineers increasingly rely on large language models to generate code, pull requests have grown larger, more frequent, and more test-heavy. This surge exposed latent bottlenecks in Linear’s existing GitHub Actions–based pipeline, where builds were queuing for minutes and slowing down feedback loops.

The team didn’t just tweak settings—they rearchitected. Linear migrated key workloads off GitHub Actions to third-party CI runners with faster CPUs, higher-throughput storage, and purpose-built cache infrastructure. Crucially, they redesigned their caching strategy to better handle the write-heavy, non-deterministic patterns introduced by AI-generated code—like repeated boilerplate, duplicated test suites, and inconsistent file access patterns. The result? Median build times dropped significantly, and developers regained sub-minute feedback on PRs.

This isn’t just an ops win—it reflects a broader shift in software engineering dynamics. AI tools amplify developer output, but they don’t eliminate systemic friction; instead, they magnify it. When every engineer ships 3× more code per day, legacy CI systems—designed for human-paced, deterministic workflows—struggle to keep up. Linear’s fix highlights how infrastructure must evolve with AI adoption, not just alongside it.

Beyond speed, the change surfaced deeper questions about quality and intentionality. As community comments note, faster CI doesn’t guarantee better software: tests generated by LLMs often cover trivial logic or built-in behaviors while missing real user workflows. Human-centered validation—does it work, does it make sense, does it delight—remains irreplaceable. Linear’s engineering response is pragmatic, but its implications are philosophical: velocity without discernment risks turning development into motion without direction.
