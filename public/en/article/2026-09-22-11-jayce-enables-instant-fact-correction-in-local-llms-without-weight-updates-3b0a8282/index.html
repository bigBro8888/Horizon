Jayce enables instant fact correction in local LLMs without weight updates

News time: 2026-09-22T06:10:08.715962+00:00 · Source: reddit

A new open-source project called Jayce introduces a radically lightweight approach to teaching local large language models (LLMs) new facts on the fly—without touching their weights, fine-tuning, or requiring external frameworks. Developed by researcher /u/kavanutz, Jayce is built around Adaptive Prototype Memory (APM), a memory-augmented mechanism that stores and updates context vector prototypes instead of model parameters. Inspired by how toddlers learn words through quick, targeted corrections—not massive retraining—Jayce treats each factual update as a geometric shift in a fixed pool of 4,096 prototype slots. When a user corrects the model’s output, Jayce identifies the nearest prototype in embedding space and moves it incrementally toward the corrected context vector—like nudging a compass needle toward true north.

Unlike traditional backpropagation, which recalculates gradients across millions of parameters, Jayce’s update is purely vector arithmetic: cosine-similarity-based retrieval followed by a small Euclidean step. The entire system runs offline on consumer hardware using Qwen3-4B GGUF, with implementations in pure NumPy (jayce_tokens.py) and native Java (JayceMemory.java)—no PyTorch or TensorFlow required. Benchmarks show Jayce achieves 1.6× to 4× faster learning updates than Adam-based backprop on sequential tasks like MNIST digit classification—and even outperforms backprop in accuracy when given identical numbers of training examples.

What makes Jayce especially relevant for local AI is its strict memory ceiling and zero catastrophic forgetting. Because it never modifies the base model’s weights, prior knowledge remains intact; corrections live only in the decoupled prototype memory. This sidesteps the classic trade-off between plasticity and stability that plagues fine-tuning and RAG pipelines. The prototype pool also avoids prompt inflation: unlike in-context learning (ICL), which consumes precious context window space with demonstrations, Jayce embeds task-specific knowledge into compact, reusable vectors—similar in spirit to In-Context Vectors (ICV), but operating at the prototype level rather than latent steering.

The project is intentionally minimal—a proof-of-concept, not a production system—but its implications are tangible. For developers building privacy-sensitive, offline-first LLM applications (e.g., personal knowledge assistants or edge-device tutors), Jayce offers a viable path toward adaptive, human-in-the-loop learning. Its framework-free design lowers entry barriers, while its neuro-inspired architecture invites deeper scrutiny from both ML engineers and cognitive scientists. The GitHub repo includes runnable benchmarks, visualizations of prototype shifts, and a terminal interface for live interaction—making it as accessible to experiment with as it is conceptually distinct.
