LLM CLI adds support for GPT-6 Sol and Luna models

News time: 2026-09-23T05:56:01.182193+00:00 · Source: rss

Simon Willison has released version 0.36 of the llm command-line tool — a widely used open-source utility for interacting with dozens of large language models, from OpenAI and Anthropic to local models like Mistral and Gemma. This release stands out not only for its technical refinements but for something far more consequential: official integration of two newly announced OpenAI models — gpt-6-sol and gpt-6-luna. According to OpenAI’s own announcements published just hours before the llm release, these are real, production-deployed models now available via GitHub Copilot and OpenAI’s API, with Sol emphasizing deep reasoning and Luna optimized for speed and throughput.

The addition isn’t just cosmetic. The llm tool now treats these models as first-class citizens, enabling users to invoke them directly via llm -m gpt-6-sol '...' or llm chat -m gpt-6-luna. Crucially, this integration arrives alongside a new architectural safeguard: model plugins can now declare supports_conversation = False, forcing single-turn usage where appropriate. The first plugin to adopt this is llm-typesafe, which wraps TypeSafe AI’s classification models — systems designed for yes/no decisions, not multi-turn dialogue. When such a model is selected for an interactive chat session, llm chat refuses to start, preventing silent misbehavior or confusing errors.

Beyond model support, v0.36 improves developer ergonomics. Reasoning traces in llm logs output — previously shown inline — are now collapsible using HTML <details><summary> tags, making verbose logs easier to scan. The release also includes bug fixes contributed by five new developers, underscoring the project’s growing community involvement.

What makes this release especially notable is timing and authenticity. Unlike speculative rumors, the gpt-6-sol and gpt-6-luna endpoints link directly to OpenAI’s official documentation and pricing pages — confirming their existence and availability. For developers building on top of LLM tooling, this means immediate access to cutting-edge capabilities without waiting for SDK updates or third-party wrappers. It also signals that llm remains tightly coupled to upstream API evolution — a key strength in a fast-moving ecosystem.
