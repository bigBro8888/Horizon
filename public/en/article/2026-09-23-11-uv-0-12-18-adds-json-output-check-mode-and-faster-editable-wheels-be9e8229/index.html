uv 0.12.18 adds JSON output, --check mode, and faster editable wheels

News time: 2026-09-23T05:56:02.211599+00:00 · Source: github

Astral has released uv 0.12.18 — the latest update to its blazing-fast Python package installer and resolver. Released on September 22, 2026, this patch delivers practical improvements for developers who rely on uv for dependency management, environment setup, and reproducible builds. Unlike major version jumps, this release focuses on reliability, interoperability, and automation-readiness — making it especially valuable for CI/CD pipelines, tooling integrators, and teams adopting uv at scale.

The most immediately useful additions are --output-format json and --check. The new JSON output option works across uv pip install and uv pip sync, including with --dry-run and --check, enabling structured parsing in scripts and IDE integrations. Meanwhile, --check lets users preview exactly what would be installed or removed — without touching the environment — a long-requested safety guard for automated workflows. These features bring uv closer to production-grade robustness while preserving its signature speed.

Under the hood, uv’s build system is becoming more resilient. It now correctly identifies failures from PEP 517 get_requires_for_build_* hooks — critical for projects using modern build backends like setuptools or hatchling. A related preview feature validates build dependencies when using uv build --no-build-isolation, helping catch missing build-time requirements before compilation fails mid-process. Performance also sees a tangible win: editable wheel creation is significantly faster thanks to skipping compression during temporary wheel generation — a small but impactful optimization for local development loops.

Bug fixes round out the release with notable attention to correctness and portability. uv now properly handles wheel compatibility across Python ABI variants (e.g., stable vs. generic tags), restores project files on interrupted operations like uv add or uv remove, and avoids dangerous path normalization on Windows — rejecting archive entries that resolve to absolute paths. It also correctly parses URLs with query fragments (e.g., ?v=1.2) and generates accurate platform tags for BSD and Haiku systems. Taken together, these changes reflect uv’s maturing focus: not just raw speed, but predictable, secure, and cross-platform behavior.
