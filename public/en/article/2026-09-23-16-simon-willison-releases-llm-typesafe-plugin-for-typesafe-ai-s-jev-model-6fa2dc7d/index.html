Simon Willison releases llm-typesafe plugin for TypeSafe AI's Jev model

News time: 2026-09-23T05:56:01.182263+00:00 · Source: rss

Simon Willison, creator of the popular LLM command-line interface tool, has released llm-typesafe 0.1a0 — a new plugin that integrates TypeSafe AI’s Jev model into the LLM ecosystem. Unlike traditional large language models that generate free-form text, Jev is designed specifically for structured decision-making: it returns calibrated, machine-readable outputs like yes/no/uncertain ('noul'), discrete choices, or ordinal scores — all with confidence estimates. The plugin makes these capabilities accessible directly from the terminal, enabling developers to embed precise, deterministic AI judgments into scripts, automation pipelines, and agent workflows.

Installation is straightforward: users run llm install llm-typesafe, then set their TypeSafe API key using llm keys set typesafe. Once configured, they can invoke Jev with commands like llm -m jev followed by a prompt and structured instruction. For example, asking whether a customer message explicitly requests a refund returns a JSON object like {"type": "noul", "noul": 0.99}, where the numeric value reflects calibrated confidence — not a raw logit or heuristic score.

The plugin supports three core interaction modes. In 'noul' mode, it answers binary or ternary questions with probabilistic certainty. In 'choice' mode, users define named categories (e.g., 'billing', 'technical', 'other') and Jev selects the best-fitting one based on criteria they supply. In 'score' mode, it ranks input against an ordered list of evaluation criteria — useful for triaging bug reports or assessing content quality. Each mode avoids open-ended generation, instead producing bounded, parseable output ideal for programmatic branching.

This release fits into a broader shift toward 'System One' AI models — a term coined by TypeSafe AI to describe fast, deterministic, decision-first models inspired by Daniel Kahneman’s dual-process theory. While LLMs serve as 'System Two' (slow, deliberative, linguistic), Jev acts as 'System One' (fast, intuitive, typed). The llm-typesafe plugin doesn’t replace LLMs; rather, it augments them by offloading classification, routing, and guardrail tasks to a purpose-built model. As Willison notes, this lowers the barrier for developers who need reliable, auditable AI decisions — not just fluent prose.
