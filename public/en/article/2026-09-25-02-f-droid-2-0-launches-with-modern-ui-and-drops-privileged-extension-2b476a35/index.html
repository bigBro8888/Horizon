F-Droid 2.0 launches with modern UI and drops privileged extension

News time: 2026-09-25T06:08:33.874804+00:00 · Source: hackernews

F-Droid — the long-standing open-source Android app store dedicated to free and privacy-respecting software — has released version 2.0, its most significant update in over a decade. The new release overhauls the entire user interface, replaces outdated architecture, and officially retires the F-Droid Privileged Extension (FPE), a component that previously required deep system integration to enable silent app installs and updates. This shift marks a deliberate move toward greater compatibility, security, and usability — especially on hardened Android forks like GrapheneOS and LineageOS, where FPE often caused configuration headaches or instability.

The redesign prioritizes clarity and accessibility: navigation is simplified, app discovery is more intuitive, and visual hierarchy has been strengthened to distinguish interactive elements from static content. Behind the scenes, F-Droid 2.0 migrates to a modern Android architecture using Jetpack Compose and Material 3, enabling smoother animations, better accessibility support, and easier maintenance. Crucially, it no longer relies on privileged system permissions — instead, it leverages Android’s built-in package installer APIs with explicit user confirmation for each install or update, aligning with modern Android security models.

This architectural pivot addresses longstanding pain points. For years, users on privacy-focused ROMs reported inconsistent FPE behavior — failed updates, permission denials after reboots, or outright incompatibility with newer Android versions. Removing FPE eliminates those friction points while preserving core functionality: verified builds, reproducible APKs, and strict FOSS licensing enforcement. However, automatic background updates are now replaced by scheduled, user-confirmed batch updates — a trade-off between convenience and transparency.

Community response reflects both enthusiasm and thoughtful critique. Many welcome the cleaner UX and FPE deprecation, especially those who struggled with setup on GrapheneOS or LineageOS. Others raise valid concerns about missing social signals — notably, the absence of user reviews or ratings makes app evaluation harder for newcomers. Design critics point to subtle but meaningful gaps in visual affordance, such as unclear tap targets or ambiguous scroll boundaries — issues that matter deeply for usability, even in a privacy-first tool. Looking ahead, questions linger about sustainability: how will F-Droid evolve as Google tightens ecosystem controls in 2027? Its success now hinges not just on technical execution, but on building trust through transparency, consistency, and community co-design.
