Whiteboard launches open-source IDE for AI-human software design collaboration

News time: 2026-09-25T06:08:33.874846+00:00 · Source: hackernews

Whiteboard, a new open-source desktop IDE developed by a Y Combinator W26 batch team, aims to restore the clarity and shared understanding of in-person whiteboard sessions—but for modern AI-assisted software development. Built by former tech leads Sid, Alex, Ketan, and Milan, the tool provides a shared visual canvas where developers and AI agents (like Claude Code) co-design systems through diagrams, traces, and decision logs—not just code. Unlike traditional editors, Whiteboard bridges high-level architecture and low-level implementation: clicking on a sequence diagram or entity relationship visualization jumps directly to relevant source files, backed by full VS Code–level language support via its foundation on Code OSS.

The app tackles three persistent pain points in agentic coding. First, it introduces a semantic diff viewer written in Rust that filters noise—collapsing test additions, summarizing large functions as pseudocode, and highlighting only AST-level meaningful changes. Second, it embeds a decision log that lets developers trace how an AI agent interpreted requirements and which design choices it made autonomously. Third, it integrates natively with LLM toolchains: agents use the Claude Agent SDK to draw, annotate, and update the canvas in real time, turning opaque AI outputs into auditable, navigable design artifacts.

Early adopters—including engineering teams at Salesforce and Modal—are using Whiteboard not for daily coding, but for architecture reviews and spec-level change validation. Teams run AI agents to generate prototypes and corresponding Whiteboard sessions, then review both the code and the visual reasoning side-by-side. It also composes well with tools like Greptile: automated reviewers handle small diffs, while complex, judgment-sensitive changes escalate to a collaborative Whiteboard session. The team explicitly designed it to fight ‘cognitive debt’—the growing gap between code velocity and human comprehension that emerges when PRs pile up without shared context.

Whiteboard is released under the MIT license as a desktop application for macOS, Windows, and Linux (correcting early community confusion about platform support). While the core remains free and self-hostable, the team plans a future hosted web version with features like multiplayer review sessions, trajectory storage, and centralized session management—targeted at enterprise teams. Their philosophy is clear: all functionality must remain locally runnable and extensible, with a WASM-based plugin system enabling custom diff rules, visualization renderers, and trace integrations.
