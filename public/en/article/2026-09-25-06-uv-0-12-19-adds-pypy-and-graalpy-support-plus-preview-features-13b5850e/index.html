uv 0.12.19 adds PyPy and GraalPy support plus preview features

News time: 2026-09-25T06:08:34.711328+00:00 · Source: github

The Rust-based Python package manager uv has released version 0.12.19, marking another step in its rapid evolution as a high-performance alternative to pip and related tools. Released on September 24, 2026, this patch brings expanded interpreter compatibility, improved error clarity, and two experimental features aimed at future Python versions and more efficient lockfile handling.

One of the most practical updates is official support for PyPy 3.11.16 and 3.12.14 — the latest stable releases of the just-in-time compiled Python implementation known for speed in long-running programs. uv also now supports GraalPy 3.13.0 (build 25.4.4), Oracle’s Python runtime built on GraalVM, which targets polyglot applications and native image compilation. These additions mean developers using alternative Python runtimes can now leverage uv’s speed — up to 100× faster than pip in some scenarios — for dependency resolution, installation, and publishing.

The release also improves developer experience: uv publish now formats upload URLs with backticks in error messages, making them easier to copy and debug. Several bug fixes address subtle but impactful edge cases — such as preserving signed query parameters in direct-URL dependencies (preventing unnecessary reinstalls) and correctly interpreting version specifiers like ===1 to match installed packages. A Rust API change restores the public FlatDistributions export, helping downstream resolvers integrate with uv’s internal distribution logic.

Two preview features signal longer-term direction. The build-lazy-imports flag enables lazy import evaluation during build-backend hooks on CPython 3.15+, reducing startup overhead for large projects. Meanwhile, resolution-inputs makes lockfiles smarter by omitting unused resolution settings (e.g., --python-version) and ignoring changes to them when checking freshness — a meaningful optimization for teams managing complex, multi-target environments. Both are opt-in and disabled by default, reflecting uv’s cautious approach to stabilizing new capabilities.

As uv continues maturing — backed by Astral, the team behind Ruff — it consolidates more of the Python toolchain into a single, statically linked binary. With support across macOS, Linux, and Windows, and growing adoption in CI pipelines and monorepos, uv isn’t just speeding up installs: it’s reshaping how Python projects define reproducibility, portability, and performance.
