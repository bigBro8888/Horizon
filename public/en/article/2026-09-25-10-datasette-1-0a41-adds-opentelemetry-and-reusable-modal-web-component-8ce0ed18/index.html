Datasette 1.0a41 adds OpenTelemetry and reusable modal web component

News time: 2026-09-25T06:08:33.518708+00:00 · Source: rss

Datasette — the open source tool for exploring, visualizing, and publishing structured data as interactive websites — has released version 1.0a41, an alpha milestone that delivers two meaningful architectural upgrades. Though still pre-stable, this release signals growing maturity in both observability and plugin extensibility, two critical dimensions for a data tool increasingly used in production environments and embedded workflows.

The first major change is native OpenTelemetry support, contributed by developer Alec Garcia. OpenTelemetry is an industry-standard framework for collecting telemetry data — including traces, metrics, and logs — from applications. By integrating it, Datasette now enables operators to monitor request latency, error rates, database query performance, and plugin behavior using existing observability backends like Prometheus, Grafana, or SigNoz. This isn’t just logging: it’s structured, vendor-agnostic instrumentation baked directly into Datasette’s core HTTP and database layers.

The second improvement is a clean, forward-looking refactor of Datasette’s UI modals. Previously, each modal dialog — such as those for editing table rows, setting column types, or navigating jump menus — was implemented separately with duplicated logic. Now, they’ve been unified into a single, documented, standards-compliant Web Component (<datasette-modal>). This component is exposed via Datasette’s JavaScript plugin API and comes with TypeScript definitions, lifecycle hooks, and clear usage examples in the official docs. Plugin authors can now instantiate consistent, accessible, and theme-aware modals without reimplementing layout, keyboard navigation, or backdrop behavior.

Together, these changes reflect a shift from Datasette as a simple exploration tool toward a more robust, observable, and embeddable platform. The OpenTelemetry integration lowers the barrier for teams running Datasette at scale, while the Web Component refactor reduces friction for developers building custom interfaces or integrations — especially those working with modern frontend frameworks or low-code tools. As Simon Willison noted in his announcement, these aren’t flashy features, but foundational ones: the kind that make future innovation faster, safer, and more collaborative.
