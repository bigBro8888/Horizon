Excel now lets you store multiple values in one cell

News time: 2026-09-26T06:07:57.132445+00:00 · Source: hackernews

Microsoft Excel has quietly crossed a major threshold: it now natively supports storing and operating on multiple values within a single cell. This isn’t just about comma-separated text—it’s a structural shift enabled by dynamic arrays and list-based data validation. Users can now enter lists directly (e.g., = {"Apple","Banana","Cherry"}), reference them from tables or dropdowns, and use new functions like FILTER, UNIQUE, and SEQUENCE to manipulate those values without complex workarounds. The feature is designed for non-programmers who regularly juggle semi-structured data—like teams tracking software tools per user, product SKUs per order, or skills per employee.

This capability builds on Excel’s 2019–2021 dynamic array overhaul, which introduced spilling: formulas that return arrays automatically populate adjacent cells. But the latest update goes further by letting users contain arrays inside cells—not just spill them out. Behind the scenes, Excel treats these as lightweight list objects, compatible with data validation, sorting, filtering, and even conditional formatting. Microsoft emphasizes usability over coding: no VBA, no Power Query required, and minimal syntax—just curly braces or table references.

The change reflects Excel’s evolving role in enterprise data workflows. As one commenter noted, Excel remains indispensable for analysts and business users who lack developer access or approval cycles for custom tools. Yet this expansion also invites scrutiny: some users worry about visual clutter, inconsistent editing behavior, or missed opportunities—like native support for probability distributions or keyboard shortcuts for inline list editing. Others point out real-world pain points this solves, such as parsing messy comma-delimited fields that previously demanded helper columns or regex-like formulas.

Ultimately, this isn’t about replacing databases or programming languages. It’s about lowering the barrier for structured thinking inside spreadsheets—making Excel more expressive without demanding fluency in code. For millions of knowledge workers who live in grids but don’t write scripts, it’s a meaningful step toward handling richer, messier, more human-shaped data.
