Reladraw launches as a human- and agent-friendly diagram language with manual layout control

News time: 2026-09-27T06:35:07.048834+00:00 · Source: hackernews

Reladraw is a new open-source diagram language designed for developers, technical writers, and AI agents who need precise visual control without sacrificing editability or automation. Unlike Mermaid or Graphviz—which delegate layout to opaque algorithms—or GUI tools like Draw.io that require mouse-driven editing, Reladraw lets users declare where elements go using intuitive relative positioning (e.g., "node A right of node B", "label below arrow"). The result is a plain-text format that remains readable, version-controllable, and scriptable—ideal for documentation, architecture diagrams, and agent-assisted development.

The tool emerged from a practical frustration: existing options force a trade-off. Auto-layout tools produce unpredictable outputs, making it hard to align diagrams with mental models or design intent. Drag-and-drop editors, while flexible, are slow to edit, impossible to diff meaningfully, and inaccessible to LLMs or CLI tools. Reladraw bridges that gap by treating placement as first-class syntax—not an afterthought. Its playground at github.com/reladraw/reladraw requires no install, and npm packages plus Claude-compatible skills are already available.

Technically, Reladraw uses a declarative, line-oriented syntax built around spatial relationships rather than graph topology. It supports nodes, arrows, labels, groups, and basic styling—all expressed in ASCII text. Crucially, it avoids complex coordinate systems or pixel math; instead, it relies on composable relative constraints (e.g., "C above A and left of B") that remain stable under edits. This makes diagrams both human-intuitive and machine-parsable: agents can insert, move, or annotate elements by editing text lines—not parsing SVG or simulating clicks.

Early community response has been enthusiastic but grounded. Practitioners praise its alignment value in AI-assisted coding—especially for clarifying system boundaries or data flow before writing code. Others highlight its potential for Obsidian or VS Code integrations, though current workflows still involve copy-pasting from the HTML playground. One recurring note is the desire for native Markdown embedding (like mermaid), which isn’t yet supported but is technically feasible via renderer plugins. As documentation becomes increasingly co-authored by humans and agents, Reladraw offers a rare middle path: intentional, editable, and interoperable.
