Interactive NumPy MLP visualizer shows weights, t-SNE, and ablation in real time

News time: 2026-09-27T06:35:07.343886+00:00 · Source: reddit

A new open-source educational tool lets learners watch a neural network learn — literally. Built entirely in NumPy with no deep learning frameworks or automatic differentiation, the tool implements a small multilayer perceptron (MLP) from first principles: manual forward pass, hand-coded backpropagation, SGD with momentum, L2 regularization, dropout, cosine learning rate decay, and four activation functions. Trained on MNIST, it achieves ~98.5% test accuracy — not state-of-the-art, but more than sufficient for pedagogy.

What sets this project apart is its live, interactive GUI. As training progresses, users see real-time plots of loss per mini-batch and epoch, gradient norms per layer, and the percentage of inactive (dead) neurons. Weight distributions update dynamically — comparing current values to initialization — while first-layer receptive fields animate to show how filters evolve. Beyond diagnostics, the interface offers deeper interpretability: PCA and t-SNE embeddings of the test set are computed layer-by-layer in pure NumPy, revealing how representations separate (or collapse) across hidden layers. Each misclassified digit draws a line to the cluster of the class it was confused with — making classification errors spatially legible.

The tool also includes a dedicated 'lab' for controlled experimentation. Users can ablate individual neurons (zero them out), rescale their outputs, prune entire units, inject weight noise, or adjust softmax temperature — and instantly see how test accuracy shifts. Robustness curves visualize performance under increasing input noise or rotation, while a confidence-accuracy tradeoff plot shows coverage versus correctness at varying thresholds. All of this runs locally, transparently, and without black-box abstractions.

Designed for accessibility, the project targets high school students, self-learners, and university instructors alike. Its GitHub repository includes clear documentation, minimal dependencies, and classroom-ready examples. By stripping away framework complexity, it refocuses attention on what actually happens inside a neural network — not just how to train one, but how to see it think.
