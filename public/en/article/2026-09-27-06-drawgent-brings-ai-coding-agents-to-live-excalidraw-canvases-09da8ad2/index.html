Drawgent brings AI coding agents to live Excalidraw canvases

News time: 2026-09-27T06:35:07.048939+00:00 · Source: hackernews

Drawgent is an open-source AI coding agent that operates directly on a live Excalidraw canvas—enabling real-time, collaborative diagramming where developers and AI co-edit architectural sketches, flowcharts, and system designs. Unlike traditional AI tools that generate static diagrams or require copy-paste round trips, Drawgent interacts with the canvas as it runs, responding to natural language prompts, refining shapes, adding annotations, and even generating code snippets linked to visual elements—all while preserving Excalidraw’s signature hand-drawn aesthetic and end-to-end encrypted collaboration.

The project sits at a meaningful intersection: AI agent frameworks (like those built on the Model Context Protocol, or MCP) and real-time whiteboarding infrastructure. Excalidraw already supports MCP via its official open-source server, allowing external agents to read and write canvas state. Drawgent leverages this interface but goes further—it embeds agent logic within the browser, enabling low-latency, context-aware interactions without relying on remote inference for every edit. This makes it especially useful for teams sketching infrastructure, API flows, or microservice topologies during design sprints.

What sets Drawgent apart isn’t just technical integration—it’s workflow philosophy. As one community commenter noted, diagramming isn’t just about output; it’s a thinking tool that surfaces knowledge gaps and hidden assumptions. Drawgent augments that process: instead of replacing human reasoning, it acts as a responsive collaborator—suggesting layout improvements, auto-aligning components, or translating a vague prompt like ‘show auth flow between frontend and identity service’ into annotated arrows and labeled boxes. It doesn’t aim to replace Mermaid or Obsidian plugins, but offers a complementary path—one rooted in spatial, visual, and synchronous collaboration.

While still early-stage, Drawgent reflects a broader shift toward agent-native interfaces: tools designed from the ground up for AI-human co-authorship, not bolted-on automation. Its GitHub repository shows active iteration on canvas synchronization, error recovery, and prompt grounding—indicating serious engineering attention behind the concept. For developers tired of switching between chat windows, IDEs, and static diagram tools, Drawgent points toward a more fluid, embodied way of designing systems—together, in real time.
