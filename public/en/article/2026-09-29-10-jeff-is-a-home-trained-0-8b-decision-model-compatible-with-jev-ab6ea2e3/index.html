Jeff is a home-trained 0.8B decision model compatible with Jev

News time: 2026-09-29T06:51:52.975388+00:00 · Source: hackernews

Jeff is a new open-source decision model that lets developers run fast, lightweight AI classification tasks locally — without relying on cloud APIs or large language models. Released on GitHub by developer firelex, Jeff has just 0.8 billion parameters and is explicitly designed to be Jev-compatible: it accepts the same input format and returns the same structured output (e.g., typed decisions, scores, probabilities) as the commercial Jev API. Crucially, it achieves ~30 ms inference latency on modest hardware — such as a consumer-grade GPU or even high-end CPUs — making it viable for real-time edge use cases like moderation, intent detection, or routing.

Unlike general-purpose LLMs, Jeff is purpose-built for decision tasks: classifying sentiment, detecting abuse, routing support tickets, or scoring risk — all without generating text. Its architecture draws from the broader System One model family, which prioritizes efficiency and determinism over generative fluency. The training was done entirely at home, using publicly available datasets and open tooling; the repository includes full training scripts, quantized weights, and benchmarks against both synthetic and real-world classification workloads.

The release arrives amid growing scrutiny of AI bloat. As Hacker News comments show, many developers are fatigued by oversized models doing simple jobs — one user quipped about “pimp my LLM” — and are actively seeking leaner alternatives. Jeff fits squarely into this trend alongside other Jev-compatible models like Kev and Laya AI, all aiming to replace heavyweight LLMs in narrow, high-frequency classification scenarios. Still, accuracy trade-offs exist: one user reported 70% accuracy versus Jev’s claimed 94% on their internal task, highlighting that compatibility doesn’t guarantee parity.

What makes Jeff notable isn’t raw performance, but accessibility. It lowers the bar for running production-grade decision logic offline — no vendor lock-in, no per-million pricing, no data egress. For startups, researchers, or privacy-sensitive applications, that autonomy matters. And while Jev itself remains a closed commercial service (with no public architecture docs), the ecosystem of open recreations is rapidly maturing — turning ‘Do Jev at home’ from a meme into a practical engineering option.
