Researcher hijacks PS5’s RTMP streaming traffic via MITM

News time: 2026-09-29T06:51:52.975433+00:00 · Source: hackernews

A security researcher has demonstrated how to intercept and manipulate the PlayStation 5’s live video streaming traffic by performing a man-in-the-middle (MITM) attack on its Real-Time Messaging Protocol (RTMP) stream. The PS5 natively supports streaming gameplay directly to platforms like Twitch and YouTube when users are signed in — but instead of using encrypted RTMPS, the console sends unencrypted RTMP traffic over the local network during setup and handshaking. By redirecting DNS queries for streaming endpoints and running a local RTMP server (e.g., nginx-rtmp), the attacker can impersonate Twitch or YouTube, capture raw video and audio frames, and even inject custom overlays or metadata before forwarding the stream onward.

This isn’t theoretical: the technique is implemented in open-source tools like PS5-Streamer, which repurposes the PS5’s built-in streaming feature to broadcast to third-party platforms such as Bilibili. The setup relies on dnsmasq to spoof DNS responses and route PS5 traffic to a local nginx-rtmp instance — effectively turning a Raspberry Pi or small Linux server into a stealthy streaming proxy. While Sony doesn’t officially support this use case, the exploit works because the PS5’s streaming stack makes no certificate validation or protocol enforcement beyond basic RTMP handshake negotiation.

The implications extend beyond novelty. Unencrypted RTMP means video, audio, and potentially session tokens flow in plaintext — exposing sensitive data to anyone on the same network segment. As one commenter noted, this lack of encryption leaves room for more serious exploits, especially given RTMP’s complex parsing logic and legacy design. Meanwhile, Microsoft has moved toward official, secure alternatives: Xbox consoles now support certified external destinations like Lightstream Studio using modern protocols, eliminating the need for MITM workarounds.

Still, the hack highlights an enduring tension in consumer hardware: convenience versus control. Console manufacturers prioritize seamless user experiences over deep protocol hardening — and developers fill the gap with creative, community-driven tooling. For hobbyists, streamers, or cloud gaming experimenters, this method offers low-cost, high-fidelity capture without HDMI capture cards. But it also underscores how much foundational infrastructure remains exposed — not due to flaws, but by design.
