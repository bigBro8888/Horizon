Free open-source book teaches hardware-aware ML performance engineering

News time: 2026-09-30T06:39:49.262029+00:00 · Source: reddit

A new free, open-source book titled How to Make Your Model Fast: A Systems View of Efficient Machine Learning, from Silicon to Agents offers a rare, unified framework for ML performance engineering — one that starts not with algorithms or code, but with silicon. Written by systems and ML engineer Usamah Zafar (u/SoloTiger_), the book challenges the common misconception that reducing FLOPs automatically yields faster inference. Instead, it teaches practitioners to first diagnose system bottlenecks using tools like roofline analysis — asking: Is this workload compute-bound? Memory-bandwidth-limited? Or constrained by PCIe transfer, cache hierarchy, or even OS scheduling?

The book’s progression mirrors the full stack: it begins with hardware fundamentals and arithmetic intensity, moves through kernel optimization and compiler-aware quantization, then tackles domain-specific challenges — from on-device LLMs and vision models to robotics and real-time agent systems. Each chapter emphasizes reasoning over recipes: readers learn not just how to apply pruning or INT4 quantization, but when those techniques will meaningfully shift the bottleneck — and when they’ll waste engineering effort. Serving infrastructure, profiling toolchains (e.g., Nsight Compute), and latency-critical agent orchestration are treated as first-class performance surfaces, not afterthoughts.

Unlike most ML optimization guides that focus narrowly on model-level tricks, this resource bridges traditionally siloed domains — hardware architecture, compiler design, systems programming, and applied ML. It assumes no prior expertise in computer architecture but builds intuition step-by-step: e.g., explaining why a GPU’s Tensor Core utilization depends not only on model ops but on memory access patterns and batch size alignment. The practical orientation is reinforced by open-sourced code examples, benchmarks, and editable notebooks — all hosted on GitHub.

The timing couldn’t be more relevant. As organizations deploy increasingly complex agents and multimodal models at scale, inference latency, energy cost, and hardware utilization have become decisive operational metrics — yet few engineers receive formal training in cross-stack performance reasoning. This book fills that gap with clarity and depth. Whether you’re tuning a vision transformer for an edge robot or optimizing a RAG pipeline for sub-100ms response times, its core question remains constant: What is actually limiting speed right now — and what change would move that limit?
