Developer replaces DeepSeek with TypeSafe Jev to cut search latency by 10×

News time: 2026-09-30T06:39:49.262287+00:00 · Source: reddit

A solo developer behind indiedex.gg — a niche search engine for hidden-gem Steam games — recently overhauled a critical bottleneck in their query understanding pipeline. When users type natural-language requests like “a game like Hades that feels cozier and is co-op,” the system must parse not just keywords but layered intent: reference titles, emotional vibes (e.g., ‘cozy’), multiplayer constraints, and genre tags. Previously, this step relied on DeepSeek, a powerful open-weight LLM, invoked via free-form text generation. Though accurate, it added ~1.5 seconds of median latency per query and incurred nontrivial cost — especially problematic for a high-traffic frontend where speed directly impacts user retention.

The developer switched to TypeSafe Jev, accessed through OpenRouter’s new Decisions API. Unlike traditional LLMs, Jev doesn’t generate prose; instead, it answers a fixed set of structured questions in parallel — such as “Is this referencing a specific game?” or “Does the user want co-op?” — returning typed values (booleans, enums) with confidence scores. The developer composed these outputs with lightweight regex helpers to reconstruct the exact same structured intent format their downstream search engine already expected. No changes were needed to indexing, ranking, or result rendering — only the parsing layer was swapped.

Benchmarking across 50 real-world queries showed dramatic improvements: Jev reduced extraction latency from ~1.5s to ~150ms (roughly 10× faster), cut end-to-end route latency nearly in half (from 2871ms to ~1500ms), and lowered per-query cost by about 6× (from $0.014 to ~$0.0023). Crucially, functional correctness held steady: tag extraction accuracy remained at 96–100%, and top-N game recommendations overlapped strongly with the old pipeline. The author notes this isn’t about building chatbots — it’s about embedding machine-native reasoning into application logic, where deterministic, low-latency decisions matter more than fluent sentences.

This case illustrates a broader shift: as structured reasoning models mature, developers are moving beyond prompt-and-parse hacks toward purpose-built inference interfaces. Jev’s design — outputting JSON-serializable, confidence-annotated decisions — aligns tightly with software engineering needs: testability, composability, and observability. For search, moderation, filtering, and decision-heavy UX, such models may soon become the default choice over general-purpose LLMs — not because they’re smarter, but because they’re more appropriate.
