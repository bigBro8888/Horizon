uv 0.12.21 released with OpenSSL update and lockfile refinements

News time: 2026-09-30T06:39:49.803450+00:00 · Source: github

The Rust-based Python package manager uv has rolled out version 0.12.21, a focused maintenance release issued on September 29, 2026. While not introducing major new features, this update delivers important under-the-hood improvements—especially around security, correctness, and lockfile hygiene—that matter to developers relying on uv for fast, deterministic dependency resolution.

One of the most consequential changes is the upgrade of CPython’s bundled OpenSSL to version 3.5.9. This ensures uv’s Python interpreter builds benefit from the latest security patches and cryptographic improvements without requiring users to manually manage OpenSSL dependencies. For teams operating in regulated or high-security environments, such updates reduce exposure to known vulnerabilities—even if they’re not immediately exploitable in typical uv workflows.

The release also refines how uv generates and manages uv.lock files. It now omits empty [manifest] sections when those sections contain only nested subtables—a small but meaningful reduction in lockfile noise. More notably, with the resolution-inputs preview feature enabled, uv now strips redundant runtime constraints—including pre-release version constraints—from the lockfile. This leads to smaller, cleaner lockfiles and avoids spurious conflicts during resolution, especially in projects using alpha/beta packages alongside stable dependencies.

Bug fixes address subtle but impactful edge cases: uv python pin --rm no longer accidentally deletes the global .python-versions file unless explicitly invoked with --global, preventing unintended Python version resets across projects. Another fix corrects how uv validates installed packages against pre-release bounds—previously, post-releases (e.g., 1.0.0.post1) were misclassified as incompatible with exclusive lower bounds like >1.0.0a1, causing false-positive resolution failures. These corrections improve reliability in real-world CI/CD pipelines and developer workflows where version precision matters.

Though incremental, releases like 0.12.21 reflect uv’s maturing philosophy: prioritize correctness, security, and ergonomics over flashy features. As uv gains adoption—particularly among teams migrating from pip+poetry or seeking faster CI times—these steady improvements compound into tangible productivity and stability gains.
