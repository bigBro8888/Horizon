Magnitude launches as self-optimizing inference engine for local AI agents

News time: 2026-10-01T07:09:55.647147+00:00 · Source: hackernews

Magnitude, a new open-source inference engine built by Y Combinator’s S25 cohort, aims to solve a growing pain point in the local LLM ecosystem: running long-running, interactive agent workloads efficiently on consumer hardware. Unlike traditional inference engines optimized for either datacenter-scale batch serving (like vLLM) or broad compatibility (like llama.cpp), Magnitude is designed from the ground up for agents — programs that maintain state across many turns, run concurrently, and must coexist with other desktop applications.

The core innovation lies in its self-optimizing approach. Instead of shipping precompiled kernels tuned for generic hardware, Magnitude performs on-device compilation and autotuning before model execution. Its kernels are parameterized — think configurable loop unrolling, memory layout choices, or tiling strategies — and then benchmarked in real time on the user’s actual CPU or GPU. This bridges the gap between portability and peak performance: it runs everywhere and adapts to your M4 Pro, RTX 4090, or AMD Radeon like a native engine.

Magnitude also introduces several agent-specific systems. Its hybrid paged attention allows concurrent agent sessions to share prefix caches — reducing redundant computation when multiple agents use similar system prompts or tool schemas — while preserving memory locality to avoid degrading single-session latency. Dynamic memory allocation means it only reserves space for model weights upfront; memory grows and shrinks with active agent sessions, freeing resources for other tasks. And unlike most engines, it ships as a desktop app that auto-starts models on demand and shuts them down after inactivity — no manual server management.

Benchmarks show tangible gains: up to 92% faster decode on Apple Silicon (M4 Pro) and 23% faster prefill on NVIDIA DGX Spark versus llama.cpp, using Qwen3.6 35B A3B (4-bit) at 64k context. Memory usage drops by up to 28% per agent. The engine is written entirely in Rust, includes a custom GPU kernel runtime, and draws inspiration from FlashAttention, FlashInfer, and SGLang’s radix attention. Future plans include expert streaming for models larger than GPU VRAM and a full kernel compiler for deeper hardware specialization.
