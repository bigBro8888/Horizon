uv 0.12.22 adds CPython patch support and improves workspace lockfile fidelity

News time: 2026-10-02T06:58:44.799580+00:00 · Source: github

The Python tooling ecosystem just got more robust: uv — Astral’s blazing-fast, Rust-powered package installer and resolver — has released version 0.12.22. Dated October 1, 2026, this patch release quietly delivers high-impact improvements for developers managing complex Python projects, especially those using workspaces (monorepo-style layouts) and strict reproducibility requirements.

At its core, uv aims to replace slower tools like pip and Poetry in critical workflows — installation, dependency resolution, virtual environment management, and lockfile generation. Version 0.12.22 extends official support to five new CPython patch versions: 3.10.22, 3.11.17, 3.12.15, 3.13.16, and 3.14.8. This ensures developers can adopt the latest security and bug-fix updates from the Python core team without waiting for tooling lag.

More significantly, the release tightens lockfile semantics for workspace members. Previously, uv could omit or inconsistently record default dependency groups (e.g., test, dev) and their associated Python version constraints when generating uv.lock files. Now, it reliably records those groups — both for project-root workspace members and non-project roots (like shared utility packages). This means uv sync --frozen will now respect each member’s declared group dependencies and Python requirements, reducing silent mismatches and improving build correctness across large monorepos.

Additional refinements include better handling of wheel platform tags with uppercase release suffixes (e.g., cp312-cp312-win_amd64), a new UV_PYTHON_ARCH environment variable to disambiguate architecture selection (e.g., x86_64 vs aarch64) independently of Python version, and a ~5% reduction in binary size via compressed embedded metadata. The release also cleans up CLI UX — hiding unsupported options like --offline in uv publish help and standardizing URL/path formatting in error messages.

While not a headline-grabbing feature release, 0.12.22 exemplifies uv’s steady maturation: prioritizing correctness, reproducibility, and interoperability over flashy novelty. For teams adopting uv in CI/CD pipelines or enforcing strict lockfile-based deployments, these changes reduce subtle failures and increase confidence in deterministic builds.
