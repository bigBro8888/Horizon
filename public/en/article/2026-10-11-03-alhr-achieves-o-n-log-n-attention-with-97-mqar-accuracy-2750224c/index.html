ALHR achieves O(N log N) attention with 97% MQAR accuracy

News time: 2026-10-11T07:08:28.942960+00:00 · Source: reddit

A new attention mechanism called ALHR—Adaptive Learnable Hierarchical Routing—has emerged as a promising solution to the long-standing scalability problem in transformer models. Unlike standard self-attention, which scales quadratically as O(N²) in both computation and memory, ALHR uses a static binary tree structure to hierarchically route queries and keys. This design reduces the number of key-value pairs actively involved in each attention step, cutting down the computational load to O(N log N) while preserving strong performance on long-context reasoning tasks.

The system was evaluated on the Multi-Query Associative Recall (MQAR) benchmark—a rigorous test for models that must retrieve multiple target values from long sequences amid distractors. ALHR retained 97% of the accuracy achieved by full attention baselines, despite using significantly less memory and VRAM. Crucially, its memory footprint grows much more slowly as sequence length increases, making it viable for contexts thousands of tokens long without exhausting GPU memory.

What sets ALHR apart is its use of learnable routing functions atop a fixed hierarchical topology. Rather than dynamically computing all pairwise attentions, it learns to select only the most relevant subtrees at each level—effectively pruning irrelevant keys before expensive attention scoring. This is not sparse attention in the traditional sense (e.g., local or strided patterns), but a structured, data-aware reduction guided by differentiable parameters trained end-to-end.

While still early-stage research—shared as a Reddit post rather than a peer-reviewed paper—ALHR joins a growing family of efficient attention variants like FlashAttention, Linformer, and Hyena. Its appeal lies in balancing simplicity (no dynamic token merging or complex caching) with measurable gains: no accuracy collapse, clear asymptotic improvement, and compatibility with existing training pipelines. For developers building long-context LLMs or fine-tuning on document-length inputs, ALHR offers a lightweight architectural drop-in that could ease hardware constraints without sacrificing fidelity.
