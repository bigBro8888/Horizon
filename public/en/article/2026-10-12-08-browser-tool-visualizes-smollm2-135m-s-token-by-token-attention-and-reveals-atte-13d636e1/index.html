Browser tool visualizes SmolLM2-135M’s token-by-token attention and reveals attention sink

News time: 2026-10-12T07:18:49.567676+00:00 · Source: reddit

A developer has built a fully client-side web tool that lets anyone watch—step by step—how the compact SmolLM2-135M language model chooses its next word and where it directs attention across prior tokens. Unlike most LLM demos that run on remote servers, this one executes entirely in the browser using ONNX Runtime Web with int8 quantization—no backend, no API calls, and it even works smoothly on smartphones. Users type a prompt, and the tool generates one token at a time, displaying not only the top candidate words and their probabilities but also interactive attention links: lines connecting the current token to earlier ones, labeled with attention weights.

Clicking any word highlights exactly where its attention flows—ranked by strength—and reveals patterns like repeated focus on the beginning of the sequence. During development, the creator initially mistook this behavior for a bug: nearly every token appeared to attend overwhelmingly to the first token (often the BOS or start-of-sequence token). After investigation, they realized it was the well-documented 'attention sink' phenomenon—a known architectural quirk in many transformer models where certain early tokens act as stable anchors, absorbing disproportionate attention mass.

The tool is open source and includes a live demo hosted on GitHub Pages. It leverages SmolLM2-135M, a lightweight 135-million-parameter model designed for on-device use and released by Hugging Face’s TinyBERT team in early 2025. At roughly 85 MB and capable of ~40 tokens per second in WebAssembly mode, it strikes a rare balance between capability and deployability in constrained environments.

What makes this project especially valuable is its pedagogical clarity. By stripping away abstraction layers—no Python, no GPU servers, no black-box APIs—it turns abstract concepts like attention matrices and token prediction into tangible, inspectable interactions. For students, educators, and developers exploring model interpretability, it transforms theoretical knowledge into lived intuition. And because it runs locally, it preserves privacy and enables real-time experimentation without latency or cost.
