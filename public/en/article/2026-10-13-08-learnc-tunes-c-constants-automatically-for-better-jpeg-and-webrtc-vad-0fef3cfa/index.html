learnc tunes C constants automatically for better JPEG and WebRTC VAD

News time: 2026-10-13T07:40:21.142886+00:00 · Source: reddit

A new open-source tool called learnc bridges machine learning and low-level systems programming by automatically optimizing named constants in unmodified, production-grade C code. Unlike neural network weight tuning or compiler auto-vectorization, learnc works entirely at the source level: users write a simple C function that scores performance—say, compression ratio or classification accuracy—and learnc searches for better constant values using gradient-free optimization. The result? A revised version of the same C file, with only numeric literals changed—no restructuring, no rewriting, no new dependencies.

The technique shines where human tuning has long plateaued. In JPEG compression, learnc retuned the 128-entry quantization table in stb_image_write.h using just 12 Kodak images as training data. When tested on the remaining 12 held-out images, the tuned tables achieved a 9.1% BD-rate reduction at equal SSIM quality—a widely accepted metric for perceptual efficiency. For comparison, mozjpeg’s hand-optimized tables delivered only 2.7%. Crucially, this gain was independently verified using libjpeg and scikit-image, confirming real-world interoperability.

In voice activity detection (VAD), learnc improved Google’s WebRTC VAD implementation by tuning every named constant in vad_core.c. Trained on the LibriParty dev set, the optimized version lifted F1 score from 0.810 to 0.859 on the official LibriParty eval set—a +4.9-point absolute gain. That’s not incremental: it matches or exceeds improvements typically seen from major algorithmic overhauls. And because learnc modifies only constants—not logic—it preserves all safety guarantees, timing behavior, and embedded compatibility of the original C code.

learnc is deliberately narrow in scope: it targets tens to hundreds of well-named, semantically meaningful constants—not millions of neural weights. It does not parse expressions or rewrite control flow, nor does it handle constants buried in macros or computed at runtime. Its strength lies in interpretability and integration: engineers can inspect every change, commit it to version control, and reason about its impact. Released under the MIT license, the tool is already being explored for audio codecs, embedded DSP filters, and real-time signal processing pipelines where C remains the lingua franca.
