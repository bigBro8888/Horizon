Janas streams MoE LLMs from SSD to run models larger than RAM

News time: 2026-10-13T07:40:21.012468+00:00 · Source: hackernews

Janas is a new open-source inference engine designed to run large language models—especially mixture-of-experts (MoE) variants—on consumer-grade hardware with limited RAM. Unlike traditional inference tools that load all model weights into memory at once, Janas dynamically streams expert layers from fast NVMe SSD storage during token generation. This approach allows it to execute models like Qwen35B or larger even on machines with only 32GB of system memory, bypassing the usual out-of-memory (OOM) crashes that plague local LLM use.

The tool is written in C, runs CPU-only, and targets Linux systems—no GPU or CUDA dependencies required. Its design centers on sparsity: since MoE models activate only one or two experts per token, Janas loads just those needed for the current computation, discards them after use, and fetches the next batch from SSD. This fine-grained streaming reduces peak memory pressure while maintaining reasonable throughput—users report speeds around 60 tokens per second on modest hardware.

While similar memory-saving techniques exist elsewhere—llama.cpp supports disk offloading, and Strata implements MoE streaming for Qwen3—the Janas project distinguishes itself by focusing exclusively on MoE-specific optimizations and prioritizing simplicity for non-GPU users. It’s licensed under GPL-3.0 and ships as a single-command installer, lowering the barrier for developers who want local, private, and hardware-accessible inference without wrestling with driver resets or GPU memory fragmentation.

Real-world feedback highlights both promise and pitfalls. One user noted that running large models on GPU often triggers display driver crashes due to unreserved VRAM—a problem Janas sidesteps entirely by staying CPU-bound. Others pointed out that while Janas isn’t revolutionary, its narrow scope and pragmatic implementation fill a niche: enabling MoE models on everyday laptops and workstations where GPU memory is scarce or unreliable. As context windows grow and reasoning chains lengthen, such I/O-aware inference strategies are becoming essential—not just for cloud providers, but for privacy-conscious developers running models locally.
