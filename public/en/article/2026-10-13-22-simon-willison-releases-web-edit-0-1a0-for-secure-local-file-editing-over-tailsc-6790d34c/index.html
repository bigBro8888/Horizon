Simon Willison releases web-edit 0.1a0 for secure local file editing over Tailscale

News time: 2026-10-13T07:40:20.491397+00:00 · Source: rss

Simon Willison, a well-known developer and co-creator of Django, has released web-edit 0.1a0 — a minimal, self-hosted Python web application designed to let users browse and edit files on their local machine through a browser interface. The tool was built specifically to solve a real-world friction point: editing sensitive configuration or credential files (like API keys or database passwords) without inadvertently exposing them to large language models during remote development workflows.

The impetus came while Willison was using Codex Remote — ChatGPT’s mobile-to-desktop remote coding feature — to work on a project from his phone. He needed to tweak a credentials file but didn’t want those secrets routed through an LLM-powered assistant, even locally. Rather than copy-paste or use clunky SSH-based editors, he prompted GPT-6 Astra Extra High (an advanced OpenAI model) alongside Codex to generate a lightweight, secure alternative — resulting in web-edit.

The app runs as a simple Python server, serves a clean web UI over HTTPS (when used with Tailscale), and supports file browsing, uploading, downloading, deletion, and inline editing of text files using CodeMirror 6 — chosen for its strong mobile responsiveness, unlike Monaco which still lags on touch devices. The interface is intentionally sparse: a file table with name, size, and modification time; upload controls; and a live editor pane. No authentication layer is included yet — it relies entirely on Tailscale’s built-in zero-trust network access control, meaning only authorized devices on your private Tailscale network can reach the service.

This isn’t another cloud-based IDE or online Python playground. Unlike services like Online Python or OnlineIDE — which run code remotely and may log or process inputs — web-edit never leaves your machine. It doesn’t execute code, doesn’t connect to external APIs beyond serving static assets, and avoids all telemetry. Its security model is ‘local-first’: files stay on disk, edits happen locally, and network exposure is strictly limited to your encrypted, identity-aware Tailscale tunnel. For developers juggling sensitive infrastructure or working across devices, it fills a quiet but critical gap between convenience and confidentiality.
