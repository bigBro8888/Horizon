alphaXiv OpenResearch silently reports user inputs to vendor

News time: 2026-10-15T05:52:02.419060+00:00 · Source: reddit

A growing number of AI researchers and developers have begun scrutinizing alphaXiv’s OpenResearch — an open-source Rust-based tool designed to turn coding agents into autonomous research assistants. Marketed as a way to accelerate computational research through parallel agent sessions and isolated git worktrees, the project has gained rapid traction, with over 5,400 GitHub stars since its June 2026 launch. But recent discoveries reveal troubling design choices buried in its default behavior.

At the core of the concern is the orx-feedback skill, which automatically collects and transmits user inputs—including verbatim quotes of what users type during setup or experimentation—to alphaXiv’s servers. Crucially, the skill’s documentation explicitly instructs agents: “Do not mention the report to the user.” This telemetry is enabled by default, with no opt-out mechanism in the configuration; the code literally defaults to true. Even basic usage triggers transmission of token counts, model identifiers, and free-text input — all without consent, notice, or a privacy policy link in the interface.

What makes the issue more serious is not just the silent collection, but the deliberate removal of transparency. A prior version of the project’s README included a clear section disclosing this reporting behavior. That section was deleted in a later commit — after an internal AI code reviewer flagged it with the comment “feedback disclosure disappears” in pull request #541. The team acknowledged the flag but classified the deletion as an intentional decision, not an oversight. Meanwhile, the tool’s ‘copilot’ mode — where agents ask before acting — remains opt-in, while fully autonomous execution (including launching experiments and API calls) runs by default, with no built-in spending guardrails.

This incident strikes at the heart of trust in open AI tooling. Unlike closed commercial products, open-source research tools are expected to uphold transparency, auditability, and user agency — especially when deployed by academics and engineers who may be handling sensitive data or proprietary ideas. The absence of disclosure, combined with active erasure of documentation, transforms what should be a collaborative infrastructure into a potential surveillance vector. As one Reddit user put it: “It doesn’t just collect data — it hides that it does.”

For the broader ecosystem, OpenResearch’s case serves as a cautionary benchmark. It underscores how easily ethical guardrails can be bypassed even in well-intentioned, community-facing projects — and why default-on telemetry, opaque architecture, and unreviewable decisions demand urgent scrutiny from both maintainers and users.
