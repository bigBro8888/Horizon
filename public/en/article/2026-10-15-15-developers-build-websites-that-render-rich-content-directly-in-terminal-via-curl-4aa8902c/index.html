Developers build websites that render rich content directly in terminal via curl

News time: 2026-10-15T05:52:01.997660+00:00 · Source: hackernews

A growing collection of experimental websites—dubbed 'fancy curl sites'—shows how web servers can deliver rich, interactive terminal-native experiences using nothing more than standard HTTP and curl. These sites don’t rely on JavaScript or browsers: instead, they serve ANSI escape sequences and leverage the terminal’s alternate screen buffer to display formatted text, colors, status updates, weather forecasts, music logs, and even personal portfolios—all from a single curl command.

The trick lies in two well-established but underused terminal features. First, the alternate screen buffer (activated with the ANSI sequence \x1b[?1049h) gives developers a clean, isolated canvas—like opening a new window—so content doesn’t scroll into or overwrite the user’s command history. When the request ends, the site sends \x1b[?1049l to restore the original terminal state, leaving the scrollback untouched. Second, ANSI escape codes handle styling: colors, cursor positioning, bold/underline text, and even rudimentary layout control—enabling surprisingly expressive interfaces without any client-side logic.

Examples include cole.ws, a personal portfolio that renders as a full-screen terminal app; wthr.dev, a lightweight weather service accepting location paths like /Washington,DC; and listening.cailinpitt.com, which displays recent Spotify activity. All are statically served—no backend rendering—and many detect curl usage by inspecting headers like User-Agent, though some (like cole.ws) avoid UA sniffing entirely by embedding HTML inside the alternate buffer comments and appending ANSI-rendered content afterward.

This isn’t just nostalgia—it’s a deliberate rethinking of the CLI as a first-class interface for web content. Unlike traditional text-based web clients (e.g., Lynx), these sites assume modern terminal emulators (iTerm2, Windows Terminal, Kitty, Alacritty) and use their full capabilities. As one commenter notes, it even works on Windows—if you run curl from Windows Terminal instead of PowerShell mode. The movement reflects broader interest in minimal, resilient, and toolchain-native web patterns—especially among developers who spend most of their day inside terminals.
