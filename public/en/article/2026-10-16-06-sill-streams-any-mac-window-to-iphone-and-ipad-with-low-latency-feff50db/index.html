Sill streams any Mac window to iPhone and iPad with low latency

News time: 2026-10-16T05:48:26.194752+00:00 · Source: hackernews

Sill is a new open-source macOS application that lets users stream any individual window—or their entire desktop—live to an iPhone or iPad over USB or local Wi-Fi. Unlike traditional remote desktop tools, Sill is built for speed and simplicity: it achieves noticeably lower latency than VNC-based solutions, making interactions like typing, scrolling, and tapping feel responsive rather than sluggish. The app appears as a small menu bar icon on macOS; with one click, users can select a window to mirror, adjust text size for readability on smaller screens, and begin streaming instantly—no complex setup or account required.

What sets Sill apart is its focus on practical, everyday friction points. Many users report frustration with iOS keyboard lag, especially when entering longer text on older iPhones. Others own legacy devices—like the original iPhone—that are too slow for modern apps but still physically elegant and functional as thin clients. Sill effectively breathes new life into such hardware by turning them into lightweight, real-time display terminals for Mac workflows.

The tool also sparks creative rethinking of device roles. While Apple’s Sidecar already enables iPad-as-second-screen functionality—including Apple Pencil support—it doesn’t extend to iPhone, nor does it allow arbitrary window selection with one-tap switching. Sill fills that gap cleanly. Community interest has quickly expanded beyond basic mirroring: developers are asking about reverse streaming (iOS to Mac), Windows compatibility, and even hardware integration like stylus input handling. These discussions reflect how Sill isn’t just a utility—it’s a catalyst for reimagining cross-device interaction in the Apple ecosystem.

Importantly, Sill is free, notarized by Apple for security, and installable via Homebrew or direct download from getsill.app. Its GitHub repository shows active development and clear documentation, making it accessible to both casual users and developers who want to extend or audit the code. As remote collaboration and hybrid workflows grow more common, tools like Sill demonstrate how lightweight, focused open-source software can solve real usability problems better than bloated commercial alternatives.
