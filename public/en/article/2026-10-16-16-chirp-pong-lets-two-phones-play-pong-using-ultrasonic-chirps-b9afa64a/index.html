Chirp Pong lets two phones play Pong using ultrasonic chirps

News time: 2026-10-16T05:48:25.846587+00:00 · Source: rss

Chirp Pong is a playful yet technically precise experiment in peer-to-peer web gaming—no Wi-Fi, no Bluetooth, no server required. Two players simply open the same static HTML page on their smartphones, hold the devices near each other, and start playing a reimagined version of Pong. Instead of syncing over the internet, the game transmits paddle positions, ball velocity, and score updates via brief, inaudible ultrasonic chirps emitted by one phone’s speaker and captured by the other’s microphone. The entire system runs client-side using the Web Audio API, with real-time audio analysis happening entirely in the browser.

The design goes beyond basic Pong: it features dynamic ball physics that respond to where the paddle is struck, visual feedback pulses synced to chirps, and subtle asymmetries between players—like one side having slightly faster acceleration—to encourage physical positioning and attentive listening. These twists make the audio channel not just a transport layer but an integral part of gameplay and interaction design.

What makes Chirp Pong especially notable is how it bridges creative coding, accessibility, and AI-assisted development. Developer Simon Willison used Claude Code (Claude Opus 5.5 Extra) to generate and iterate on the core audio synchronization logic—demonstrating how modern LLMs can accelerate low-level signal processing prototyping for web developers without deep DSP expertise. The result is a fully offline, zero-install, cross-platform experience that works on any modern smartphone with a microphone and speaker.

While not intended as production software, Chirp Pong serves as both an educational artifact and a provocation: it shows how everyday hardware—microphones and speakers—can become networking interfaces when paired with thoughtful API use. In an era of increasing connectivity dependence, it reminds us that local, physical, and even audible layers of interaction remain richly underexplored in web applications.
