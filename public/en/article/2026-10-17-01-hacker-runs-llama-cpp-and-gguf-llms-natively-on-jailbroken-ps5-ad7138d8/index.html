Hacker runs llama.cpp and GGUF LLMs natively on jailbroken PS5

News time: 2026-10-17T05:33:27.819340+00:00 · Source: hackernews

A developer known as cobanov has achieved a remarkable systems engineering feat: porting llama.cpp — the widely used C/C++ library for local LLM inference — to run natively on a jailbroken PlayStation 5. The project, hosted publicly on GitHub under the name PS5LM, enables the console to load and execute GGUF-quantized language models without emulation or virtualization. This isn’t just a proof-of-concept; it’s functional, low-level code that leverages the PS5’s custom AMD Zen 2 CPU and RDNA 2 GPU architecture through carefully adapted memory management, thread scheduling, and kernel-level hooks.

The PS5 was never designed as a general-purpose computer — its firmware is tightly locked down, its OS is proprietary, and its hardware abstraction layer is intentionally opaque. Yet by exploiting known jailbreak vulnerabilities (including kernel-level privilege escalation), cobanov bypassed Sony’s security model to install a minimal Linux userspace and compile llama.cpp against it. Crucially, the implementation relies on GGUF, the binary model format co-developed with GGML, which supports efficient tensor loading, metadata embedding, and fine-grained quantization — enabling even large models like Qwen 3.8B to run at 2-bit precision on the console’s 16 GB of unified GDDR6 RAM.

While raw throughput doesn’t rival modern AI workstations, the PS5’s sustained power efficiency (~70 cents per day in electricity) and always-on readiness make it unexpectedly viable for long-running edge-AI tasks. Commenters highlight use cases like real-time server log analysis, autonomous plant monitoring with camera feeds, or lightweight security video summarization — applications where consistent, low-cost token generation matters more than peak speed or human-level reasoning. One user even speculates about integrating LLM-powered NPCs directly into PS5 games, building on early experiments like PUBG Ally on PC.

Beyond novelty, this effort signals a broader shift: consumer gaming hardware is increasingly capable of repurposing as accessible, silent, and energy-efficient AI infrastructure. It also raises practical questions about sustainability — such as whether Sony may issue takedown notices — and technical ones about cross-platform compatibility, with speculation that BC250 mining cards (built on the same ‘Cyan Skillfish’ APU as the PS5) could run identical binaries. Ultimately, PS5LM isn’t just about running chatbots on a game console — it’s a demonstration of how deeply constrained platforms can be reclaimed for open, general-purpose computation.
