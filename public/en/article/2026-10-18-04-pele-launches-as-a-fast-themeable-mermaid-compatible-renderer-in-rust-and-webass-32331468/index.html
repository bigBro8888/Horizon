Pele launches as a fast themeable Mermaid-compatible renderer in Rust and WebAssembly

News time: 2026-10-18T05:50:46.692688+00:00 · Source: hackernews

Pele is a new open-source diagram renderer that aims to solve long-standing pain points in the Mermaid ecosystem—particularly inconsistent layout behavior and limited theming control. Unlike Mermaid.js, which relies on browser-based rendering (often requiring full or headless browsers for server-side use), Pele compiles Rust code to WebAssembly and runs entirely client-side without DOM dependencies. This makes it faster, more predictable, and embeddable in environments where JavaScript-heavy libraries or browser contexts are unavailable—such as static site generators, CLI tools, or Obsidian plugins.

One of its standout features is correct subgraph directionality: flowchart subgraphs retain their internal orientation even when connected to external nodes—a subtle but critical fix that developers have struggled with in Mermaid.js for years. Users report topological layout failures in complex diagrams, where arrows cross unnecessarily or nodes cluster illogically; Pele’s deterministic layout engine avoids many of these issues by design. It also supports full CSS-in-JS–style theming, letting users define colors, fonts, spacing, and stroke styles via structured configuration—not just global CSS overrides.

Built by the Obsidian team and hosted on GitHub, Pele is already being adopted in documentation pipelines and note-taking workflows. Its WASM-first architecture means no runtime browser dependency, enabling consistent rendering across platforms—from CI environments to mobile WebView contexts. While still early in development, it ships with support for core Mermaid syntax including flowcharts, sequence diagrams, and class diagrams, and parses input identically to Mermaid.js—ensuring drop-in compatibility for most existing .mmd files.

The Hacker News discussion reflects genuine developer enthusiasm—not just hype. Commenters highlight specific frustrations they’ve had with Mermaid.js (e.g., broken layouts at scale, opaque styling APIs) and praise Pele’s pragmatic focus on correctness over feature bloat. Several users noted how rare it is to see a new diagramming tool gain traction so quickly, especially one that prioritizes interoperability and composability rather than reinventing syntax.
