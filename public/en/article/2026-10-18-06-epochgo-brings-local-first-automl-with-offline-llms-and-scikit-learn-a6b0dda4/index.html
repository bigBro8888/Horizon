EpochGo brings local-first AutoML with offline LLMs and scikit-learn

News time: 2026-10-18T05:50:47.027220+00:00 · Source: reddit

EpochGo is a new open-source AutoML system designed for privacy-conscious, cost-sensitive, and resource-constrained environments. Unlike cloud-dependent AutoML tools that send sensitive tabular data to remote APIs, EpochGo runs entirely on the user’s machine — no internet connection required after setup. Its core innovation lies in a strict architectural separation: an offline Ollama-hosted LLM handles high-level reasoning about data structure and modeling strategy, while all actual computation — feature engineering, hyperparameter tuning, and model training — is delegated to deterministic, battle-tested scikit-learn pipelines.

The system uses qwen2.5-coder:7b, a lightweight code-specialized LLM served locally via Ollama, to inspect metadata like column types, missingness, and cardinality. Crucially, the LLM never sees raw data rows — only schema summaries — reducing hallucination risks in numerical tasks like gradient descent or hyperparameter search. Once the LLM proposes a pipeline (e.g., StandardScaler → OneHotEncoder → XGBoost), EpochGo parses the generated Python code into an Abstract Syntax Tree (AST) to verify safety: no system calls, no file I/O outside sandbox, no arbitrary imports. Only validated, syntactically sound code proceeds to execution.

All model evaluation happens via isolated K-Fold cross-validation within scikit-learn’s native Pipeline objects — ensuring reproducibility, version stability, and full compatibility with existing ML workflows. When a winning pipeline emerges, EpochGo auto-generates a containerized FastAPI endpoint, ready for immediate deployment. The entire stack runs on consumer hardware (16GB RAM minimum) across macOS, Linux, and Windows — with zero recurring cloud costs or compliance exposure under GDPR or India’s DPDP Act.

By decoupling strategic reasoning from numerical execution, EpochGo sidesteps two persistent industry pain points: the financial and legal risks of cloud-based inference, and the unreliability of LLMs when generating low-level numeric logic. It’s not just another wrapper — it’s a principled rethinking of how agentic AI should interface with classical ML infrastructure. For data scientists working with sensitive enterprise or healthcare datasets, EpochGo offers a rare combination: autonomy, auditability, and simplicity — all without sacrificing rigor.
