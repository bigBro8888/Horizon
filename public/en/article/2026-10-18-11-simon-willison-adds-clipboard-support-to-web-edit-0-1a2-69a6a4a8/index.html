Simon Willison adds clipboard support to web-edit 0.1a2

News time: 2026-10-18T05:50:46.328994+00:00 · Source: rss

Simon Willison has released version 0.1a2 of web-edit, his minimal, self-hosted web-based file editor designed for lightweight remote development workflows. The tool lets users browse and edit files in a local directory through a browser — no installation or backend server required beyond Python’s built-in HTTP server. Willison built it specifically to simplify editing files across machines connected via Tailscale, a secure mesh networking tool that makes remote devices feel like they’re on the same local network.

This update introduces a practical but meaningful enhancement: copy-to-clipboard functionality for both plain text and image data. Previously, copying logs or generated SVGs — such as those from AI prompts — required manual selection and keyboard shortcuts, which is cumbersome on mobile or when working across devices. Now, users can click a dedicated button to copy content directly, eliminating friction in iterative remote tasks.

The motivation came from a real-world use case: Willison was running Pelican — an experimental prompt benchmark involving generating SVGs of a pelican riding a bicycle — on a laptop while controlling it from his phone. He used DeepSeek V4.1 Flash 1017 (a fast, low-cost, open-weight LLM released October 17, 2026) to generate outputs, then needed to quickly capture and share logs or rendered SVGs in GitHub Gists. With web-edit’s new clipboard feature, he could copy results in one click and paste them straight into a gist — no terminal commands, no file downloads, no context switching.

While web-edit remains intentionally minimal — it lacks syntax highlighting, multi-file tabs, or collaborative editing — its strength lies in its narrow focus and zero-dependency design. It runs with python -m http.server and serves static HTML/JS that talks directly to the filesystem via browser APIs (with user permission). This makes it ideal for developers who value simplicity over features, especially in constrained or ad-hoc environments like headless servers, IoT devices, or air-gapped test setups. As remote and edge development grows more common, tools like web-edit fill a quiet but important niche: not replacing VS Code, but complementing it where full IDEs won’t fit.
