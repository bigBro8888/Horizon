SteerTTS enables real-time, CPU-friendly English speech with 12 z-scored prosody controls

News time: 2026-10-19T06:08:52.621240+00:00 · Source: reddit

SteerTTS is a newly released open-source text-to-speech system designed for precision, efficiency, and developer control. Unlike most modern TTS models that prioritize raw quality over interpretability or runtime flexibility, SteerTTS explicitly centers on steerability: users can adjust pitch, speaking rate, loudness, pause duration, spectral tilt, and other prosodic features using intuitive, standardized z-scores — each relative to the target voice’s neutral baseline. This means a value of +1.0 for ‘pitch’ raises median fundamental frequency by one standard deviation above that speaker’s typical level — a mathematically grounded, voice-specific, and composable interface.

The model architecture combines a compact 9.6M-parameter acoustic predictor built on bidirectional Mamba-3 layers (a state-space sequence model known for speed and memory efficiency) with the lightweight Vocos neural vocoder. Together they total just 23 million parameters — dramatically smaller than mainstream TTS systems like VITS or Coqui TTS, which often exceed 100M. It runs in real time on consumer CPUs: first audio streams in ~500 ms, and sustained inference achieves 4–8× real-time speed without GPU acceleration. Optional flow-based refinement improves fidelity but is disabled by default for latency-critical use.

Beyond numeric controls, SteerTTS supports rich input formats: inline SSML-like markup (e.g., <slow>, [pause 300ms]), 51 predefined style tags (e.g., "news_anchor", "podcast_host"), and free-text prompts parsed into structured JSON requests. It also includes experimental zero-shot voice cloning — though the authors candidly note its current output lacks convincing speaker similarity. Evaluation shows strong objective performance: ~1.8% word error rate on Open TTS English benchmarks, measured locally. However, not all controls behave equally well — pause timing, voicing, and CPPS (cepstral peak prominence) adjustments remain unreliable, and emotion tags act more as coarse style switches than fine-grained affect modulators.

What makes SteerTTS especially notable is its design philosophy: it bridges LLM-driven conversational agents and low-latency speech synthesis. By exposing prosody as explicit, inspectable numerical inputs — rather than opaque embeddings or black-box prompts — it allows LLMs to dynamically generate context-aware speech instructions during dialogue. For developers building voice interfaces, chatbots, or accessibility tools, this represents a rare combination of transparency, deployability, and composability — all under a permissive MIT license for code and CC BY-NC for weights.
