Free Pascal adds dynamic package support after 20 years

News time: 2026-10-19T06:08:52.422543+00:00 · Source: hackernews

The Free Pascal Compiler (FPC) and Lazarus IDE have officially gained full support for dynamic packages — a milestone announced by developer sysrpl and confirmed across multiple community channels. This capability allows developers to load components, controls, and IDE extensions at runtime without rebuilding the entire Lazarus environment. For decades, extending Lazarus meant recompiling the whole IDE — a time-consuming process that discouraged rapid iteration and third-party plugin development. Now, packages can be compiled as shared libraries (.so, .dll, .dylib) and installed or swapped on-the-fly, dramatically accelerating workflow for both tool builders and end users.

Dynamic packages are not just about convenience: they enable true plugin architectures in Pascal-based applications. As noted in the Free Pascal wiki, such packages allow transparent runtime linking — meaning code can call into loaded units as if they were statically linked, while still permitting independent updates and versioning. This brings FPC much closer to modern IDE extensibility models seen in VS Code or JetBrains tools, where extensions ship separately and integrate seamlessly.

The implementation spans all major platforms — Windows, Linux, and macOS — and is built directly into the official FPC trunk and Lazarus trunk versions. However, it comes with practical constraints: unit names must be globally unique across packages, cannot match their containing package name, and packages must be explicitly registered before use. These guardrails prevent symbol collisions but require careful naming discipline from developers.

Beyond technical impact, the release sparks reflection on the broader Pascal ecosystem. Community voices highlight persistent challenges — from accessibility gaps in the LCL GUI toolkit (noted by ethin, who relies on screen readers), to AI coding assistants’ consistent failure to generate valid Pascal syntax (Perenti’s observation). Others raise concerns about fragmentation, questioning whether this announcement originates from the official Lazarus project or a fork — a confusion amplified by conflicting domain references (getlazarus.org vs lazarus-ide.org). Still, the consensus is clear: dynamic packages represent the most consequential FPC advancement in years — one that revitalizes modularity, lowers the barrier to IDE contribution, and reaffirms Pascal’s viability for robust, maintainable desktop software.
