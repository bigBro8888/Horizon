Anthropic donates Agent Skills standard to Agentic AI Foundation

News time: 2026-10-23T06:00:37.306366+00:00 · Source: rss

In a significant move toward open infrastructure for agentic AI, Anthropic has officially donated the Agent Skills open standard to the Agentic AI Foundation (AAIF), hosted under the Linux Foundation. This follows the foundation’s establishment in 2025 by Anthropic, Block, and OpenAI — and its prior adoption of the Model Context Protocol (MCP) as its first major specification. The donation formalizes Agent Skills as a vendor-neutral, community-governed standard, reinforcing a shared commitment to interoperability across AI agents.

Agent Skills is a lightweight, file-based format that lets developers extend AI agents with specialized capabilities — from querying databases to running code or orchestrating multi-step workflows. At its core, a skill is a folder containing a SKILL.md file: a Markdown document with YAML frontmatter (requiring name and description) followed by human-readable instructions the agent uses at runtime. Because it’s portable and tool-agnostic, skills can be shared, installed, and composed across different agent platforms — much like plugins for traditional software.

The AAIF’s stewardship means technical evolution will now happen through open working groups, public RFCs, and transparent governance — not behind closed doors at any single company. This mirrors how MCP succeeded: after Anthropic open-sourced it last year, dozens of tools — including Firecrawl, Datasette, and various IDE integrations — adopted it rapidly. Agent Skills is already seeing similar early traction, with OpenCode and other frameworks implementing native support.

What makes this especially notable is timing and precedent. Anthropic first announced Agent Skills as an ‘open standard’ in December 2025 — and Simon Willison, a respected independent technologist, correctly predicted it would land in the AAIF just weeks later. His prediction was even verified using Claude itself, via the datasette-mcp plugin, which indexes his blog using MCP. That meta-layer of self-referential tooling underscores how deeply these standards are already embedded in real-world developer workflows.

This isn’t just about one spec. It’s about building a durable, collaborative stack for agentic AI — where data access (MCP), capability packaging (Agent Skills), and future layers like agent-to-agent communication can evolve together, without lock-in. For developers, it means less reinvention; for enterprises, more portability; and for the ecosystem, a stronger foundation to scale beyond chatbots into autonomous, task-executing systems.
