High school student built 100k-line OpenGL game engine from scratch

News time: 2026-10-23T06:00:37.664782+00:00 · Source: hackernews

Hedra is not just another hobby game — it’s a full-featured, cross-platform 3D open-world engine and game written entirely by Max Levi while he was still in high school. Released publicly on GitHub under the pre-AI branch, the project spans roughly 100,000 lines of C++ code and implements core systems like skeletal animation, dynamic terrain generation, deferred rendering, and a custom modding API — all built without external game engines or AI assistance. The engine uses OpenGL (via GLEW) for graphics, SDL2 for window and input handling, and avoids high-level abstractions, favoring hand-rolled systems for physics, entity management, and rendering pipelines.

What makes Hedra especially striking today is its timing and context. Created around 2015–2016, it predates the mainstream adoption of large language models in software development by nearly a decade. In an era where AI tools routinely generate boilerplate, scaffold projects, or even entire modules, Hedra stands as a tactile artifact of deep systems programming — one where every line reflects deliberate design decisions, debugging sessions, and iterative learning. Its architecture mirrors patterns seen in professional-grade educational engines like GlistEngine or aemeny’s Custom OpenGL GameEngine-MARK: modular, low-level, and prioritizing understanding over convenience.

The project also reveals how much craft is embedded in seemingly simple choices — like building a robust mod API from day one. As commenter chrysoprace noted, this wasn’t an afterthought but a foundational philosophy: games should be platforms, not monoliths. That mindset enabled community extensions long before modding became standard practice in indie titles. Meanwhile, panza’s observation about shifting linguistic meaning — how “wrote from scratch” now carries layered connotations about tooling, authorship, and intent — adds a quiet meta-layer to the project’s relevance.

Hedra isn’t being pitched as production-ready or commercially competitive. It’s shared as both a technical milestone and a reflective gesture — a reminder that mastery begins with constraint, patience, and the willingness to write code no one else will see. For students and professionals alike, it’s a rare glimpse into what ‘building from the ground up’ truly meant before AI changed the grammar of software creation.
