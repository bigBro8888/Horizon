Researcher jailbreaks iPhone using iMessage and PDF zero-days

News time: 2026-10-24T05:46:59.598580+00:00 · Source: hackernews

Today, a security researcher at Calif published a technical blog post titled 'Today, we hacked what we'd set out to hack: the iPhone'—documenting a full-chain, zero-click jailbreak against modern iOS devices. The exploit chain leverages two previously unknown vulnerabilities: one in Apple’s iMessage processing subsystem and another in CoreGraphics, the framework responsible for rendering PDFs and other 2D content across iOS and macOS. Critically, the attack requires no user interaction—no tap, no preview, no contact relationship—making it functionally identical to high-profile zero-click exploits like ForcedEntry used by Pegasus.

The chain begins with a maliciously crafted PDF sent via iMessage. When the device processes the attachment—even before the user opens it—the CoreGraphics flaw triggers memory corruption, enabling arbitrary code execution inside the sandboxed iMessage process. From there, the exploit escalates privileges by compromising a kernel extension or driver interface, ultimately achieving persistent root access and disabling key iOS security mechanisms including ASLR, PAC, and pointer authentication. Video demos show the compromised device running unsigned binaries, modifying system files, and bypassing Lockdown Mode protections.

This isn’t just another jailbreak tool for enthusiasts. It reflects a sophisticated, real-world exploitation methodology that mirrors those used by state-sponsored actors. The researcher’s team—known for prior work on zero-click attack surfaces in messaging apps—reverse-engineered the vulnerability from binary diffs between iOS 26.7 and 26.7.1, suggesting Apple had already patched it silently in the latter version. That implies the exploit was actively used or weaponized before patching.

The broader implications extend beyond jailbreaking. It exposes limitations in BlastDoor—the sandboxed iMessage parser Apple introduced in iOS 14 to isolate untrusted message payloads—and raises urgent questions about CoreGraphics’ attack surface, which remains deeply embedded in iOS graphics, printing, and document handling. With over 530 community comments, the post has ignited deep technical discussion around persistence, kernel integrity, and whether Lockdown Mode meaningfully mitigates such advanced vectors. For defenders, it underscores that even hardened, layered defenses can be undone by a single, well-placed zero-day in foundational frameworks.
