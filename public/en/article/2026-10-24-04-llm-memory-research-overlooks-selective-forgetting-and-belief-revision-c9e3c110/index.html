LLM memory research overlooks selective forgetting and belief revision

News time: 2026-10-24T05:46:59.825957+00:00 · Source: reddit

Long-context language models now ingest millions of tokens — yet a growing critique warns that scaling memory capacity alone misses the deeper challenge: how LLMs update knowledge when facts change. Consider a coding assistant that reads an API timeout of 30 seconds in documentation, then later sees it updated to 5 seconds. Both values remain in context, but the model often fails to revise its behavior — not because it forgot the old value, but because it lacks mechanisms to selectively overwrite or de-prioritize outdated beliefs. This isn’t a recall failure; it’s a belief revision failure.

Traditional architectures compound the issue. Standard Transformers and RAG systems treat memory as static storage: new information is appended or retrieved alongside old, leaving conflict resolution entirely to attention-weighted inference — a brittle, unprincipled process. Linear attention variants like DeltaNet attempt a fix by applying the delta rule: instead of overwriting memory states, they adjust them incrementally based on prediction error — making updates targeted and efficient (O(N) training, constant memory). Meanwhile, BDH (Dragon Hatchling) draws from neuroscience, using Hebbian-style synaptic plasticity to let connections strengthen or weaken dynamically during inference, aiming for biologically plausible memory updating.

But both approaches face unresolved questions. When should a model update a memory? How does it avoid catastrophic interference — changing one belief while corrupting unrelated ones? And crucially, how do we even test this? Most long-context benchmarks only ask whether a model can retrieve a fact — not whether it changes its answer upon seeing newer, contradictory evidence while still retaining the original fact. That gap points to a fundamental misalignment between current evaluation practices and real-world agent reliability.

The post raises a foundational question: Is the core problem architectural (how memory is stored and updated), or cognitive (how models reason over contradictions)? It suggests neither is sufficient alone — robust agents need both dynamic memory and explicit reasoning scaffolds for epistemic uncertainty. As LLMs evolve into long-lived, autonomous agents, solving belief revision won’t be optional. It will define whether they act as reliable collaborators — or persistent sources of outdated advice.
