Simon Willison builds oil painting simulator using Claude-generated Canvas code

News time: 2026-10-24T05:46:59.324644+00:00 · Source: rss

Simon Willison has released Quick Study — a minimalist, self-contained web tool that transforms uploaded photographs into simulated oil paintings directly in the browser. Unlike typical AI image generators that rely on server-side models or heavy client-side libraries, Quick Study runs entirely on the frontend using only vanilla HTML, CSS, and JavaScript. It loads an image, applies Sobel edge detection to identify contours and texture boundaries, then renders layered brushstroke-like strokes over the original pixels — all within a single <canvas> element.

The tool’s core innovation lies not in novel computer vision research, but in its clever orchestration of well-understood techniques via large language model (LLM) assistance. Willison prompted Claude Opus 5.5 with a concise, task-oriented instruction: “Build an artifact where you open a photo and it rapidly (in a few seconds) paints a version of that photo using a canvas element and simulated paintbrush.” The resulting code — generated in one go, without external dependencies — implements real-time pixel manipulation, gradient magnitude estimation, and directional stroke simulation using only native browser APIs.

This follows Willison’s earlier experiment with Pelican Watercolor, where he used Claude Fable to generate a P5.js sketch mimicking watercolor diffusion. But Quick Study takes minimalism further: no frameworks, no bundlers, no npm packages — just Google Fonts for typography and raw Canvas 2D rendering. The heron image shown in the demo illustrates how effectively the algorithm preserves structural detail while introducing painterly texture, especially along high-contrast edges detected by the Sobel operator.

What makes Quick Study compelling is its demonstration of LLMs as precision tooling collaborators rather than black-box content engines. It highlights how prompt engineering — paired with domain awareness — can yield compact, performant, and pedagogically transparent code. For web developers and creative coders, it’s both a practical utility and a case study in leveraging AI not to replace coding, but to accelerate the implementation of specific, well-scoped visual effects.
