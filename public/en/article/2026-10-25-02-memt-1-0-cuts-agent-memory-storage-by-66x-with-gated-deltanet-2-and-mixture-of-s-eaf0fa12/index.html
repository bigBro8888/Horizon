memt-1.0 cuts agent memory storage by 66x with gated DeltaNet-2 and mixture-of-storage

News time: 2026-10-25T06:02:50.692002+00:00 · Source: reddit

memt-1.0 is not just another LLM optimization—it’s a rethinking of how language models remember. Instead of treating memory as an external add-on—like retrieval-augmented generation (RAG) or ever-growing key-value (KV) caches—memt-1.0 embeds memory directly into the model’s computation. At its core lies gated DeltaNet-2, a second-generation linear attention architecture that decouples memory erasure and writing via separate gates, enabling stable, token-level updates to internal state during each interaction. This eliminates the need to reprocess full historical context on every turn. Complementing this is the mixture-of-storage (MoS) layer: a parametric, capacity-scalable mechanism that replaces brute-force KV persistence with selective, compressed memory retention—akin to how humans prioritize procedural knowledge over raw logs.

The payoff is dramatic at scale. At 128k context length—a common target for long-horizon agentic workflows—memt-1.0-nano achieves a 1.86× end-to-end inference speedup and slashes persistent storage requirements by 66× compared to standard full-KV caching. Crucially, this isn’t achieved by sacrificing general capability: through a two-stage training regimen (continued pre-training + post-training across 34 billion tokens), memt-1.0 preserves strong reasoning performance while outperforming prior parametric memory baselines. That balance—efficiency without degradation—is rare in memory-augmented LLMs.

What makes memt-1.0 especially notable is its departure from architectural band-aids. Most current agents rely on stitching together LLMs, vector databases, and prompt engineering—a fragile, latency-prone stack. memt-1.0 instead treats memory as first-class compute: updated dynamically, stored parametrically, and optimized jointly with language modeling. Its gated DeltaNet-2 block ensures memory remains stable across turns, while MoS allows memory capacity to scale independently of context window size—no more quadratic KV growth.

For developers building autonomous agents, this signals a potential inflection point: moving from external memory scaffolding toward internalized, trainable memory layers. If widely adopted, architectures like memt-1.0 could simplify agent infrastructure, reduce cloud storage costs, and enable real-time adaptation in resource-constrained environments—from edge devices to multi-step enterprise workflows.
