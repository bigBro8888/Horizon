Researcher hosts $502 Bitcoin prize on deliberately vulnerable PHP server

News time: 2026-10-25T06:02:51.045260+00:00 · Source: hackernews

A security researcher has launched a live, publicly accessible experiment titled 'Steal My Bitcoin' — a deliberately vulnerable PHP web server hosting a real $502 Bitcoin wallet key. The goal is not to invite malicious exploitation, but to empirically test whether the recently disclosed PHP2SHELL remote code execution (RCE) vulnerabilities are already being weaponized in the wild. Unlike typical bug bounty programs or theoretical PoCs, this setup runs a real, constrained PHP environment — with memory limits, CLI-only execution, and no external network access — designed to be just exploitable if an attacker has a working, reliable PHP2SHELL exploit.

The server was configured using a pre-patch version of PHP known to be affected by the PHP2SHELL flaws (CVE-2026-109618 and CVE-2026-109619), which stem from memory-safety failures during fatal error handling — especially out-of-memory conditions. Crucially, the researcher did not expose a generic web shell; instead, the flag (the private key) is only retrievable via a custom print-flag binary executable by the PHP user. This forces attackers to achieve full RCE and correctly pivot to local file access — a higher bar than many automated scanners clear.

Within hours, the experiment sparked intense technical debate across Hacker News and Twitter. Some participants reported server overload due to traffic spikes, while others — including AI-assisted teams — began systematic attempts. Notably, respected security researcher Dan Guido declined to attempt exploitation, citing responsible disclosure ethics: he confirmed possessing a working RCE but refused to demonstrate it publicly, fearing premature exposure before patching windows close. Others, like hpone91, argued the specific configuration isn’t actually vulnerable to PHP2SHELL as advertised — pointing to architectural constraints (CLI mode, 1 MiB cap, inert page) that neutralize the core attack vectors.

Beyond the Bitcoin prize, the experiment serves as a rare real-world stress test for threat intelligence claims. It challenges sensational narratives about autonomous bot swarms instantly compromising every unpatched site — revealing instead a gap between theoretical exploitability and operational reliability. As one commenter observed, the fact that the server remained uncompromised after several hours suggests that even high-profile, actively discussed RCEs require significant manual effort or tailored tooling to deploy at scale. For defenders, it underscores that timely patching remains effective — but only if exploits aren’t already circulating in private channels.
