ASRN enables exact long-range copying with linear memory

News time: 2026-10-25T06:02:50.691940+00:00 · Source: reddit

A new neural architecture called ASRN—Adaptive Sparse Recurrence Network—offers a principled, memory-efficient way to copy tokens across arbitrarily long distances in language modeling. Unlike standard attention layers whose memory and compute scale quadratically with sequence length, ASRN uses adaptive sparse recurrence: each token only attends to its C most recent neighbors within learned sign-hash buckets, then copies the token that immediately followed each match. This design ensures per-token computation remains bounded—no matter how long the input—making it truly linear in both memory and time.

What makes ASRN distinctive is not just sparsity, but how it models when and how strongly to copy. It introduces a learned ‘proper-time clock’—a cumulative sum Bₜ = Σᵤ≤ₜ βᵤ—that draws inspiration from relativistic physics, where proper time measures elapsed time along an object’s worldline. In ASRN, this clock governs two key dynamics: the decay of retrieval scores (αₛ e⁻κ(Bₜ−Bₛ)) and the self-exciting intensity of repeated n-gram groups, modeled via a Hawkes process. That means repetitions don’t just trigger copying—they amplify future copying likelihood in a temporally grounded, history-aware way.

The final decision to copy is made by a learned non-monotonic gating function that reads both the Hawkes-derived repetition intensity and the local repetition streak. This avoids rigid heuristics and allows the model to learn nuanced copying policies—e.g., copying after three repeats but suppressing it after five, or delaying copy actions until context stabilizes. The architecture is fully differentiable and trained end-to-end, with open-source code and weights released on GitHub and Zenodo.

ASRN targets a persistent pain point in sequence modeling: efficient handling of exact repetitions over kilo-token contexts—think legal clauses, code snippets, or scientific definitions. While transformers can memorize such patterns, they do so at quadratic cost and often with blurry or hallucinated copies. ASRN sidesteps those trade-offs by design, offering verbatim reproduction without sacrificing scalability. Its fusion of ideas—from physics-inspired time modeling to event-driven self-excitation—signals a shift toward more interpretable, mechanism-aware architectures in efficient LMs.
